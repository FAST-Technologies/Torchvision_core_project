metrics.SegmentationMetrics

Модуль для расчёта метрик качества семантической и бинарной сегментации.

Предназначен для универсальной оценки соответствия предсказанных масок эталонным (Ground Truth) с поддержкой:

  • Бинарной сегментации: объект/фон (0/1 или 0/255).
  • Многоклассовой сегментации: пер-классовые метрики, матрица ошибок.
  • Кластеризации: внутренние метрики компактности (Silhouette, CH, DB).

Поддерживаемые метрики: ┌─────────────────────────────────────────────────────┐ │ Категория │ Метрики │ ├─────────────────────────────────────────────────────┤ │ Пересечение/Объединение │ IoU, Jaccard, Dice/F1 │ │ Классификация │ Precision, Recall, Accuracy │ │ Ошибки │ MAE, Pixel Accuracy │ │ Геометрия контуров │ Hausdorff Distance │ │ Статистика областей │ Area, Ratio, Difference │ │ Конфузионная матрица │ TP, FP, FN, TN │ │ Кластеризация* │ Silhouette, CH, Davies-Bouldin│ └─────────────────────────────────────────────────────┘

  • — только для масок с >2 уникальных классов

Особенности реализации:

  • 🔄 Все методы статические: класс используется как пространство имён.
  • 🎚️ Автоматическая бинаризация с адаптивным порогом для [0,1] и [0,255].
  • 🛡️ Защита от деления на ноль через smooth=1e-6 и 1e-8 в знаменателях.
  • 🔍 Опциональное сравнение кастомных и sklearn-реализаций (через verbose).
  • ⚡ Hausdorff Distance вычисляется только по координатам контуров, не по всей маске.
  • 📦 Групповой расчёт: calculate_all_metrics() для получения полного набора за один вызов.
  • 📊 Пакетная оценка: evaluate_multiple_masks() с агрегацией средних/стандартных значений.

Workflow:

  1. Подготовить предсказанную и эталонную маски (формат: np.ndarray, формы (H, W)).
  2. Вызвать SegmentationMetrics.calculate_all_metrics(pred_mask, gt_mask, threshold=0.5).
  3. Получить словарь с метриками для логирования, визуализации или агрегации.

Примечание:

  • Для бинарных масок значения должны быть в {0, 1} или {0, 255}; модуль автоматически приводит к единому формату через _normalize_masks().
  • Hausdorff Distance может возвращать inf, если один из контуров пуст — это ожидаемое поведение, обрабатывайте такие случаи в вызывающем коде.
  • Метрики кластеризации возвращают np.nan для бинарных масок, так как неинформативны при двух классах (фон/объект).
  • Для массового тестирования на датасетах используйте обёртки в BatchClassicTester2, SegmentationBenchmark или SegmentationTester.

 125    @staticmethod
 126    def _normalize_masks(
 127        pred_mask: MaskArray,
 128        gt_mask: MaskArray,
 129        threshold: float = 0.5,
 130    ) -> Tuple[MaskArray, MaskArray]:
 131        """Приводит маски к бинарному виду (0 и 1) и возвращает плоские массивы.
 132
 133        Логика:
 134        - Если макс. значение > 1, предполагается диапазон [0, 255] → порог умножается на 255.
 135        - Иначе предполагается диапазон [0, 1] → порог применяется напрямую.
 136        - Результат: `uint8` массивы формы `(H*W,)` для удобного сравнения.
 137
 138        Args:
 139            pred_mask: Предсказанная маска (бинарная или вероятностная).
 140            gt_mask: Ground truth маска.
 141            threshold: Порог бинаризации (0.0–1.0).
 142
 143        Returns:
 144            Tuple[np.ndarray, np.ndarray]:
 145            - Бинаризованное предсказание, форма `(N,)`, dtype `uint8`.
 146            - Бинаризованный ground truth, форма `(N,)`, dtype `uint8`.
 147        """
 148        # Бинаризация предсказания
 149        pred_binary: np.ndarray
 150        gt_binary: np.ndarray
 151        if pred_mask.max() > 1:
 152            pred_binary = (pred_mask > threshold * 255).astype(np.uint8)
 153        else:
 154            pred_binary = (pred_mask > threshold).astype(np.uint8)
 155
 156        # Бинаризация Ground Truth
 157        if gt_mask.max() > 1:
 158            gt_binary = (gt_mask > threshold * 255).astype(np.uint8)
 159        else:
 160            gt_binary = (gt_mask > threshold).astype(np.uint8)
 161        return pred_binary, gt_binary

 164    @staticmethod
 165    def calculate_iou(
 166        pred_mask: MaskArray,
 167        gt_mask: MaskArray,
 168        threshold: float = 0.5,
 169    ) -> MetricValue:
 170        """Intersection over Union (IoU) / Jaccard Index.
 171
 172        Формула:
 173        ```
 174        IoU = |A ∩ B| / |A ∪ B|
 175        ```
 176
 177        Args:
 178            pred_mask: Предсказанная маска (0–1 или 0–255).
 179            gt_mask: Ground truth маска.
 180            threshold: Порог для бинаризации.
 181
 182        Returns:
 183            float: Значение IoU в диапазоне [0, 1].
 184        """
 185        # Нормализуем маски к бинарному формату 0/1
 186        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 187
 188        # Вычисляем пересечение и объединение
 189        intersection: int = int(np.logical_and(pred_binary, gt_binary).sum())
 190        union: int = int(np.logical_or(pred_binary, gt_binary).sum())
 191        if union == 0:
 192            return 0.0
 193        return float(intersection / (union + 1e-8))

 248    @staticmethod
 249    def calculate_dice_coefficient(
 250        pred_mask: MaskArray,
 251        gt_mask: MaskArray,
 252        threshold: float = 0.5,
 253        smooth: float = 1e-6,
 254    ) -> MetricValue:
 255        """Dice Coefficient / F1 Score для бинарной сегментации.
 256
 257        Формула:
 258        ```
 259        Dice = (2 * |A ∩ B| + smooth) / (|A| + |B| + smooth)
 260        ```
 261
 262        Args:
 263            pred_mask: Предсказанная маска.
 264            gt_mask: Ground truth маска.
 265            threshold: Порог для бинаризации.
 266            smooth: Малое значение для избежания деления на ноль.
 267
 268        Returns:
 269            float: Значение Dice coefficient в диапазоне [0, 1].
 270        """
 271        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 272        intersection: int = int(np.logical_and(pred_binary, gt_binary).sum())
 273        dice: MetricValue = (2.0 * intersection + smooth) / (int(pred_binary.sum()) + int(gt_binary.sum()) + smooth)
 274        return float(dice)

 277    @staticmethod
 278    def calculate_precision_recall(
 279        pred_mask: MaskArray,
 280        gt_mask: MaskArray,
 281        threshold: float = 0.5,
 282        verbose: bool = False,
 283    ) -> Tuple[MetricValue, MetricValue]:
 284        """Precision и Recall для бинарной сегментации.
 285
 286        Формулы:
 287        ```
 288        Precision = TP / (TP + FP)
 289        Recall    = TP / (TP + FN)
 290        ```
 291
 292        Args:
 293            pred_mask: Предсказанная маска.
 294            gt_mask: Ground truth маска.
 295            threshold: Порог для бинаризации.
 296            verbose: Если `True`, выводит сравнение sklearn vs custom.
 297
 298        Returns:
 299            Tuple[float, float]: (precision, recall) в диапазоне [0, 1].
 300        """
 301        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 302
 303        # Sklearn (Эталон)
 304        p_sklearn: MetricValue = precision_score(gt_binary.ravel(), pred_binary.ravel(), zero_division=0)
 305        r_sklearn: MetricValue = recall_score(gt_binary.ravel(), pred_binary.ravel(), zero_division=0)
 306
 307        # Confusion matrix также требует 1D
 308        tn, fp, fn, tp = confusion_matrix(gt_binary.ravel(), pred_binary.ravel(), labels=[0, 1]).ravel()
 309
 310        p_custom: MetricValue = tp / (tp + fp + 1e-8)
 311        r_custom: MetricValue = tp / (tp + fn + 1e-8)
 312
 313        if verbose:
 314            logging.info("--- Сравнение Precision/Recall ---")
 315            logging.info(f"TP: {tp}, FP: {fp}, FN: {fn}, TN: {tn}")
 316            logging.info(
 317                f"Precision: Sklearn={p_sklearn:.6f} | Custom={p_custom:.6f} | Diff={abs(p_sklearn - p_custom):.2e}"
 318            )
 319            logging.info(
 320                f"Recall:    Sklearn={r_sklearn:.6f} | Custom={r_custom:.6f} | Diff={abs(r_sklearn - r_custom):.2e}"
 321            )
 322
 323        return float(p_custom), float(r_custom)

 326    @staticmethod
 327    def calculate_f1_score(
 328        pred_mask: MaskArray,
 329        gt_mask: MaskArray,
 330        threshold: float = 0.5,
 331        verbose: bool = False,
 332    ) -> MetricValue:
 333        """F1 Score (среднее гармоническое precision и recall).
 334
 335        Формула:
 336        ```
 337        F1 = 2 * (Precision * Recall) / (Precision + Recall)
 338        ```
 339
 340        Args:
 341            pred_mask: Предсказанная маска.
 342            gt_mask: Ground truth маска.
 343            threshold: Порог для бинаризации.
 344            verbose: Если `True`, выводит сравнение sklearn vs custom.
 345
 346        Returns:
 347            float: Значение F1 Score в диапазоне [0, 1].
 348        """
 349        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 350        precision, recall = SegmentationMetrics.calculate_precision_recall(pred_mask, gt_mask, threshold)
 351        if precision + recall == 0:
 352            f1_custom: MetricValue = 0.0
 353        else:
 354            f1_custom = 2 * (precision * recall) / (precision + recall + 1e-8)
 355
 356        f1_sklearn: MetricValue = f1_score(gt_binary.ravel(), pred_binary.ravel())
 357        if verbose:
 358            logging.info(
 359                f"F1-Score: Sklearn={f1_sklearn:.6f} | Custom={f1_custom:.6f} | Diff={abs(f1_sklearn - f1_custom):.2e}"
 360            )
 361        return float(f1_custom)

 368        normalize: bool = True,

 371        """Mean Absolute Error (Средняя абсолютная погрешность).

 373        Args:

 375            gt_mask: Ground truth маска.

 381        """
 382        # Нормализация к [0, 1] если нужно
 383        pred_norm: np.ndarray
 384        gt_norm: np.ndarray
 385        if normalize:
 386            pred_norm = pred_mask.astype(np.float32) / 255.0 if pred_mask.max() > 1 else pred_mask.astype(np.float32)
 387            gt_norm = gt_mask.astype(np.float32) / 255.0 if gt_mask.max() > 1 else gt_mask.astype(np.float32)
 388        else:
 389            pred_norm = pred_mask.astype(np.float32)
 390            gt_norm = gt_mask.astype(np.float32)
 391
 392        # Кастомный
 393        mae_custom: MetricValue = np.abs(pred_norm - gt_norm).mean()
 394
 395        # Sklearn
 396        if verbose:
 397            mae_sklearn: MetricValue = mean_absolute_error(gt_norm, pred_norm)
 398            logging.info(
 399                f"MAE: Sklearn={mae_sklearn:.6f} | Custom={mae_custom:.6f} | Diff={abs(mae_sklearn - mae_custom):.2e}"
 400            )
 401        return float(mae_custom)

 404    @staticmethod
 405    def calculate_hausdorff_distance(
 406        pred_mask: MaskArray,
 407        gt_mask: MaskArray,
 408        threshold: float = 0.5,
 409    ) -> MetricValue:
 410        """Hausdorff Distance (Расстояние Хаусдорфа) между контурами масок.
 411
 412        Вычисляется как максимум из двух направленных расстояний:
 413        ```
 414        H(A, B) = max( h(A→B), h(B→A) )
 415        ```
 416
 417        Args:
 418            pred_mask: Предсказанная маска.
 419            gt_mask: Ground truth маска.
 420            threshold: Порог для бинаризации.
 421
 422        Returns:
 423            float: Значение расстояния Хаусдорфа (в пикселях) или `inf` при ошибке.
 424        """
 425        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 426
 427        # Получаем координаты точек контуров
 428        pred_coords: np.ndarray = np.column_stack(np.where(pred_binary))
 429        gt_coords: np.ndarray = np.column_stack(np.where(gt_binary))
 430
 431        # Если один из контуров пустой, возвращаем бесконечность
 432        if len(pred_coords) == 0 or len(gt_coords) == 0:
 433            return float("inf")
 434
 435        try:
 436            # Вычисляем двунаправленное расстояние Хаусдорфа
 437            h1: MetricValue = directed_hausdorff(pred_coords, gt_coords)[0]
 438            h2: MetricValue = directed_hausdorff(gt_coords, pred_coords)[0]
 439            hausdorff_dist = max(h1, h2)
 440        except ValueError:
 441            hausdorff_dist = float("inf")
 442        return float(hausdorff_dist)

 445    @staticmethod
 446    def calculate_clustering_metrics(
 447        pred_mask: MaskArray,
 448        n_samples: int = 1000,
 449    ) -> ClusteringMetricsDict:
 450        """Оценивает внутреннюю компактность сегментов (только если классов > 2).
 451
 452        Поддерживаемые метрики:
 453        - Silhouette Score: [-1, 1], чем больше — тем лучше.
 454        - Calinski-Harabasz: [0, ∞), чем больше — тем лучше.
 455        - Davies-Bouldin: [0, ∞), чем меньше — тем лучше.
 456
 457        ⚠️ Для бинарной маски (фон/объект) эти метрики не информативны.
 458
 459        Args:
 460            pred_mask: Многоклассовая маска с целочисленными метками.
 461            n_samples: Количество случайных пикселей для сэмплирования (для скорости).
 462
 463        Returns:
 464            Dict[str, Optional[float]]:
 465            ```python
 466            {
 467                "silhouette_score": float | None,
 468                "calinski_harabasz_score": float | None,
 469                "davies_bouldin_score": float | None,
 470            }
 471            ```
 472        """
 473        unique_labels: np.ndarray = np.unique(pred_mask)
 474
 475        if len(unique_labels) <= 2:
 476            return {
 477                "silhouette_score": np.nan,
 478                "calinski_harabasz_score": np.nan,
 479                "davies_bouldin_score": np.nan,
 480            }
 481
 482        h, w = pred_mask.shape
 483        y_coords, x_coords = np.mgrid[0:h, 0:w]
 484
 485        # Сэмплируем 1000 случайных пикселей для скорости
 486        n_pixels: int = int(h * w)
 487        indices: np.ndarray = np.random.choice(n_pixels, min(n_samples, n_pixels), replace=False)
 488
 489        X: np.ndarray = np.column_stack([y_coords.ravel()[indices], x_coords.ravel()[indices]])
 490        labels: np.ndarray = pred_mask.ravel()[indices]
 491
 492        metrics: ClusteringMetricsDict = {}
 493        try:
 494            if len(np.unique(labels)) > 1:
 495                metrics["silhouette_score"] = silhouette_score(X, labels)
 496                metrics["calinski_harabasz_score"] = calinski_harabasz_score(X, labels)
 497                metrics["davies_bouldin_score"] = davies_bouldin_score(X, labels)
 498            else:
 499                metrics["silhouette_score"] = None
 500                metrics["calinski_harabasz_score"] = None
 501                metrics["davies_bouldin_score"] = None
 502        except Exception:
 503            # При любой ошибке возвращаем None
 504            metrics["silhouette_score"] = None
 505            metrics["calinski_harabasz_score"] = None
 506            metrics["davies_bouldin_score"] = None
 507        return metrics

 510    @staticmethod
 511    def calculate_pixel_accuracy(
 512        pred_mask: MaskArray,
 513        gt_mask: MaskArray,
 514        threshold: float = 0.5,
 515    ) -> MetricValue:
 516        """Pixel Accuracy (Пиксельная точность).
 517
 518        Формула:
 519        ```
 520        Accuracy = |{i : pred[i] == gt[i]}| / N
 521        ```
 522
 523        Args:
 524            pred_mask: Предсказанная маска.
 525            gt_mask: Ground truth маска.
 526            threshold: Порог для бинаризации.
 527
 528        Returns:
 529            float: Значение точности в диапазоне [0, 1].
 530        """
 531        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 532
 533        correct_pixels: int = int((pred_binary == gt_binary).sum())
 534        total_pixels: int = int(pred_binary.size)
 535
 536        if total_pixels == 0:
 537            return 0.0
 538        return float(correct_pixels / total_pixels)

 541    @staticmethod
 542    def calculate_all_metrics(
 543        pred_mask: MaskArray,
 544        gt_mask: MaskArray,
 545        threshold: float = 0.5,
 546        include_hausdorff: bool = True,
 547        verbose_comparison: bool = False,
 548        metrics_list: Optional[List[str]] = None,
 549    ) -> MetricsDict:
 550        """Вычисляет все метрики качества сегментации в одном вызове.
 551
 552        Возвращаемые метрики:
 553        - `accuracy`, `iou`, `jaccard_score`, `dice`
 554        - `precision`, `recall`, `f1_score`, `pixel_accuracy`, `mae`
 555        - `hausdorff_distance` (если `include_hausdorff=True`)
 556        - `predicted_area`, `ground_truth_area`, `area_difference`, `area_ratio`
 557        - `true_positive`, `false_positive`, `false_negative`, `true_negative`
 558
 559        Args:
 560            pred_mask: Предсказанная маска.
 561            gt_mask: Ground truth маска.
 562            threshold: Порог для бинаризации.
 563            include_hausdorff: Включать ли вычисление расстояния Хаусдорфа (медленно!).
 564            verbose_comparison: Если `True`, выводит сравнение кастомных и sklearn-реализаций.
 565            metrics_list: Список метрик для вычисления. Если None — вычисляются все.
 566
 567        Returns:
 568            Dict[str, float]: Словарь со всеми рассчитанными метриками.
 569        """
 570        metrics: MetricsDict = {}
 571
 572        if metrics_list is None:
 573            metrics_list = [
 574                "accuracy",
 575                "iou",
 576                "jaccard_score",
 577                "dice",
 578                "precision",
 579                "recall",
 580                "f1_score",
 581                "pixel_accuracy",
 582                "mae",
 583                "hausdorff_distance",
 584                "predicted_area",
 585                "ground_truth_area",
 586                "area_difference",
 587                "area_ratio",
 588                "true_positive",
 589                "false_positive",
 590                "false_negative",
 591                "true_negative",
 592            ]
 593
 594        def _need(metric_name: str) -> bool:
 595            return metric_name in metrics_list
 596
 597        # 1. Точность (Accuracy)
 598        if _need("accuracy"):
 599            metrics["accuracy"] = SegmentationMetrics.calculate_accuracy_sklearn(pred_mask, gt_mask, threshold)
 600
 601        # 2. IoU / Jaccard
 602        if _need("iou") or _need("jaccard_score"):
 603            iou_custom: MetricValue = SegmentationMetrics.calculate_iou(pred_mask, gt_mask, threshold)
 604            if _need("iou"):
 605                metrics["iou"] = iou_custom
 606            if _need("jaccard_score"):
 607                iou_sklearn: MetricValue = SegmentationMetrics.calculate_jaccard_sklearn(pred_mask, gt_mask, threshold)
 608                metrics["jaccard_score"] = iou_sklearn
 609
 610            if verbose_comparison and _need("iou") and _need("jaccard_score"):
 611                logging.info(
 612                    f"IoU Check: Custom={iou_custom:.6f} | Sklearn={iou_sklearn:.6f} | Diff={abs(iou_custom - iou_sklearn):.2e}"
 613                )
 614
 615        # 3. Dice
 616        if _need("dice"):
 617            metrics["dice"] = SegmentationMetrics.calculate_dice_coefficient(pred_mask, gt_mask, threshold)
 618
 619        # 4. Precision & Recall (с внутренней проверкой)
 620        if _need("precision") or _need("recall") or _need("f1_score"):
 621            precision, recall = SegmentationMetrics.calculate_precision_recall(
 622                pred_mask, gt_mask, threshold, verbose=verbose_comparison
 623            )
 624            if _need("precision"):
 625                metrics["precision"] = precision
 626            if _need("recall"):
 627                metrics["recall"] = recall
 628
 629        # 5. F1 Score (с внутренней проверкой)
 630        if _need("f1_score"):
 631            metrics["f1_score"] = SegmentationMetrics.calculate_f1_score(
 632                pred_mask, gt_mask, threshold, verbose=verbose_comparison
 633            )
 634
 635        # 6. Pixel Accuracy
 636        if _need("pixel_accuracy"):
 637            metrics["pixel_accuracy"] = SegmentationMetrics.calculate_pixel_accuracy(pred_mask, gt_mask, threshold)
 638
 639        # 7. MAE (с внутренней проверкой)
 640        if _need("mae"):
 641            metrics["mae"] = SegmentationMetrics.calculate_mae(pred_mask, gt_mask, verbose=verbose_comparison)
 642
 643        # 8. Hausdorff
 644        if _need("hausdorff_distance") and include_hausdorff:
 645            metrics["hausdorff_distance"] = SegmentationMetrics.calculate_hausdorff_distance(
 646                pred_mask, gt_mask, threshold
 647            )
 648
 649        # 9. Статистика областей и Confusion Matrix
 650        area_or_cm_metrics = [
 651            "predicted_area",
 652            "ground_truth_area",
 653            "area_difference",
 654            "area_ratio",
 655            "true_positive",
 656            "false_positive",
 657            "false_negative",
 658            "true_negative",
 659        ]
 660        if any(_need(m) for m in area_or_cm_metrics):
 661            pred_binary, gt_binary = SegmentationMetrics._normalize_masks(pred_mask, gt_mask, threshold)
 662
 663            # Площади
 664            if _need("predicted_area"):
 665                metrics["predicted_area"] = float(np.sum(pred_binary))
 666            if _need("ground_truth_area"):
 667                metrics["ground_truth_area"] = float(np.sum(gt_binary))
 668            if _need("area_difference"):
 669                pred_area = int(np.sum(pred_binary))
 670                gt_area = int(np.sum(gt_binary))
 671                metrics["area_difference"] = float(abs(pred_area - gt_area))
 672            if _need("area_ratio"):
 673                pred_area = int(np.sum(pred_binary))
 674                gt_area = int(np.sum(gt_binary))
 675                if max(pred_area, gt_area) > 0:
 676                    metrics["area_ratio"] = min(pred_area, gt_area) / max(pred_area, gt_area)
 677                else:
 678                    metrics["area_ratio"] = 0.0
 679
 680            # Confusion Matrix Elements
 681            cm_metrics = [
 682                "true_positive",
 683                "false_positive",
 684                "false_negative",
 685                "true_negative",
 686            ]
 687            if any(_need(m) for m in cm_metrics):
 688                try:
 689                    tn, fp, fn, tp = confusion_matrix(gt_binary.ravel(), pred_binary.ravel(), labels=[0, 1]).ravel()
 690                    if _need("true_negative"):
 691                        metrics["true_negative"] = int(tn)
 692                    if _need("false_positive"):
 693                        metrics["false_positive"] = int(fp)
 694                    if _need("false_negative"):
 695                        metrics["false_negative"] = int(fn)
 696                    if _need("true_positive"):
 697                        metrics["true_positive"] = int(tp)
 698                except ValueError as e:
 699                    warnings.warn(f"Не удалось вычислить матрицу ошибок: {e}")
 700                    for m in cm_metrics:
 701                        if _need(m):
 702                            metrics[m] = 0
 703
 704        return metrics

 708    def evaluate_multiple_masks(
 709        pred_masks: List[MaskArray],
 710        gt_masks: List[MaskArray],
 711        threshold: float = 0.5,
 712    ) -> Dict[str, Any]:
 713        """Оценка нескольких масок с вычислением средних метрик.
 714
 715        Args:
 716            pred_masks: Список предсказанных масок.
 717            gt_masks: Список ground truth масок.
 718            threshold: Порог для бинаризации.
 719
 720        Returns:
 721            Dict[str, Any]:
 722            ```python
 723            {
 724                "individual_results": Dict[str, MetricsDict],  # по индексам
 725                "average_metrics": Dict[str, float],           # средние значения
 726                "total_masks": int,
 727            }
 728            ```
 729
 730        Raises:
 731            ValueError: Если длины списков не совпадают.
 732        """
 733        if len(pred_masks) != len(gt_masks):
 734            raise ValueError("Количество предсказанных и ground truth масок должно совпадать")
 735
 736        all_metrics: List[MetricsDict] = []
 737        individual_results: Dict[str, MetricsDict] = {}
 738
 739        for i, (pred_mask, gt_mask) in enumerate(zip(pred_masks, gt_masks)):
 740            metrics: MetricsDict = SegmentationMetrics.calculate_all_metrics(
 741                pred_mask, gt_mask, threshold, include_hausdorff=False
 742            )
 743            all_metrics.append(metrics)
 744            individual_results[f"mask_{i}"] = metrics
 745
 746        # Вычисляем средние метрики
 747        avg_metrics: Dict[str, MetricValue] = {}
 748        if not all_metrics:
 749            return {"average_metrics": {}, "individual_results": {}}
 750
 751        for key in all_metrics[0].keys():
 752            values: List[MetricValue] = [m[key] for m in all_metrics if key in m and not np.isnan(m[key])]
 753            if values:
 754                avg_metrics[f"avg_{key}"] = float(np.mean(values))
 755                avg_metrics[f"std_{key}"] = float(np.std(values))
 756                avg_metrics[f"min_{key}"] = float(np.min(values))
 757                avg_metrics[f"max_{key}"] = float(np.max(values))
 758        return {
 759            "individual_results": individual_results,
 760            "average_metrics": avg_metrics,
 761            "total_masks": len(pred_masks),
 762        }

 765    @staticmethod
 766    def calculate_multiclass_miou(
 767        pred_mask: MaskArray,
 768        gt_mask: MaskArray,
 769        ignore_index: int = 255,
 770        num_classes: Optional[int] = None,
 771        return_per_class: bool = False,
 772    ) -> Union[MetricValue, Tuple[MetricValue, Dict[int, MetricValue]]]:
 773        """Multi-class Mean IoU (mIoU) для семантической сегментации.
 774
 775        Корректно обрабатывает:
 776        - Ignore index (по умолчанию 255) — исключается из расчёта
 777        - Классы, присутствующие только в предсказании или только в GT
 778        - Пустые классы (без пикселей в объединении)
 779
 780        Формула для каждого класса:
 781        ```
 782        IoU_c = |pred_c ∩ gt_c| / |pred_c ∪ gt_c|
 783        mIoU = mean(IoU_c for all classes with union > 0)
 784        ```
 785
 786        Args:
 787            pred_mask: Предсказанная маска с целочисленными метками классов, форма (H, W).
 788            gt_mask: Ground truth маска с целочисленными метками, форма (H, W).
 789            ignore_index: Значение, обозначающее игнорируемые пиксели (по умолчанию 255).
 790            num_classes: Опциональное количество классов. Если None — определяется автоматически.
 791            return_per_class: Если True, возвращает также словарь {class_id: iou}.
 792
 793        Returns:
 794            float | Tuple[float, Dict[int, float]]:
 795            - mIoU значение в диапазоне [0, 1]
 796            - Если return_per_class=True: кортеж (mIoU, {class_id: iou_per_class})
 797        """
 798        # Приводим к одинаковой форме и типу
 799        pred = np.asarray(pred_mask, dtype=np.int32)
 800        gt = np.asarray(gt_mask, dtype=np.int32)
 801
 802        if pred.shape != gt.shape:
 803            raise ValueError(f"Shape mismatch: pred {pred.shape} vs gt {gt.shape}")
 804
 805        # Создаём маску валидных пикселей (исключаем ignore_index)
 806        valid_mask = (gt != ignore_index) & (pred != ignore_index)
 807
 808        # Определяем диапазон классов
 809        if num_classes is None:
 810            # Автоматически: все классы, которые встречаются в валидных пикселях
 811            classes = np.unique(np.concatenate([gt[valid_mask], pred[valid_mask]]))
 812            classes = classes[classes != ignore_index]  # на всякий случай
 813        else:
 814            classes = np.arange(num_classes)
 815
 816        iou_per_class: Dict[int, float] = {}
 817
 818        for cls in classes:
 819            # Бинарные маски для текущего класса (только валидные пиксели)
 820            pred_cls = (pred == cls) & valid_mask
 821            gt_cls = (gt == cls) & valid_mask
 822
 823            intersection = np.logical_and(pred_cls, gt_cls).sum()
 824            union = np.logical_or(pred_cls, gt_cls).sum()
 825
 826            if union > 0:
 827                iou_per_class[int(cls)] = float(intersection / union)
 828            else:
 829                # Класс есть, но нет пикселей в объединении — пропускаем в среднем
 830                iou_per_class[int(cls)] = np.nan
 831
 832        # Считаем mIoU только по классам с валидным IoU (не NaN)
 833        valid_ious = [v for v in iou_per_class.values() if not np.isnan(v)]
 834
 835        if not valid_ious:
 836            m_iou = 0.0
 837        else:
 838            m_iou = float(np.mean(valid_ious))
 839
 840        if return_per_class:
 841            return m_iou, iou_per_class
 842        return m_iou

 845    @staticmethod
 846    def compute_segmentation_metrics(
 847        pred_mask: MaskArray,
 848        gt_mask: MaskArray,
 849        num_classes: int,
 850        ignore_index: int = 255,
 851        include_confusion_matrix: bool = True,
 852        include_hausdorff: bool = False,
 853    ) -> MetricsDict:
 854        """Полный расчёт метрик для семантической сегментации (multi-class).
 855
 856        Объединяет:
 857        - Multi-class mIoU (per-class + mean)
 858        - Pixel Accuracy
 859        - Weighted F1-Score
 860        - Confusion Matrix (опционально)
 861        - Бинарные метрики (для совместимости)
 862
 863        Args:
 864            pred_mask: Предсказанная маска [H, W].
 865            gt_mask: Ground truth маска [H, W].
 866            num_classes: Общее количество классов.
 867            ignore_index: Индекс игнорируемых пикселей.
 868            include_confusion_matrix: Вычислять ли confusion matrix (медленно для 150 классов).
 869            include_hausdorff: Вычислять ли Hausdorff distance (очень медленно!).
 870
 871        Returns:
 872            Dict[str, Any]:
 873            ```python
 874            {
 875                "mIoU": float,                    # Mean IoU
 876                "pixel_acc": float,               # Pixel Accuracy
 877                "f1_weighted": float,             # Weighted F1
 878                "per_class_iou": np.ndarray,      # [num_classes]
 879                "confusion_matrix": np.ndarray,   # [num_classes, num_classes] или None
 880                "iou": float,                     # Binary IoU (для совместимости)
 881                "dice": float,                    # Binary Dice
 882                "hausdorff_distance": float,      # Если include_hausdorff=True
 883            }
 884            ```
 885        """
 886        # Валидные пиксели
 887        valid_mask = gt_mask != ignore_index
 888        if not np.any(valid_mask):
 889            return {
 890                "mIoU": np.nan,
 891                "pixel_acc": np.nan,
 892                "f1_weighted": np.nan,
 893                "per_class_iou": np.array([np.nan] * num_classes),
 894                "confusion_matrix": None,
 895                "iou": np.nan,
 896                "dice": np.nan,
 897            }
 898
 899        pred_valid = pred_mask[valid_mask]
 900        gt_valid = np.clip(gt_mask[valid_mask], 0, num_classes - 1)
 901
 902        # 1. Multi-class mIoU
 903        m_iou, per_class_iou_dict = SegmentationMetrics.calculate_multiclass_miou(
 904            pred_mask=pred_mask,
 905            gt_mask=gt_mask,
 906            ignore_index=ignore_index,
 907            num_classes=num_classes,
 908            return_per_class=True,
 909        )
 910
 911        # Конвертируем dict → array
 912        per_class_iou_array = np.array([per_class_iou_dict.get(c, np.nan) for c in range(num_classes)])
 913
 914        # 2. Pixel Accuracy
 915        pixel_acc = accuracy_score(gt_valid, pred_valid)
 916
 917        # 3. Weighted F1-Score
 918        f1_weighted = f1_score(
 919            gt_valid,
 920            pred_valid,
 921            average="weighted",
 922            labels=list(range(num_classes)),
 923            zero_division=0,
 924        )
 925
 926        # 4. Confusion Matrix (опционально)
 927        cm = None
 928        if include_confusion_matrix:
 929            cm = confusion_matrix(gt_valid, pred_valid, labels=list(range(num_classes)))
 930
 931        # 5. Бинарные метрики (для совместимости с старым кодом)
 932        pred_binary = (pred_mask > 0).astype(np.uint8)
 933        gt_binary = (gt_mask > 0).astype(np.uint8)
 934
 935        binary_metrics = SegmentationMetrics.calculate_all_metrics(
 936            pred_mask=pred_binary,
 937            gt_mask=gt_binary,
 938            threshold=0.5,
 939            include_hausdorff=include_hausdorff,
 940        )
 941
 942        result: MetricsDict = {
 943            "mIoU": m_iou,
 944            "pixel_acc": pixel_acc,
 945            "f1_weighted": f1_weighted,
 946            "per_class_iou": per_class_iou_array,
 947            "confusion_matrix": cm,
 948            "iou": binary_metrics.get("iou", np.nan),
 949            "dice": binary_metrics.get("dice", np.nan),
 950        }
 951
 952        if include_hausdorff:
 953            result["hausdorff_distance"] = binary_metrics.get("hausdorff_distance", np.nan)
 954
 955        return result

 957    @staticmethod
 958    def calculate_per_class_dice(
 959        pred_mask: MaskArray,

 430        gt_coords: np.ndarray = np.column_stack(np.where(gt_binary))
 431
 432        # Если один из контуров пустой, возвращаем бесконечность

 767    def calculate_multiclass_miou(
 768        pred_mask: MaskArray,
 769        gt_mask: MaskArray,
 770        ignore_index: int = 255,
 771        num_classes: Optional[int] = None,
 772        return_per_class: bool = False,
 773    ) -> Union[MetricValue, Tuple[MetricValue, Dict[int, MetricValue]]]:
 774        """Multi-class Mean IoU (mIoU) для семантической сегментации.
 775

 777        - Ignore index (по умолчанию 255) — исключается из расчёта
 778        - Классы, присутствующие только в предсказании или только в GT
 779        - Пустые классы (без пикселей в объединении)
 780
 781        Формула для каждого класса:
 782        ```
 783        IoU_c = |pred_c ∩ gt_c| / |pred_c ∪ gt_c|
 784        mIoU = mean(IoU_c for all classes with union > 0)
 785        ```
 786
 787        Args:
 788            pred_mask: Предсказанная маска с целочисленными метками классов, форма (H, W).
 789            gt_mask: Ground truth маска с целочисленными метками, форма (H, W).
 790            ignore_index: Значение, обозначающее игнорируемые пиксели (по умолчанию 255).

 792            return_per_class: Если True, возвращает также словарь {class_id: iou}.
 793
 794        Returns:
 795            float | Tuple[float, Dict[int, float]]:
 796            - mIoU значение в диапазоне [0, 1]
 797            - Если return_per_class=True: кортеж (mIoU, {class_id: iou_per_class})
 798        """
 799        # Приводим к одинаковой форме и типу
 800        pred = np.asarray(pred_mask, dtype=np.int32)
 801        gt = np.asarray(gt_mask, dtype=np.int32)
 802
 803        if pred.shape != gt.shape:
 804            raise ValueError(f"Shape mismatch: pred {pred.shape} vs gt {gt.shape}")
 805
 806        # Создаём маску валидных пикселей (исключаем ignore_index)
 807        valid_mask = (gt != ignore_index) & (pred != ignore_index)
 808
 809        # Определяем диапазон классов
 810        if num_classes is None:
 811            # Автоматически: все классы, которые встречаются в валидных пикселях
 812            classes = np.unique(np.concatenate([gt[valid_mask], pred[valid_mask]]))
 813            classes = classes[classes != ignore_index]  # на всякий случай
 814        else:
 815            classes = np.arange(num_classes)
 816
 817        iou_per_class: Dict[int, float] = {}
 818
 819        for cls in classes:
 820            # Бинарные маски для текущего класса (только валидные пиксели)
 821            pred_cls = (pred == cls) & valid_mask
 822            gt_cls = (gt == cls) & valid_mask
 823
 824            intersection = np.logical_and(pred_cls, gt_cls).sum()
 825            union = np.logical_or(pred_cls, gt_cls).sum()
 826
 827            if union > 0:
 828                iou_per_class[int(cls)] = float(intersection / union)
 829            else:
 830                # Класс есть, но нет пикселей в объединении — пропускаем в среднем
 831                iou_per_class[int(cls)] = np.nan
 832
 833        # Считаем mIoU только по классам с валидным IoU (не NaN)
 834        valid_ious = [v for v in iou_per_class.values() if not np.isnan(v)]
 835
 836        if not valid_ious:
 837            m_iou = 0.0
 838        else:
 839            m_iou = float(np.mean(valid_ious))
 840
 841        if return_per_class:
 842            return m_iou, iou_per_class
 843        return m_iou
