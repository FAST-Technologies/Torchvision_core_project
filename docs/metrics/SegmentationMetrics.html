metrics.SegmentationMetrics

Модуль для расчёта метрик качества семантической и бинарной сегментации.

Предназначен для универсальной оценки соответствия предсказанных масок эталонным (Ground Truth) с поддержкой:

  • Бинарной сегментации: объект/фон (0/1 или 0/255).
  • Многоклассовой сегментации: пер-классовые метрики, матрица ошибок.
  • Кластеризации: внутренние метрики компактности (Silhouette, CH, DB).

Поддерживаемые метрики: ┌─────────────────────────────────────────────────────┐ │ Категория │ Метрики │ ├─────────────────────────────────────────────────────┤ │ Пересечение/Объединение │ IoU, Jaccard, Dice/F1 │ │ Классификация │ Precision, Recall, Accuracy │ │ Ошибки │ MAE, Pixel Accuracy │ │ Геометрия контуров │ Hausdorff Distance │ │ Статистика областей │ Area, Ratio, Difference │ │ Конфузионная матрица │ TP, FP, FN, TN │ │ Кластеризация* │ Silhouette, CH, Davies-Bouldin│ └─────────────────────────────────────────────────────┘

  • — только для масок с >2 уникальных классов

Особенности реализации:

  • 🔄 Все методы статические: класс используется как пространство имён.
  • 🎚️ Автоматическая бинаризация с адаптивным порогом для [0,1] и [0,255].
  • 🛡️ Защита от деления на ноль через smooth=1e-6 и 1e-8 в знаменателях.
  • 🔍 Опциональное сравнение кастомных и sklearn-реализаций (через verbose).
  • ⚡ Hausdorff Distance вычисляется только по координатам контуров, не по всей маске.
  • 📦 Групповой расчёт: calculate_all_metrics() для получения полного набора за один вызов.
  • 📊 Пакетная оценка: evaluate_multiple_masks() с агрегацией средних/стандартных значений.

Workflow:

  1. Подготовить предсказанную и эталонную маски (формат: np.ndarray, формы (H, W)).
  2. Вызвать SegmentationMetrics.calculate_all_metrics(pred_mask, gt_mask, threshold=0.5).
  3. Получить словарь с метриками для логирования, визуализации или агрегации.

Примечание:

  • Для бинарных масок значения должны быть в {0, 1} или {0, 255}; модуль автоматически приводит к единому формату через _normalize_masks().
  • Hausdorff Distance может возвращать inf, если один из контуров пуст — это ожидаемое поведение, обрабатывайте такие случаи в вызывающем коде.
  • Метрики кластеризации возвращают np.nan для бинарных масок, так как неинформативны при двух классах (фон/объект).
  • Для массового тестирования на датасетах используйте обёртки в BatchClassicTester2, SegmentationBenchmark или SegmentationTester.

120    @staticmethod
121    def _normalize_masks(
122        pred_mask: MaskArray,
123        gt_mask: MaskArray,
124        threshold: float = 0.5,
125    ) -> Tuple[MaskArray, MaskArray]:
126        """Приводит маски к бинарному виду (0 и 1) и возвращает плоские массивы.
127
128        Логика:
129        - Если макс. значение > 1, предполагается диапазон [0, 255] → порог умножается на 255.
130        - Иначе предполагается диапазон [0, 1] → порог применяется напрямую.
131        - Результат: `uint8` массивы формы `(H*W,)` для удобного сравнения.
132
133        Args:
134            pred_mask: Предсказанная маска (бинарная или вероятностная).
135            gt_mask: Ground truth маска.
136            threshold: Порог бинаризации (0.0–1.0).
137
138        Returns:
139            Tuple[np.ndarray, np.ndarray]:
140            - Бинаризованное предсказание, форма `(N,)`, dtype `uint8`.
141            - Бинаризованный ground truth, форма `(N,)`, dtype `uint8`.
142        """
143        # Бинаризация предсказания
144        pred_binary: np.ndarray
145        gt_binary: np.ndarray
146        if pred_mask.max() > 1:
147            pred_binary = (pred_mask > threshold * 255).astype(np.uint8)
148        else:
149            pred_binary = (pred_mask > threshold).astype(np.uint8)
150
151        # Бинаризация Ground Truth
152        if gt_mask.max() > 1:
153            gt_binary = (gt_mask > threshold * 255).astype(np.uint8)
154        else:
155            gt_binary = (gt_mask > threshold).astype(np.uint8)
156        return pred_binary, gt_binary

159    @staticmethod
160    def calculate_iou(
161        pred_mask: MaskArray,
162        gt_mask: MaskArray,
163        threshold: float = 0.5,
164    ) -> MetricValue:
165        """Intersection over Union (IoU) / Jaccard Index.
166
167        Формула:
168        ```
169        IoU = |A ∩ B| / |A ∪ B|
170        ```
171
172        Args:
173            pred_mask: Предсказанная маска (0–1 или 0–255).
174            gt_mask: Ground truth маска.
175            threshold: Порог для бинаризации.
176
177        Returns:
178            float: Значение IoU в диапазоне [0, 1].
179        """
180        # Нормализуем маски к бинарному формату 0/1
181        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
182            pred_mask, gt_mask, threshold
183        )
184
185        # Вычисляем пересечение и объединение
186        intersection: int = int(np.logical_and(pred_binary, gt_binary).sum())
187        union: int = int(np.logical_or(pred_binary, gt_binary).sum())
188        if union == 0:
189            return 0.0
190        return float(intersection / (union + 1e-8))

251    @staticmethod
252    def calculate_dice_coefficient(
253        pred_mask: MaskArray,
254        gt_mask: MaskArray,
255        threshold: float = 0.5,
256        smooth: float = 1e-6,
257    ) -> MetricValue:
258        """Dice Coefficient / F1 Score для бинарной сегментации.
259
260        Формула:
261        ```
262        Dice = (2 * |A ∩ B| + smooth) / (|A| + |B| + smooth)
263        ```
264
265        Args:
266            pred_mask: Предсказанная маска.
267            gt_mask: Ground truth маска.
268            threshold: Порог для бинаризации.
269            smooth: Малое значение для избежания деления на ноль.
270
271        Returns:
272            float: Значение Dice coefficient в диапазоне [0, 1].
273        """
274        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
275            pred_mask, gt_mask, threshold
276        )
277        intersection: int = int(np.logical_and(pred_binary, gt_binary).sum())
278        dice: MetricValue = (2.0 * intersection + smooth) / (
279            int(pred_binary.sum()) + int(gt_binary.sum()) + smooth
280        )
281        return float(dice)

284    @staticmethod
285    def calculate_precision_recall(
286        pred_mask: MaskArray,
287        gt_mask: MaskArray,
288        threshold: float = 0.5,
289        verbose: bool = False,
290    ) -> Tuple[MetricValue, MetricValue]:
291        """Precision и Recall для бинарной сегментации.
292
293        Формулы:
294        ```
295        Precision = TP / (TP + FP)
296        Recall    = TP / (TP + FN)
297        ```
298
299        Args:
300            pred_mask: Предсказанная маска.
301            gt_mask: Ground truth маска.
302            threshold: Порог для бинаризации.
303            verbose: Если `True`, выводит сравнение sklearn vs custom.
304
305        Returns:
306            Tuple[float, float]: (precision, recall) в диапазоне [0, 1].
307        """
308        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
309            pred_mask, gt_mask, threshold
310        )
311
312        # Sklearn (Эталон)
313        p_sklearn: MetricValue = precision_score(
314            gt_binary.ravel(), pred_binary.ravel(), zero_division=0
315        )
316        r_sklearn: MetricValue = recall_score(
317            gt_binary.ravel(), pred_binary.ravel(), zero_division=0
318        )
319
320        # Confusion matrix также требует 1D
321        tn, fp, fn, tp = confusion_matrix(
322            gt_binary.ravel(), pred_binary.ravel(), labels=[0, 1]
323        ).ravel()
324
325        p_custom: MetricValue = tp / (tp + fp + 1e-8)
326        r_custom: MetricValue = tp / (tp + fn + 1e-8)
327
328        if verbose:
329            logging.info("--- Сравнение Precision/Recall ---")
330            logging.info(f"TP: {tp}, FP: {fp}, FN: {fn}, TN: {tn}")
331            logging.info(
332                f"Precision: Sklearn={p_sklearn:.6f} | Custom={p_custom:.6f} | Diff={abs(p_sklearn - p_custom):.2e}"
333            )
334            logging.info(
335                f"Recall:    Sklearn={r_sklearn:.6f} | Custom={r_custom:.6f} | Diff={abs(r_sklearn - r_custom):.2e}"
336            )
337
338        return float(p_custom), float(r_custom)

341    @staticmethod
342    def calculate_f1_score(
343        pred_mask: MaskArray,
344        gt_mask: MaskArray,
345        threshold: float = 0.5,
346        verbose: bool = False,
347    ) -> MetricValue:
348        """F1 Score (среднее гармоническое precision и recall).
349
350        Формула:
351        ```
352        F1 = 2 * (Precision * Recall) / (Precision + Recall)
353        ```
354
355        Args:
356            pred_mask: Предсказанная маска.
357            gt_mask: Ground truth маска.
358            threshold: Порог для бинаризации.
359            verbose: Если `True`, выводит сравнение sklearn vs custom.
360
361        Returns:
362            float: Значение F1 Score в диапазоне [0, 1].
363        """
364        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
365            pred_mask, gt_mask, threshold
366        )
367        precision, recall = SegmentationMetrics.calculate_precision_recall(
368            pred_mask, gt_mask, threshold
369        )
370        if precision + recall == 0:
371            f1_custom: MetricValue = 0.0
372        else:
373            f1_custom = 2 * (precision * recall) / (precision + recall + 1e-8)
374
375        f1_sklearn: MetricValue = f1_score(gt_binary.ravel(), pred_binary.ravel())
376        if verbose:
377            logging.info(
378                f"F1-Score: Sklearn={f1_sklearn:.6f} | Custom={f1_custom:.6f} | Diff={abs(f1_sklearn - f1_custom):.2e}"
379            )
380        return float(f1_custom)

410            gt_norm = (
411                gt_mask.astype(np.float32) / 255.0
412                if gt_mask.max() > 1
413                else gt_mask.astype(np.float32)
414            )
415        else:

417            gt_norm = gt_mask.astype(np.float32)
418
419        # Кастомный
420        mae_custom: MetricValue = np.abs(pred_norm - gt_norm).mean()
421
422        # Sklearn
423        if verbose:
424            mae_sklearn: MetricValue = mean_absolute_error(gt_norm, pred_norm)
425            logging.info(
426                f"MAE: Sklearn={mae_sklearn:.6f} | Custom={mae_custom:.6f} | Diff={abs(mae_sklearn - mae_custom):.2e}"
427            )

431    @staticmethod
432    def calculate_hausdorff_distance(
433        pred_mask: MaskArray,
434        gt_mask: MaskArray,
435        threshold: float = 0.5,
436    ) -> MetricValue:
437        """Hausdorff Distance (Расстояние Хаусдорфа) между контурами масок.
438
439        Вычисляется как максимум из двух направленных расстояний:
440        ```
441        H(A, B) = max( h(A→B), h(B→A) )
442        ```
443
444        Args:
445            pred_mask: Предсказанная маска.
446            gt_mask: Ground truth маска.
447            threshold: Порог для бинаризации.
448
449        Returns:
450            float: Значение расстояния Хаусдорфа (в пикселях) или `inf` при ошибке.
451        """
452        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
453            pred_mask, gt_mask, threshold
454        )
455
456        # Получаем координаты точек контуров
457        pred_coords: np.ndarray = np.column_stack(np.where(pred_binary))
458        gt_coords: np.ndarray = np.column_stack(np.where(gt_binary))
459
460        # Если один из контуров пустой, возвращаем бесконечность
461        if len(pred_coords) == 0 or len(gt_coords) == 0:
462            return float("inf")
463
464        try:
465            # Вычисляем двунаправленное расстояние Хаусдорфа

161    def calculate_iou(
162        pred_mask: MaskArray,
163        gt_mask: MaskArray,
164        threshold: float = 0.5,
165    ) -> MetricValue:
166        """Intersection over Union (IoU) / Jaccard Index.
167

169        ```
170        IoU = |A ∩ B| / |A ∪ B|
171        ```
172
173        Args:
174            pred_mask: Предсказанная маска (0–1 или 0–255).
175            gt_mask: Ground truth маска.
176            threshold: Порог для бинаризации.
177
178        Returns:
179            float: Значение IoU в диапазоне [0, 1].
180        """
181        # Нормализуем маски к бинарному формату 0/1
182        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
183            pred_mask, gt_mask, threshold
184        )
185
186        # Вычисляем пересечение и объединение
187        intersection: int = int(np.logical_and(pred_binary, gt_binary).sum())
188        union: int = int(np.logical_or(pred_binary, gt_binary).sum())
189        if union == 0:
190            return 0.0
191        return float(intersection / (union + 1e-8))

433    def calculate_hausdorff_distance(
434        pred_mask: MaskArray,
435        gt_mask: MaskArray,
436        threshold: float = 0.5,
437    ) -> MetricValue:
438        """Hausdorff Distance (Расстояние Хаусдорфа) между контурами масок.
439
440        Вычисляется как максимум из двух направленных расстояний:
441        ```
442        H(A, B) = max( h(A→B), h(B→A) )
443        ```
444
445        Args:
446            pred_mask: Предсказанная маска.
447            gt_mask: Ground truth маска.
448            threshold: Порог для бинаризации.
449
450        Returns:
451            float: Значение расстояния Хаусдорфа (в пикселях) или `inf` при ошибке.
452        """
453        pred_binary, gt_binary = SegmentationMetrics._normalize_masks(
454            pred_mask, gt_mask, threshold
455        )
456
457        # Получаем координаты точек контуров
458        pred_coords: np.ndarray = np.column_stack(np.where(pred_binary))
459        gt_coords: np.ndarray = np.column_stack(np.where(gt_binary))
460
461        # Если один из контуров пустой, возвращаем бесконечность
462        if len(pred_coords) == 0 or len(gt_coords) == 0:
463            return float("inf")
464
465        try:
466            # Вычисляем двунаправленное расстояние Хаусдорфа
467            h1: MetricValue = directed_hausdorff(pred_coords, gt_coords)[0]
468            h2: MetricValue = directed_hausdorff(gt_coords, pred_coords)[0]
469            hausdorff_dist = max(h1, h2)
470        except ValueError:
471            hausdorff_dist = float("inf")
472        return float(hausdorff_dist)

752                    if _need("false_negative"):
753                        metrics["false_negative"] = int(fn)
754                    if _need("true_positive"):
755                        metrics["true_positive"] = int(tp)
756                except ValueError as e:
757                    warnings.warn(f"Не удалось вычислить матрицу ошибок: {e}")
758                    for m in cm_metrics:
759                        if _need(m):
760                            metrics[m] = 0
761
762        return metrics
