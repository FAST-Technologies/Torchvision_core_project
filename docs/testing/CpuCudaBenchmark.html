testing.CpuCudaBenchmark

Модуль для бенчмаркинга производительности и стабильности методов сегментации на CPU и CUDA.

Предназначен для автоматизированного сравнения времени выполнения, ускорения (speedup) и стабильности алгоритмов сегментации при запуске на разных устройствах и бэкендах:

  • Устройства: CPU, CUDA (GPU)
  • Бэкенды: PyTorch, OpenCV, Scikit-learn, ONNX, TensorRT
  • Точности: fp32, fp16, bf16

Основные возможности:

  • Точный тайминг с time.perf_counter() и обязательной torch.cuda.synchronize() для GPU
  • Warm-up прогоны для стабилизации производительности (избегает искажений из-за ленивой инициализации CUDA)
  • Автоматическое переключение устройства сегментера (.device, .model.to())
  • Устойчивость к ошибкам: падение одного метода не останавливает весь бенчмарк
  • Сохранение артефактов: результат сегментации, бинарная маска, overlay-визуализация
  • Экспорт результатов: CSV, Excel (с автоформатированием), текстовый отчёт со сводкой
  • Генерация визуализаций: сравнительные гистограммы, графики ускорения, scatter-plot зависимости

Примечание:

  • Имена методов ожидаются в формате: {base_method}_{backend}_{precision} (например, otsu_thresholding_ONNX_fp16, canny_edge_CV2_fp32).
  • Для корректного переключения устройства сегментер должен иметь атрибут .device типа torch.device.
  • Бенчмарк не оценивает качество сегментации — только производительность. Для валидации качества используйте BatchClassicTester2 или SegmentationMetrics.

  65

  81    1. Инициализация параметров (кол-во прогонов, warm-up, директория вывода).
  82    2. Для каждого метода: переключение устройства → warm-up → N запусков с замером → статистика.
  83    3. Агрегация результатов, расчёт ускорения CUDA/CPU.

 109    @staticmethod
 110    def _parse_method_info(method_name: str) -> Dict[str, str]:
 111        """Парсит имя метода вида 'otsu_thresholding_ONNX_fp32' в компоненты."""
 112        parts: List[str] = method_name.split("_")
 113        precision: str = parts[-1].lower()
 114        if precision in ["fp32", "fp16", "bf16"] and len(parts) >= 3:
 115            backend_raw: str = parts[-2]
 116            base_method: str = "_".join(parts[:-2])
 117        else:
 118            # Fallback: Otsu_Thresholding_CV2 -> base=Otsu_Thresholding, backend=CV2, precision=fp32
 119            precision = "fp32"
 120            last: str = parts[-1].upper()
 121            # Убираем суффиксы версий
 122            if last in ["V1", "V2", "V3"]:
 123                backend_raw = parts[-2].upper()
 124                base_method = "_".join(parts[:-2])
 125            else:
 126                backend_raw = last
 127                base_method = "_".join(parts[:-1])
 128        if "TORCH" in backend_raw or backend_raw in ["PYTORCH", "NEURAL"]:
 129            backend = "PyTorch"
 130        elif "CV2" in backend_raw or "OPENCV" in backend_raw:
 131            backend = "CV2"
 132        elif "SKLEARN" in backend_raw:
 133            backend = "Sklearn"
 134        elif "ONNX" in backend_raw:
 135            backend = "ONNX"
 136        elif "TRT" in backend_raw or "TENSORRT" in backend_raw:
 137            backend = "TRT"
 138        else:
 139            backend = "PyTorch"  # Дефолт
 140        return {"base_method": base_method, "backend": backend, "precision": precision}

 142    # ──────────────────────────────────────────────────────────────────────
 143    def benchmark_method(
 144        self,
 145        segmenter: Any,
 146        image: np.ndarray,
 147        method_name: str,
 148        device: str = "cpu",
 149        save_artifacts: bool = True,
 150        output_dir: Optional[str] = None,
 151    ) -> Dict[str, Any]:
 152        """Выполняет точный замер времени выполнения одного метода сегментации на указанном устройстве.
 153
 154        Логика:
 155        - Временно переключает `.device` сегментера (и `.model`, если присутствует) на целевое.
 156        - Выполняет `warmup_runs` прогонов без замера.
 157        - Выполняет `n_runs` прогонов с принудительной синхронизацией CUDA (если `device="cuda"`).
 158        - Восстанавливает исходное устройство сегментера.
 159        - Сохраняет результат сегментации, маску и overlay (если save_artifacts=True).
 160        - При исключениях пропускает прогон, но продолжает цикл.
 161
 162        Args:
 163            segmenter: Объект-сегментер, реализующий метод `.segment(image)`.
 164                Ожидается атрибут `.device` типа `torch.device` для динамического переключения.
 165            image: Входное изображение в формате `np.ndarray` (любой формы/канальности).
 166            method_name: Уникальное имя метода для логирования и маркировки результатов.
 167            device: Целевое устройство выполнения (`"cpu"` или `"cuda"`).
 168            save_artifacts: Если True, сохранять результат, маску и overlay после сегментации.
 169            output_dir: Директория для сохранения артефактов. Если None, используется временная.
 170
 171        Returns:
 172            Словарь со статистикой производительности:
 173            - `method`, `device`: Идентификаторы теста.
 174            - `mean_time`, `std_time`, `min_time`, `max_time`: Статистика времени (в секундах).
 175            - `total_time`: Общее время замера, включая накладные расходы Python.
 176            - `n_runs`: Фактическое количество успешных прогонов.
 177            - `error`: Строка с описанием ошибки, если ни один прогон не выполнился успешно.
 178        """
 179        times: List[float] = []
 180        last_result: Optional[np.ndarray] = None
 181        last_mask: Optional[np.ndarray] = None
 182
 183        # Переключение устройства для Torch-сегментеров
 184        original_device = None
 185        info: Dict[str, str] = self._parse_method_info(method_name)
 186        if hasattr(segmenter, "device") and isinstance(segmenter.device, torch.device):
 187            original_device = segmenter.device
 188            segmenter.device = torch.device(device)
 189            if hasattr(segmenter, "model") and segmenter.model is not None:
 190                try:
 191                    segmenter.model = segmenter.model.to(device)
 192                except Exception:
 193                    pass
 194
 195        # Warm-up
 196        actual_warmup: int = max(
 197            self.warmup_runs,
 198            5 if getattr(segmenter, "use_compile", False) else self.warmup_runs,
 199        )
 200        for _ in range(actual_warmup):
 201            try:
 202                segmenter.segment(image)
 203            except Exception:
 204                pass
 205
 206        # Основное тестирование
 207        (
 208            torch.cuda.synchronize()
 209            if device == "cuda" and torch.cuda.is_available()
 210            else None
 211        )
 212        start_total: float = time.perf_counter()
 213
 214        for run in range(self.n_runs):
 215            try:
 216                if device == "cuda":
 217                    torch.cuda.synchronize()
 218                start: float = time.perf_counter()
 219                if hasattr(segmenter, "segment_with_mask"):
 220                    result_opt, mask_opt = segmenter.segment_with_mask(image)
 221                    result = (
 222                        result_opt
 223                        if result_opt is not None
 224                        else segmenter.segment(image)
 225                    )
 226                    mask = mask_opt if mask_opt is not None else result
 227                else:
 228                    result = segmenter.segment(image)
 229                    mask = result
 230                if device == "cuda":
 231                    torch.cuda.synchronize()
 232                end: float = time.perf_counter()
 233                times.append(end - start)
 234                if run == 0 and save_artifacts:
 235                    last_result = result
 236                    last_mask = mask
 237            except Exception as e:
 238                print(f"⚠️ Error in {method_name} ({device}), run {run + 1}: {e}")
 239                break
 240
 241        (
 242            torch.cuda.synchronize()
 243            if device == "cuda" and torch.cuda.is_available()
 244            else None
 245        )
 246        end_total: float = time.perf_counter()
 247
 248        artifact_paths: Dict[str, Optional[str]] = {
 249            "result": None,
 250            "mask": None,
 251            "overlay": None,
 252        }
 253
 254        if save_artifacts and last_result is not None and output_dir:
 255            try:
 256                os.makedirs(output_dir, exist_ok=True)
 257
 258                # Конвертация результата в изображение
 259                result_to_save: np.ndarray = last_result
 260                if isinstance(result_to_save, torch.Tensor):
 261                    result_to_save = result_to_save.cpu().numpy()
 262                if result_to_save.ndim == 2:
 263                    result_pil = Image.fromarray(result_to_save.astype(np.uint8))
 264                elif result_to_save.ndim == 3 and result_to_save.shape[0] in [1, 3]:
 265                    # (C, H, W) -> (H, W, C)
 266                    result_to_save = np.transpose(result_to_save, (1, 2, 0))
 267                    result_pil = Image.fromarray(result_to_save.astype(np.uint8))
 268                else:
 269                    result_pil = Image.fromarray(result_to_save.astype(np.uint8))
 270
 271                # Сохранение результата
 272                result_path: str = os.path.join(
 273                    output_dir, f"{method_name}_{device}_result.jpg"
 274                )
 275                result_pil.save(result_path)
 276                artifact_paths["result"] = result_path
 277
 278                # Сохранение маски
 279                if last_mask is not None:
 280                    mask_to_save: np.ndarray = last_mask
 281                    if isinstance(mask_to_save, torch.Tensor):
 282                        mask_to_save = mask_to_save.cpu().numpy()
 283                    if mask_to_save.max() <= 1.0:
 284                        mask_to_save = (mask_to_save * 255).astype(np.uint8)
 285                    else:
 286                        mask_to_save = mask_to_save.astype(np.uint8)
 287
 288                    mask_path: str = os.path.join(
 289                        output_dir, f"{method_name}_{device}_mask.png"
 290                    )
 291                    Image.fromarray(mask_to_save).save(mask_path)
 292                    artifact_paths["mask"] = mask_path
 293
 294                    # Создание overlay (оригинал + результат)
 295                    if isinstance(image, np.ndarray):
 296                        orig_to_save: np.ndarray = image
 297                        if orig_to_save.ndim == 2:
 298                            orig_rgb: np.ndarray = np.stack([orig_to_save] * 3, axis=-1)
 299                        else:
 300                            orig_rgb = orig_to_save
 301
 302                        # Приводим результат к 3 каналам если нужно
 303                        if result_to_save.ndim == 2:
 304                            result_rgb: np.ndarray = np.stack(
 305                                [result_to_save] * 3, axis=-1
 306                            )
 307                        else:
 308                            result_rgb = result_to_save
 309
 310                        # Alpha-смешивание: 30% оригинал + 70% результат
 311                        overlay: np.ndarray = (
 312                            orig_rgb * 0.3 + result_rgb * 0.7
 313                        ).astype(np.uint8)
 314                        overlay_path: str = os.path.join(
 315                            output_dir, f"{method_name}_{device}_overlay.jpg"
 316                        )
 317                        Image.fromarray(overlay).save(overlay_path)
 318                        artifact_paths["overlay"] = overlay_path
 319
 320            except Exception as e:
 321                print(f"⚠️ Ошибка сохранения артефактов для {method_name}: {e}")
 322
 323        # Восстановление оригинального устройства
 324        if original_device is not None:
 325            segmenter.device = original_device
 326            if hasattr(segmenter, "model") and segmenter.model is not None:
 327                try:
 328                    segmenter.model = segmenter.model.to(original_device)
 329                except Exception:
 330                    pass
 331
 332        if device == "cuda" and torch.cuda.is_available():
 333            torch.cuda.empty_cache()
 334            torch.cuda.synchronize()
 335            import gc
 336
 337            gc.collect()
 338
 339        if not times:
 340            return {
 341                "method": method_name,
 342                "device": device,
 343                "error": "Failed/Skipped",
 344                "mean_time": float("inf"),
 345                "std_time": 0.0,
 346                "min_time": float("inf"),
 347                "max_time": float("inf"),
 348                "total_time": end_total - start_total,
 349                "n_runs": 0,
 350                "artifact_paths": artifact_paths,
 351                **info,
 352            }
 353
 354        return {
 355            "method": method_name,
 356            "device": device,
 357            "error": None,
 358            "mean_time": np.mean(times),
 359            "std_time": np.std(times),
 360            "min_time": np.min(times),
 361            "max_time": np.max(times),
 362            "total_time": end_total - start_total,
 363            "n_runs": len(times),
 364            "artifact_paths": artifact_paths,
 365            **info,
 366        }

 369    def benchmark_all_methods(
 370        self,
 371        methods_dict: Dict[str, Any],
 372        image: np.ndarray,
 373        test_name: str = "multi_backend_comparison",
 374        save_artifacts: bool = True,
 375        artifact_base_dir: Optional[str] = None,
 376    ) -> pd.DataFrame:
 377        """Запускает полный цикл бенчмарка для набора методов на CPU и (опционально) CUDA.
 378
 379        Для каждого метода последовательно выполняет замеры на CPU и GPU,
 380        рассчитывает ускорение (speedup), выводит прогресс в консоль,
 381        сохраняет результаты и генерирует графики.
 382
 383        Args:
 384            methods_dict: Словарь `{имя_метода: экземпляр_сегментера}`.
 385            image: Тестовое изображение для всех методов.
 386            test_name: Префикс имени эксперимента для организации выходных файлов.
 387
 388        Returns:
 389            `pd.DataFrame` с агрегированными метриками производительности.
 390        """
 391        all_results: List = []
 392        devices = ["cpu"]
 393        if torch.cuda.is_available():
 394            devices.append("cuda")
 395
 396        print("\n" + "=" * 80)
 397        print("🚀 БЕНЧМАРК: MULTI-BACKEND (CPU vs CUDA)")
 398        print("=" * 80)
 399        print(f"Количество методов: {len(methods_dict)}")
 400        print(f"Количество прогонов: {self.n_runs}")
 401        print(f"Warm-up прогонов: {self.warmup_runs}")
 402        print(f"Устройства: {', '.join(devices)}")
 403        print(f"Сохранение артефактов: {'✅ ВКЛ' if save_artifacts else '❌ ВЫКЛ'}")
 404        print("=" * 80)
 405
 406        # Сохраняем результаты
 407        timestamp: str = datetime.now().strftime("%Y%m%d_%H%M%S")
 408        output_dir: str = os.path.join(self.base_output_dir, f"{test_name}_{timestamp}")
 409        if artifact_base_dir is None and save_artifacts:
 410            artifact_base_dir = os.path.join(output_dir, "artifacts")
 411
 412        # Создаём директорию для артефактов заранее
 413        if save_artifacts and artifact_base_dir:
 414            os.makedirs(artifact_base_dir, exist_ok=True)
 415
 416        for method_name, segmenter in methods_dict.items():
 417            print(f"\n🔹 Метод: {method_name}")
 418            for device in devices:
 419                if save_artifacts and artifact_base_dir:
 420                    method_artifact_dir: str = os.path.join(
 421                        artifact_base_dir, device, method_name
 422                    )
 423                    os.makedirs(method_artifact_dir, exist_ok=True)
 424
 425                if device == "cuda":
 426                    print(f"   📊 Тестирование на {device.upper()}...")
 427                    if torch.cuda.is_available():
 428                        res: Dict[str, Any] = self.benchmark_method(
 429                            segmenter,
 430                            image,
 431                            method_name,
 432                            device,
 433                            save_artifacts=save_artifacts,
 434                            output_dir=method_artifact_dir,
 435                        )
 436                    else:
 437                        res = {"error": "Skipped (No CUDA)"}
 438                else:
