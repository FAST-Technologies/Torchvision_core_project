testing.SegmentationComparator

Модуль для сравнительного тестирования и валидации сегментационных методов.

Предназначен для автоматизированного попарного, пакетного и матричного сравнения реализаций алгоритмов сегментации (классических и нейросетевых) с использованием единого модуля метрик SegmentationMetrics для обеспечения консистентности расчётов.

Основные возможности:

  • 🔍 Попарное сравнение: Запуск двух сегментеров на одном изображении с расчётом метрик сходства (IoU, Dice, F1, Precision, Recall, Hausdorff) и визуализацией разницы.
  • 📦 Пакетное тестирование: Сравнение множества методов против референсного алгоритма с агрегацией результатов в DataFrame и генерацией сводных графиков.
  • 🔗 Матричное сравнение: Режимы "all-vs-all", "all-vs-ref", "pairwise" с генерацией тепловых карт (heatmaps) для каждой метрики и интерактивного HTML-отчёта.
  • 🎨 Визуализация: 2×4 grid с оригиналом, масками, оверлеями, heatmap разницы и текстовыми метриками.
  • 💾 Экспорт артефактов: Сохранение масок (PNG), оверлеев, CSV-таблиц, JSON-деталей, HTML-отчётов.
  • ⚡ Управление памятью: Синхронизация CUDA, замер времени через time.perf_counter().

Особенности:

  • Использует общий SegmentationMetrics для консистентности с другими модулями проекта.
  • Автоматическая бинаризация масок (порог 127/0.5) перед сравнением.
  • Поддержка любых объектов с методом .segment(image) -> np.ndarray (OpenCV, Torch, Sklearn сегментеры).
  • Устойчивость к ошибкам: исключения в отдельных методах логируются, но не прерывают пакетное выполнение.

Примечание:

  • Для валидации качества относительно Ground Truth используйте BatchClassicTester2.
  • Для проверки консистентности реализаций между библиотеками — BatchClassicTester.
  • Данный модуль фокусируется на сравнении методов между собой, а не на оценке против эталона.

 107    def compute_metrics(
 108        self,
 109        mask1: MaskArray,
 110        mask2: MaskArray,
 111        method1_name: Optional[str] = "Method1",
 112        method2_name: Optional[str] = "Method2",
 113    ) -> Dict[str, float]:
 114        """Вычисляет полный набор метрик сходства между двумя бинарными масками.
 115
 116        Использует общий модуль `SegmentationMetrics.calculate_all_metrics` для
 117        консистентности с другими компонентами библиотеки.
 118
 119        Args:
 120            mask1: Первая бинарная маска (предсказание или референс).
 121            mask2: Вторая бинарная маска для сравнения.
 122            method1_name: Идентификатор первого метода (для логирования).
 123            method2_name: Идентификатор второго метода.
 124
 125        Returns:
 126            Dict[str, float]: Словарь с метриками:
 127            - Качество: `accuracy`, `precision`, `recall`, `f1_score`, `jaccard` (IoU), `dice_coefficient`
 128            - Площади: `area1`, `area2`, `area_difference`, `area_ratio`
 129            - Граничные: `hausdorff_distance`
 130            - Конфузионная матрица: `true_positive`, `false_positive`, `false_negative`, `true_negative`
 131
 132        Note:
 133            - Входные маски автоматически бинаризуются (порог 0.5 внутри SegmentationMetrics).
 134            - Если маски разного размера, метрики могут быть некорректны — ответственность на вызывающем коде.
 135        """
 136        # Бинаризируем маски
 137        raw_metrics: MetricDict = SegmentationMetrics.calculate_all_metrics(
 138            pred_mask=mask1, gt_mask=mask2, threshold=0.5, include_hausdorff=True
 139        )
 140
 141        metrics: MetricDict = {
 142            # Основные метрики качества
 143            "accuracy": raw_metrics.get("pixel_accuracy", 0.0),
 144            "precision": raw_metrics.get("precision", 0.0),
 145            "recall": raw_metrics.get("recall", 0.0),
 146            "f1_score": raw_metrics.get("f1_score", 0.0),
 147            "jaccard": raw_metrics.get("iou", 0.0),
 148            "dice_coefficient": raw_metrics.get("dice", 0.0),
 149            "intersection_over_union": raw_metrics.get("iou", 0.0),
 150            "pixel_agreement": raw_metrics.get("pixel_accuracy", 0.0),
 151            # Площади и статистика
 152            "area1": float(raw_metrics.get("predicted_area", 0.0)),
 153            "area2": float(raw_metrics.get("ground_truth_area", 0.0)),
 154            "area_difference": float(raw_metrics.get("area_difference", 0.0)),
 155            "area_ratio": float(raw_metrics.get("area_ratio", 0.0)),
 156            # Граничные метрики
 157            "hausdorff_distance": float(raw_metrics.get("hausdorff_distance", 0.0)),
 158            # Конфузионная матрица
 159            "true_positive": int(raw_metrics.get("true_positive", 0)),
 160            "false_positive": int(raw_metrics.get("false_positive", 0)),
 161            "false_negative": int(raw_metrics.get("false_negative", 0)),
 162            "true_negative": int(raw_metrics.get("true_negative", 0)),
 163        }
 164        return metrics

 168    # ──────────────────────────────────────────────────────────────────────
 169    def compare_methods(
 170        self,
 171        image: ImageArray,
 172        segmenter1: SegmenterLike,
 173        segmenter2: SegmenterLike,
 174        name1: Optional[str] = None,
 175        name2: Optional[str] = None,
 176        save_comparison: bool = True,
 177        output_path: Optional[str] = None,
 178    ) -> Dict[str, Any]:
 179        """Выполняет попарное сравнение двух сегментаторов на одном изображении.
 180
 181        Args:
 182            image: Входное изображение (HxW или HxWxC, np.ndarray).
 183            segmenter1: Первый сегментер с методом `.segment(image) -> MaskArray`.
 184            segmenter2: Второй сегментер.
 185            name1: Человекочитаемое имя первого метода. Если `None`, берётся из `segmenter.method`.
 186            name2: Имя второго метода.
 187            save_comparison: Если `True`, сохраняет визуализацию сравнения.
 188            output_path: Путь для сохранения изображения (если `save_comparison=True`).
 189
 190        Returns:
 191            Dict[str, Any]: Результаты сравнения:
 192            - `mask1`, `mask2`: Сгенерированные бинарные маски.
 193            - `info1`, `info2`: Словари с `execution_time` и `method`.
 194            - `metrics`: Словарь метрик из `compute_metrics()`.
 195
 196        Raises:
 197            RuntimeError: Если один из сегментеров выбрасывает исключение при инференсе.
 198        """
 199        m1_name: Optional[str] = name1 or getattr(segmenter1, "method", "Method1")
 200        m2_name: Optional[str] = name2 or getattr(segmenter2, "method", "Method2")
 201
 202        # Инференс первого метода
 203        if str(self.device) == "cuda":
 204            torch.cuda.synchronize()
 205        start_time_1: float = time.perf_counter()
 206        mask1: MaskArray = segmenter1.segment(image)
 207        if str(self.device) == "cuda":
 208            torch.cuda.synchronize()
 209        time_1: float = time.perf_counter() - start_time_1
 210        info1: Dict[str, Any] = {"execution_time": time_1, "method": m1_name}
 211
 212        # Инференс второго метода
 213        if str(self.device) == "cuda":
 214            torch.cuda.synchronize()
 215        start_time_2: float = time.perf_counter()
 216        mask2: MaskArray = segmenter2.segment(image)
 217        if str(self.device) == "cuda":
 218            torch.cuda.synchronize()
 219        time_2: float = time.perf_counter() - start_time_2
 220        info2: Dict[str, Any] = {"execution_time": time_2, "method": m2_name}
 221
 222        # Расчёт метрик
 223        metrics: MetricDict = self.compute_metrics(mask1, mask2, m1_name, m2_name)
 224
 225        # Сохранение в кэш
 226        result_key: str = f"{m1_name}_vs_{m2_name}"
 227        self.results[result_key] = {
 228            "mask1": mask1,
 229            "mask2": mask2,
 230            "info1": info1,
 231            "info2": info2,
 232            "metrics": metrics,
 233        }
 234
 235        if save_comparison:
 236            self.visualize_comparison(
 237                image,
 238                mask1,
 239                mask2,
 240                info1,
 241                info2,
 242                metrics,
 243                method1_name=m1_name,
 244                method2_name=m2_name,
 245                output_path=output_path,
 246            )
 247        return self.results[result_key]

 250    def visualize_comparison(
 251        self,
 252        image: ImageArray,
 253        mask1: MaskArray,
 254        mask2: MaskArray,
 255        info1: Dict[str, Any],
 256        info2: Dict[str, Any],
 257        metrics: MetricDict,
 258        method1_name: Optional[str] = "Method 1",
 259        method2_name: Optional[str] = "Method 2",
 260        output_path: Optional[PathLike] = None,
 261    ) -> None:
 262        """Строит 2×4 grid с визуализацией сравнения двух методов сегментации.
 263
 264        Макет:
 265        [0,0] Original | [0,1] Mask1 | [0,2] Mask2 | [0,3] Difference
 266        [1,0] Overlay1 | [1,1] Overlay2 | [1,2] Combined | [1,3] Metrics text
 267
 268        Args:
 269            image: Исходное изображение.
 270            mask1: Бинарные маски для визуализации 1.
 271            mask2: Бинарные маски для визуализации 2.
 272            info1: Словари с временем выполнения и именами методов 1.
 273            info2: Словари с временем выполнения и именами методов 2.
 274            metrics: Словарь метрик для отображения в тексте.
 275            method1_name: Подписи методов 1.
 276            method2_name: Подписи методов 2.
 277            output_path: Если указан, сохраняет фигуру в файл.
 278        """
 279        fig, axes = plt.subplots(2, 4, figsize=(20, 10))
 280
 281        if len(image.shape) == 2:
 282            axes[0, 0].imshow(image, cmap="gray")
 283        else:
 284            axes[0, 0].imshow(image)
 285        axes[0, 0].set_title("Original Image")
 286        axes[0, 0].axis("off")
 287
 288        axes[0, 1].imshow(mask1, cmap="gray")
 289        time1 = info1.get("execution_time", 0)
 290        axes[0, 1].set_title(f"{method1_name}\nTime: {time1:.3f}s")
 291        axes[0, 1].axis("off")
 292
 293        axes[0, 2].imshow(mask2, cmap="gray")
 294        time2 = info2.get("execution_time", 0)
 295        axes[0, 2].set_title(f"{method2_name}\nTime: {time2:.3f}s")
 296        axes[0, 2].axis("off")
 297
 298        # Разность масок
 299        diff: np.ndarray = np.abs(mask1.astype(float) - mask2.astype(float))
 300        axes[0, 3].imshow(diff, cmap="hot")
 301        axes[0, 3].set_title("Difference")
 302        axes[0, 3].axis("off")
 303
 304        # Наложение масок на изображение
 305        if len(image.shape) == 2:
 306            overlay1 = np.stack([image] * 3, axis=-1)
 307            overlay2 = np.stack([image] * 3, axis=-1)
 308        else:
 309            overlay1 = image.copy()
 310            overlay2 = image.copy()
 311
 312        overlay1[mask1 > 127] = [255, 0, 0]  # Красный
 313        overlay2[mask2 > 127] = [0, 255, 0]  # Зеленый
 314
 315        axes[1, 0].imshow(overlay1)
 316        axes[1, 0].set_title(f"{method1_name} Overlay")
 317        axes[1, 0].axis("off")
 318
 319        axes[1, 1].imshow(overlay2)
 320        axes[1, 1].set_title(f"{method2_name} Overlay")
 321        axes[1, 1].axis("off")
 322
 323        # Комбинированное наложение
 324        combined: Union[ImageArray | np.ndarray] = (
 325            image.copy() if len(image.shape) == 3 else np.stack([image] * 3, axis=-1)
 326        )
 327        combined[mask1 > 127] = [255, 0, 0]
 328        combined[mask2 > 127] = [0, 255, 0]
 329
 330        # Желтый для пересечения
 331        intersection: np.ndarray = (mask1 > 127) & (mask2 > 127)
 332        combined[intersection] = [255, 255, 0]
 333
 334        axes[1, 2].imshow(combined)
 335        axes[1, 2].set_title(
 336            "Combined Overlay\n(Red: Method1, Green: Method2, Yellow: Both)"
 337        )
 338        axes[1, 2].axis("off")
 339
 340        # Текстовые метрики
 341        axes[1, 3].axis("off")
 342        text_str: str = (
 343            f"Metrics Comparison:\n"
 344            f"IoU (Jaccard): {metrics.get('jaccard', 0):.3f}\n"
 345            f"Dice Coeff:    {metrics.get('dice_coefficient', 0):.3f}\n"
 346            f"F1-Score:      {metrics.get('f1_score', 0):.3f}\n"
 347            f"Accuracy:      {metrics.get('accuracy', 0):.3f}\n"
 348            f"Precision:     {metrics.get('precision', 0):.3f}\n"
 349            f"Recall:        {metrics.get('recall', 0):.3f}\n"
 350            f"Hausdorff:     {metrics.get('hausdorff_distance', 0):.2f}\n"
 351            f"Area Diff:     {metrics.get('area_difference', 0):.0f}"
 352        )
 353        axes[1, 3].text(
 354            0.1,
 355            0.6,
 356            text_str,
 357            fontsize=10,
 358            verticalalignment="center",
 359            transform=axes[1, 3].transAxes,
 360        )
 361
 362        plt.suptitle(
 363            f"Segmentation Methods Comparison: {method1_name} vs {method2_name}",
 364            fontsize=14,
 365        )
 366        plt.tight_layout()
 367        if output_path:
 368            plt.savefig(output_path, dpi=150, bbox_inches="tight")
 369            print(f"✅ Визуализация сохранена: {output_path}")
 370        plt.show()

 375    def batch_comparison(
 376        self,
 377        image: ImageArray,
 378        methods_config: List[Dict[str, Any]],
 379        reference_segmenter: SegmenterLike,
 380        reference_name: Optional[str] = None,
 381        save_results: bool = True,
 382        output_dir: PathLike = "./data/comparison_results",
 383    ) -> pd.DataFrame:
 384        """Пакетное сравнение нескольких методов с референсным сегментером.
 385
 386        Для каждого метода из `methods_config`:
 387        1. Выполняет инференс и замер времени.
 388        2. Считает метрики против референсной маски.
 389        3. Сохраняет визуализацию и агрегирует результаты в DataFrame.
 390
 391        Args:
 392            image: Входное изображение.
 393            methods_config: Список конфигураций `{"name": str, "segmenter": obj}`.
 394            reference_segmenter: Референсный сегментер для сравнения.
 395            reference_name: Имя референсного метода (опционально).
 396            save_results: Если `True`, сохраняет визуализации и CSV.
 397            output_dir: Директория для сохранения артефактов.
 398
 399        Returns:
 400            pd.DataFrame: Таблица с метриками для каждого метода.

 404            os.makedirs(output_dir, exist_ok=True)
 405
 406        ref_name: Union[str | Any | None] = reference_name or getattr(
 407            reference_segmenter, "method", "Reference"
 408        )
 409        if str(self.device) == "cuda":
 410            torch.cuda.synchronize()
 411        start_time_ref: float = time.perf_counter()
 412        ref_mask: MaskArray = reference_segmenter.segment(image)
 413        if str(self.device) == "cuda":
 414            torch.cuda.synchronize()
 415        ref_time: float = time.perf_counter() - start_time_ref
 416        ref_info: Dict[str, Any] = {"execution_time": ref_time, "method": ref_name}

 418        comparison_results: List[Dict[str, Any]] = []
 419
 420        for config in methods_config:

 422            method_name = config.get("name") or getattr(segmenter, "method", "Unknown")
 423            if segmenter is None:
 424                print(f"⚠️ Пропущен конфиг без сегментера: {config}")
 425                continue
 426            try:
 427                if str(self.device) == "cuda":
 428                    torch.cuda.synchronize()
 429                start_time_test: float = time.perf_counter()
 430                test_mask: MaskArray = segmenter.segment(image)
 431                if str(self.device) == "cuda":
 432                    torch.cuda.synchronize()
 433                test_time: float = time.perf_counter() - start_time_test
 434                test_info: Dict[str, Any] = {
 435                    "execution_time": test_time,
 436                    "method": method_name,
 437                }
 438
 439                # Вычисляем метрики
 440                metrics: Dict[str, float] = self.compute_metrics(
 441                    ref_mask, test_mask, f"Ref_{ref_name}", f"Test_{method_name}"
 442                )
 443
 444                # Сохраняем результаты
 445                result: Dict[str, Any] = {
 446                    "method": method_name,
 447                    **metrics,
 448                    "test_time": test_info.get("execution_time", 0),
 449                    "ref_time": ref_info.get("execution_time", 0),
 450                    "parameters": str(getattr(segmenter, "params", {})),
 451                }
 452
 453                comparison_results.append(result)
 454
 455                # Сохраняем визуализацию
 456                if save_results:
 457                    output_path: str = os.path.join(
 458                        output_dir, f"comparison_{method_name}.jpg"
 459                    )
 460                    self.visualize_comparison(
 461                        image,
 462                        ref_mask,
 463                        test_mask,
 464                        ref_info,
 465                        test_info,
 466                        metrics,
 467                        method1_name=f"Reference: {ref_name}",
 468                        method2_name=f"Test: {method_name}",
 469                        output_path=str(output_path),
 470                    )
 471
 472                print(
 473                    f"✅ Сравнение {method_name}: F1={metrics.get('f1_score', 0):.3f}, IoU={metrics.get('jaccard', 0):.3f}"
 474                )
 475
 476            except Exception as e:
 477                print(f"❌ Ошибка при тестировании {method_name}: {e}")
 478                traceback.print_exc()
 479                continue
 480
 481        df: pd.DataFrame = pd.DataFrame(comparison_results)
 482        if save_results and not df.empty:
 483            csv_path: str = os.path.join(output_dir, "comparison_results.csv")
 484            df.to_csv(csv_path, index=False)

 581    # МАТРИЧНОЕ СРАВНЕНИЕ
 582    # ──────────────────────────────────────────────────────────────────────
 583    def matrix_comparison(
 584        self,
 585        image: ImageArray,
 586        methods_config: List[Dict[str, Any]],
 587        reference_method: Optional[str] = None,
 588        comparison_type: str = "all_vs_all",
 589        save_results: bool = True,
 590        output_dir: PathLike = "./data/matrix_comparison_results",
 591    ) -> Dict[str, Any]:
 592        """Выполняет матричное сравнение всех методов между собой.
 593
 594        Поддерживаемые режимы:
 595        - `"all_vs_all"`: Каждая пара методов сравнивается (полная матрица N×N).
 596        - `"all_vs_ref"`: Все методы сравниваются с указанным `reference_method`.
 597        - `"pairwise"`: Только уникальные пары без повторений (комбинации).
 598
 599        Args:
 600            image: Входное изображение.
 601            methods_config: Список `{"name": str, "segmenter": obj}`.
 602            reference_method: Имя референсного метода (для режима `all_vs_ref`).
 603            comparison_type: Один из `["all_vs_all", "all_vs_ref", "pairwise"]`.
 604            save_results: Если `True`, сохраняет маски, визуализации, CSV и HTML-отчёт.
 605            output_dir: Базовая директория для сохранения артефактов.
 606
 607        Returns:
 608            Dict[str, Any]:
 609            - `df_comparisons`: DataFrame с попарными метриками.
 610            - `masks`: Dict `{method_name: MaskArray}`.
 611            - `execution_times`: Dict `{method_name: float}`.
 612            - `method_infos`: Доп. информация о методах.
 613        """
 614        if save_results:
 615            timestamp: str = datetime.now().strftime("%Y%m%d_%H%M%S")
 616            output_dir = os.path.join(output_dir, f"comparison_{timestamp}")
 617            os.makedirs(output_dir, exist_ok=True)
 618
 619        # Парсинг конфигураций
 620        method_names: List[str] = []
 621        segmenters_map: Dict[str, SegmenterLike] = (
 622            {}
 623        )  # Маппинг: Имя -> Объект сегментер
 624        for config in methods_config:
 625            name = config.get("name")
 626            segmenter = config.get("segmenter")
 627            if name is None or segmenter is None:
 628                print(f"⚠️ Пропущен конфиг без имени или сегментера: {config}")
 629                continue
 630            method_names.append(name)
 631            segmenters_map[name] = segmenter
 632
 633        print(f"Выполняем сегментацию {len(method_names)} методами...")
 634        masks: Dict[str, MaskArray] = {}
 635        execution_times: Dict[str, float] = {}
 636        method_infos: Dict[str, Any] = {}
 637
 638        for name in method_names:
 639            segmenter = segmenters_map[name]
 640            try:
 641                if str(self.device) == "cuda":
 642                    torch.cuda.synchronize()
 643                start_time: float = time.perf_counter()
 644                mask: MaskArray = segmenter.segment(image)
 645                if str(self.device) == "cuda":
 646                    torch.cuda.synchronize()
 647                exec_time: float = time.perf_counter() - start_time
 648
 649                masks[name] = mask
 650                execution_times[name] = exec_time
 651                method_infos[name] = {"execution_time": exec_time}
 652
 653                print(f"  ✅ {name}: {exec_time:.3f}s")
 654            except Exception as e:
 655                print(f"  ❌ {name}: {e}")
 656                import traceback
 657
 658                traceback.print_exc()
 659                h, w = image.shape[:2] if len(image.shape) >= 2 else (256, 256)
 660                masks[name] = np.zeros((h, w), dtype=np.uint8)
 661                execution_times[name] = 0
 662                method_infos[name] = {"error": str(e)}
 663
 664        if comparison_type == "all_vs_ref" and reference_method:
 665            comparison_pairs: List[Tuple[str, str]] = [
 666                (reference_method, other)
 667                for other in method_names
 668                if other != reference_method
 669            ]
 670            ref_name = reference_method
 671        elif comparison_type == "pairwise":
 672            comparison_pairs = list(itertools.combinations(method_names, 2))
 673            ref_name = None
 674        else:  # "all_vs_all"
 675            comparison_pairs = [(m1, m2) for m1 in method_names for m2 in method_names]
 676            ref_name = None
 677
 678        print(f"\nВыполняем сравнение {len(comparison_pairs)} пар...")
 679        comparison_results: List[Dict[str, Any]] = []
 680        for i, (method1, method2) in enumerate(comparison_pairs):
 681            if method1 not in masks or method2 not in masks:
 682                continue
 683            mask1: MaskArray = masks[method1]
 684            mask2: MaskArray = masks[method2]
 685            try:
 686                metrics: Dict[str, float] = self.compute_metrics(
 687                    mask1, mask2, method1, method2
 688                )
 689                result: Dict[str, Any] = {
 690                    "method1": method1,
 691                    "method2": method2,
 692                    **metrics,
 693                    "time1": execution_times.get(method1, 0),
 694                    "time2": execution_times.get(method2, 0),
 695                    "time_diff": abs(
 696                        execution_times.get(method1, 0)
 697                        - execution_times.get(method2, 0)
 698                    ),
 699                }
 700                comparison_results.append(result)
 701                if (i + 1) % 10 == 0:
 702                    print(f"  Обработано {i + 1}/{len(comparison_pairs)} пар...")
 703            except Exception as e:
 704                print(f"  Ошибка сравнения {method1} vs {method2}: {e}")
 705
 706        df_comparisons: pd.DataFrame = pd.DataFrame(comparison_results)
 707        if save_results:
 708            masks_dir: str = os.path.join(output_dir, "masks")
 709            os.makedirs(masks_dir, exist_ok=True)
 710            for name, mask in masks.items():
 711                mask_path: str = os.path.join(masks_dir, f"{name}_mask.png")
 712                plt.imsave(mask_path, mask, cmap="gray")
 713            images_dir: str = os.path.join(output_dir, "images")
 714            os.makedirs(images_dir, exist_ok=True)
 715
 716            if len(image.shape) == 2:
 717                plt.imsave(os.path.join(images_dir, "original.png"), image, cmap="gray")
 718            else:
 719                plt.imsave(os.path.join(images_dir, "original.png"), image)
 720            overlay: np.ndarray
 721            for name, mask in masks.items():
 722                if len(image.shape) == 2:
 723                    overlay = np.stack([image] * 3, axis=-1)
 724                else:
 725                    overlay = image.copy()
 726                overlay[mask > 127] = [255, 0, 0]
 727                overlay_path = os.path.join(images_dir, f"{name}_overlay.png")
 728                plt.imsave(overlay_path, overlay)
 729
 730            self._save_matrix_results(
 731                df_comparisons,
 732                masks,
 733                method_infos,
 734                str(output_dir),
 735                comparison_type,
 736                ref_name,
 737            )
 738        return {
 739            "df_comparisons": df_comparisons,
 740            "masks": masks,
 741            "execution_times": execution_times,
 742            "method_infos": method_infos,
 743        }

 758            df_comparisons: DataFrame с попарными метриками.

 418
 419        comparison_results: List[Dict[str, Any]] = []
 420
 421        for config in methods_config:
 422            segmenter = config.get("segmenter")
 423            method_name = config.get("name") or getattr(segmenter, "method", "Unknown")
 424            if segmenter is None:
 425                print(f"⚠️ Пропущен конфиг без сегментера: {config}")
 426                continue
 427            try:
 428                if str(self.device) == "cuda":
 429                    torch.cuda.synchronize()
 430                start_time_test: float = time.perf_counter()
 431                test_mask: MaskArray = segmenter.segment(image)
 432                if str(self.device) == "cuda":
 433                    torch.cuda.synchronize()
 434                test_time: float = time.perf_counter() - start_time_test
 435                test_info: Dict[str, Any] = {
 436                    "execution_time": test_time,
 437                    "method": method_name,
 438                }
 439
 440                # Вычисляем метрики
 441                metrics: Dict[str, float] = self.compute_metrics(
 442                    ref_mask, test_mask, f"Ref_{ref_name}", f"Test_{method_name}"
 443                )
 444
 445                # Сохраняем результаты
 446                result: Dict[str, Any] = {
 447                    "method": method_name,
 448                    **metrics,
 449                    "test_time": test_info.get("execution_time", 0),
 450                    "ref_time": ref_info.get("execution_time", 0),
 451                    "parameters": str(getattr(segmenter, "params", {})),
 452                }
 453
 454                comparison_results.append(result)
 455
 456                # Сохраняем визуализацию
 457                if save_results:
 458                    output_path: str = os.path.join(
 459                        output_dir, f"comparison_{method_name}.jpg"
 460                    )
 461                    self.visualize_comparison(
 462                        image,
 463                        ref_mask,
 464                        test_mask,
 465                        ref_info,
 466                        test_info,
 467                        metrics,
 468                        method1_name=f"Reference: {ref_name}",
 469                        method2_name=f"Test: {method_name}",
 470                        output_path=str(output_path),
 471                    )
 472
 473                print(
 474                    f"✅ Сравнение {method_name}: F1={metrics.get('f1_score', 0):.3f}, IoU={metrics.get('jaccard', 0):.3f}"
 475                )
 476
 477            except Exception as e:
 478                print(f"❌ Ошибка при тестировании {method_name}: {e}")
 479                traceback.print_exc()
 480                continue
 481
 482        df: pd.DataFrame = pd.DataFrame(comparison_results)
 483        if save_results and not df.empty:
 484            csv_path: str = os.path.join(output_dir, "comparison_results.csv")
 485            df.to_csv(csv_path, index=False)
 486            print(f"📊 Результаты сохранены в CSV: {csv_path}")
 487            self._create_summary_visualization(df, str(output_dir))

 583    # ──────────────────────────────────────────────────────────────────────
 584    def matrix_comparison(
 585        self,
 586        image: ImageArray,
 587        methods_config: List[Dict[str, Any]],
 588        reference_method: Optional[str] = None,
 589        comparison_type: str = "all_vs_all",
 590        save_results: bool = True,
 591        output_dir: PathLike = "./data/matrix_comparison_results",
 592    ) -> Dict[str, Any]:
 593        """Выполняет матричное сравнение всех методов между собой.
 594
 595        Поддерживаемые режимы:
 596        - `"all_vs_all"`: Каждая пара методов сравнивается (полная матрица N×N).
 597        - `"all_vs_ref"`: Все методы сравниваются с указанным `reference_method`.
 598        - `"pairwise"`: Только уникальные пары без повторений (комбинации).
 599
 600        Args:
 601            image: Входное изображение.
 602            methods_config: Список `{"name": str, "segmenter": obj}`.
 603            reference_method: Имя референсного метода (для режима `all_vs_ref`).
 604            comparison_type: Один из `["all_vs_all", "all_vs_ref", "pairwise"]`.
 605            save_results: Если `True`, сохраняет маски, визуализации, CSV и HTML-отчёт.
 606            output_dir: Базовая директория для сохранения артефактов.
 607
 608        Returns:
 609            Dict[str, Any]:
 610            - `df_comparisons`: DataFrame с попарными метриками.
 611            - `masks`: Dict `{method_name: MaskArray}`.
 612            - `execution_times`: Dict `{method_name: float}`.
 613            - `method_infos`: Доп. информация о методах.
 614        """
 615        if save_results:
 616            timestamp: str = datetime.now().strftime("%Y%m%d_%H%M%S")
 617            output_dir = os.path.join(output_dir, f"comparison_{timestamp}")
 618            os.makedirs(output_dir, exist_ok=True)
 619
 620        # Парсинг конфигураций
 621        method_names: List[str] = []
 622        segmenters_map: Dict[str, SegmenterLike] = (
 623            {}
 624        )  # Маппинг: Имя -> Объект сегментер
 625        for config in methods_config:
 626            name = config.get("name")
 627            segmenter = config.get("segmenter")
 628            if name is None or segmenter is None:
 629                print(f"⚠️ Пропущен конфиг без имени или сегментера: {config}")
 630                continue
 631            method_names.append(name)
 632            segmenters_map[name] = segmenter
 633
 634        print(f"Выполняем сегментацию {len(method_names)} методами...")
 635        masks: Dict[str, MaskArray] = {}
 636        execution_times: Dict[str, float] = {}
 637        method_infos: Dict[str, Any] = {}
 638
 639        for name in method_names:
 640            segmenter = segmenters_map[name]
 641            try:
 642                if str(self.device) == "cuda":
 643                    torch.cuda.synchronize()
 644                start_time: float = time.perf_counter()
 645                mask: MaskArray = segmenter.segment(image)
 646                if str(self.device) == "cuda":
 647                    torch.cuda.synchronize()
 648                exec_time: float = time.perf_counter() - start_time
 649
 650                masks[name] = mask
 651                execution_times[name] = exec_time
 652                method_infos[name] = {"execution_time": exec_time}
 653
 654                print(f"  ✅ {name}: {exec_time:.3f}s")
 655            except Exception as e:
 656                print(f"  ❌ {name}: {e}")
 657                import traceback
 658
 659                traceback.print_exc()
 660                h, w = image.shape[:2] if len(image.shape) >= 2 else (256, 256)
 661                masks[name] = np.zeros((h, w), dtype=np.uint8)
 662                execution_times[name] = 0
 663                method_infos[name] = {"error": str(e)}
 664
 665        if comparison_type == "all_vs_ref" and reference_method:
 666            comparison_pairs: List[Tuple[str, str]] = [
 667                (reference_method, other)
 668                for other in method_names
 669                if other != reference_method
 670            ]
 671            ref_name = reference_method
 672        elif comparison_type == "pairwise":
 673            comparison_pairs = list(itertools.combinations(method_names, 2))
 674            ref_name = None
 675        else:  # "all_vs_all"
 676            comparison_pairs = [(m1, m2) for m1 in method_names for m2 in method_names]
 677            ref_name = None
 678
 679        print(f"\nВыполняем сравнение {len(comparison_pairs)} пар...")
 680        comparison_results: List[Dict[str, Any]] = []
 681        for i, (method1, method2) in enumerate(comparison_pairs):
 682            if method1 not in masks or method2 not in masks:
 683                continue
 684            mask1: MaskArray = masks[method1]
 685            mask2: MaskArray = masks[method2]
 686            try:
 687                metrics: Dict[str, float] = self.compute_metrics(
 688                    mask1, mask2, method1, method2
 689                )
 690                result: Dict[str, Any] = {
 691                    "method1": method1,
 692                    "method2": method2,
 693                    **metrics,
 694                    "time1": execution_times.get(method1, 0),
 695                    "time2": execution_times.get(method2, 0),
 696                    "time_diff": abs(
 697                        execution_times.get(method1, 0)
 698                        - execution_times.get(method2, 0)
 699                    ),
 700                }
 701                comparison_results.append(result)
 702                if (i + 1) % 10 == 0:
 703                    print(f"  Обработано {i + 1}/{len(comparison_pairs)} пар...")
 704            except Exception as e:
 705                print(f"  Ошибка сравнения {method1} vs {method2}: {e}")
 706
 707        df_comparisons: pd.DataFrame = pd.DataFrame(comparison_results)
 708        if save_results:
 709            masks_dir: str = os.path.join(output_dir, "masks")
 710            os.makedirs(masks_dir, exist_ok=True)
 711            for name, mask in masks.items():
 712                mask_path: str = os.path.join(masks_dir, f"{name}_mask.png")
 713                plt.imsave(mask_path, mask, cmap="gray")
 714            images_dir: str = os.path.join(output_dir, "images")
 715            os.makedirs(images_dir, exist_ok=True)
 716
 717            if len(image.shape) == 2:
 718                plt.imsave(os.path.join(images_dir, "original.png"), image, cmap="gray")
 719            else:
 720                plt.imsave(os.path.join(images_dir, "original.png"), image)
 721            overlay: np.ndarray
 722            for name, mask in masks.items():
 723                if len(image.shape) == 2:
 724                    overlay = np.stack([image] * 3, axis=-1)
 725                else:
 726                    overlay = image.copy()
 727                overlay[mask > 127] = [255, 0, 0]
 728                overlay_path = os.path.join(images_dir, f"{name}_overlay.png")
 729                plt.imsave(overlay_path, overlay)
 730
 731            self._save_matrix_results(
 732                df_comparisons,
 733                masks,
 734                method_infos,
 735                str(output_dir),
 736                comparison_type,
 737                ref_name,
 738            )
 739        return {
 740            "df_comparisons": df_comparisons,
 741            "masks": masks,
 742            "execution_times": execution_times,
 743            "method_infos": method_infos,
 744        }

 774            "precision",
 775            "recall",
 776            "f1_score",
 777            "jaccard",
 778            "dice_coefficient",
 779            "intersection_over_union",

 828                            matrix[i, j] = np.nan

 833                name[:15] + "..." if len(name) > 15 else name for name in methods
 834            ]

 846                            i,
 847                            f"{matrix[i, j]:.2f}",
 848                            ha="center",
 849                            va="center",

 851                            fontsize=8,
 852                        )
 853                        print(text)
 854

 856            plt.colorbar(im, ax=ax, fraction=0.046, pad=0.04)
 857            plt.tight_layout()
 858

 862

 872            method_infos,

 874            comparison_type,

 919        method_infos: Dict[str, Any],
 920        output_dir: str,

 924        """Генерирует интерактивный HTML-отчёт с результатами матричного сравнения.
 925
 926        Включает:
 927        - Сводную статистику по методам.
 928        - Топ-5 методов по F1 (если задан reference_method).

 931
 932        Args:
