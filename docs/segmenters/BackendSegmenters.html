segmenters.BackendSegmenters

Модуль высокопроизводительных сегментеров на базе ONNX Runtime и TensorRT.

Предназначен для ускоренного инференса предварительно экспортированных моделей сегментации с поддержкой аппаратного ускорения на GPU.

Классы:

  • 🟦 ONNXSegmenter: Инференс через ONNX Runtime с поддержкой CUDA/CPU провайдеров. • Автоматический выбор Execution Provider (CUDAExecutionProvider → CPUExecutionProvider) • Графические оптимизации: ORT_ENABLE_ALL для максимального ускорения • Гибкая конфигурация входной формы: input_shape=(B, C, H, W) • Устойчивость к ошибкам: возврат пустой маски при сбое инференса
  • 🟩 TRTSegmenter: Инференс через TensorRT (torch_tensorrt) для максимальной производительности. • Загрузка моделей из .trt файлов или готовых torch.nn.Module • Автоматическая конвертация: numpy → torch.Tensor → TRT inference → numpy • Только CUDA: TensorRT требует наличия GPU с поддержкой CUDA • Оптимизированный конвейер: нормализация [0,1], batch-обработка, пост-процессинг

Особенности реализации:

  • 🔄 Единый интерфейс: оба класса наследуют BaseSegmenter и реализуют segment() / segment_with_mask().
  • 🎚️ Автоматическая предобработка: конвертация в 3 канала, нормализация к [0, 1], добавление batch-измерения.
  • 🛡️ Устойчивость к ошибкам: при исключении в segment() возвращается пустая маска (H, W) вместо None.
  • 📦 Поддержка форматов: вход — np.ndarray, PIL.Image, str (путь), torch.Tensor; выход — np.ndarray uint8 {0, 255}.
  • ⚡ Оптимизации: torch.no_grad() для TRT, SessionOptions для ONNX, кэширование сессий/моделей.
  • 🔍 Логирование: информативные сообщения об инициализации, формах тензоров и ошибках инференса.

Ограничения:

  • Вероятностные маски не поддерживаются: segment_with_mask() возвращает (binary_mask, None).
  • TRTSegmenter требует наличия CUDA-совместимого GPU и установленных torch-tensorrt, tensorrt.
  • ONNX-модели должны быть экспортированы с фиксированной или динамической входной формой, совместимой с input_shape.

Workflow:

  1. Экспортировать обученную модель в ONNX (.onnx) или TensorRT (.trt) формат.
  2. Инициализировать сегментер: ONNXSegmenter("method", "model.onnx", device="cuda").
  3. Выполнить инференс: mask = segmenter.segment(image).
  4. (Опционально) Использовать в бенчмарках через CpuCudaBenchmark или SegmentationBenchmark.

Примечание:

  • Для классических методов (пороги, границы) используйте OpenCVSegmenter / SklearnSegmenter.
  • Для нейросетевых моделей в PyTorch — TorchSegmenter / TorchSegmenter2.
  • Данный модуль предназначен для деплоя и бенчмаркинга уже обученных моделей.
  • Функция load_trt_model() импортируется из utils.backend_exporter — убедитесь в её наличии.

111class ONNXSegmenter(BaseSegmenter):
112    """Сегментер на базе ONNX Runtime."""

114    def __init__(
115        self,
116        method_name: str,
117        onnx_path: str,
118        device: Literal["cuda", "cpu"] = "cuda",
119        input_shape: Tuple[int, int, int, int] = (1, 3, 512, 512),
120        **kwargs: Any,
121    ) -> None:
122        """Инициализация ONNX сегментера.
123
124        Args:
125            method_name: Имя метода для логирования.
126            onnx_path: Путь к .onnx файлу модели.
127            device: Устройство выполнения: "cuda" или "cpu".
128            input_shape: Ожидаемая форма входа: (B, C, H, W).
129            **kwargs: Дополнительные параметры.
130        """
131        super().__init__()
132        self.method: str = method_name
133        self.params: Dict[str, Any] = kwargs
134        self.device_str: Literal["cuda", "cpu"] = device
135        self.input_shape: Tuple[int, int, int, int] = input_shape
136        try:
137            import onnxruntime as ort
138        except ImportError:
139            raise ImportError(
140                "onnxruntime-gpu не установлен: pip install onnxruntime-gpu"
141            )
142        providers: List[str] = (
143            ["CUDAExecutionProvider", "CPUExecutionProvider"]
144            if device == "cuda"
145            else ["CPUExecutionProvider"]
146        )
147        sess_options: ort.SessionOptions = ort.SessionOptions()
148        sess_options.graph_optimization_level = (
149            ort.GraphOptimizationLevel.ORT_ENABLE_ALL
150        )
151
152        self.session: ort.InferenceSession = ort.InferenceSession(
153            onnx_path, sess_options=sess_options, providers=providers
154        )
155        self.input_name: str = self.session.get_inputs()[0].name
156        self.output_name: str = self.session.get_outputs()[0].name
157
158        # Проверяем реальный output shape из модели
159        out_shape: Tuple[Union[str, int], ...] = self.session.get_outputs()[0].shape
160        logger.info(
161            f"ONNX '{method_name}': input={self.input_name}, "
162            f"output={self.output_name}, output_shape={out_shape}"
163        )
164
165    def _preprocess(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
166        """Конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
167
168        Args:
169            image: Входное изображение (H, W) или (H, W, 3), uint8.
170
171        Returns:
172            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
173        """
174        if image.ndim == 2:
175            image = np.stack([image] * 3, axis=-1)
176        if image.ndim == 3 and image.shape[2] == 3:
177            tensor: npt.NDArray[np.float32] = (
178                np.transpose(image, (2, 0, 1)).astype(np.float32) / 255.0
179            )
180            return np.expand_dims(tensor, 0)  # (1,3,H,W)
181        # Уже (B,C,H,W)
182        return image.astype(np.float32)
183
184    def segment(self, image, **kwargs: Any) -> BinaryMask:
185        """Запускает ONNX инференс.
186
187        Алгоритм:
188        1. Предобработка изображения → (1, 3, H, W), float32, [0, 1].
189        2. Запуск сессии ONNX.
190        3. Пост-обработка вывода: squeeze → бинаризация → uint8.
191
192        Args:
193            image: Входное изображение (H, W) или (H, W, 3), uint8.
194            **kwargs: Дополнительные параметры (игнорируются).
195
196        Returns:
197            BinaryMask: Бинарная маска формы (H, W), uint8, значения {0, 255}.
198                       При ошибке возвращает пустую маску того же размера.
199        """
200        try:
201            tensor: PreprocessedTensor = self._preprocess(image)
202            outputs: List[RawOutput] = self.session.run(
203                [self.output_name], {self.input_name: tensor}
204            )
205            if not outputs or outputs[0] is None:
206                logger.error(f"ONNX '{self.method}' returned None output")
207                return np.zeros(image.shape[:2], dtype=np.uint8)
208
209            mask: RawOutput = outputs[0]
210            # Flatten до (H,W)
211            while mask.ndim > 2:
212                mask = mask.squeeze(0)
213
214            # Нормализуем: если float [0,1] → uint8 [0,255]
215            if mask.dtype in (np.float32, np.float64):
216                if mask.max() <= 1.0 and mask.min() >= 0.0:
217                    # Вероятности → бинаризация
218                    mask = (mask > 0.5).astype(np.uint8) * 255
219                else:
220                    # Уже в диапазоне [0, 255]
221                    mask = mask.astype(np.uint8)
222            else:
223                mask = mask.astype(np.uint8)
224
225            return cast(BinaryMask, mask)
226
227        except Exception as e:
228            logger.error(f"ONNX '{self.method}' inference error: {e}")
229            h = image.shape[0] if image.ndim >= 1 else self.input_shape[2]
230            w = image.shape[1] if image.ndim >= 2 else self.input_shape[3]
231            return np.zeros((h, w), dtype=np.uint8)
232
233    def segment_with_mask(
234        self, image: ImageInput, **kwargs: Any
235    ) -> Tuple[BinaryMask, Optional[ProbabilityMask]]:
236        """Сегментация с возвратом бинарной и вероятностной масок.
237
238        Для ONNX-модели возвращаем только бинарную маску,
239        вероятностная маска не поддерживается.
240
241        Args:
242            image: Входное изображение.
243            **kwargs: Дополнительные параметры.
244
245        Returns:
246            Tuple[BinaryMask, Optional[ProbabilityMask]]:
247            - Бинарная маска: значения {0, 255}.
248            - Вероятностная маска: None (не поддерживается).
249        """
250        import numpy as np
251        from PIL import Image as PILImageModule
252
253        # Конвертация входного изображения в numpy
254        if not isinstance(image, np.ndarray):
255            if isinstance(image, PILImageModule.Image):
256                image_np: npt.NDArray[np.uint8] = np.array(image)
257            elif isinstance(image, str):
258                image_np = np.array(PILImageModule.open(image).convert("RGB"))
259            elif isinstance(image, torch.Tensor):
260                image_np = image.cpu().numpy()
261                if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
262                    image_np = np.transpose(image_np, (1, 2, 0))
263            else:
264                raise TypeError(f"Unsupported image type: {type(image)}")
265        else:
266            image_np = image
267        binary_mask: BinaryMask = self.segment(image, **kwargs)
268        return binary_mask, None

271class TRTSegmenter(BaseSegmenter):
272    """Сегментер на базе TensorRT (через torch_tensorrt)."""
273
274    def __init__(
275        self,
276        method_name: str,
277        trt_model_or_path: Union[str, TRTModel],
278        device: Literal["cuda", "cpu"] = "cuda",
279        **kwargs: Any,
280    ) -> None:
281        """Инициализация TensorRT сегментера.
282
283        Args:
284            method_name: Имя метода для логирования.
285            trt_model_or_path: Путь к .trt файлу или уже загруженная TRT-модель.
286            device: Устройство выполнения (только "cuda" поддерживается).
287            **kwargs: Дополнительные параметры.
288        """
289        super().__init__()
290        self.method: str = method_name
291        self.params: Dict[str, Any] = kwargs
292        self.device: torch.device = torch.device(device)
293        if isinstance(trt_model_or_path, str):
294            from utils.backend_exporter import load_trt_model
295
296            loaded_model: Optional[TRTModel] = load_trt_model(trt_model_or_path)
297            if loaded_model is None:
298                raise RuntimeError(
299                    f"Не удалось загрузить TRT модель: {trt_model_or_path}"
300                )
301            self.model: TRTModel = loaded_model
302        else:
303            self.model = trt_model_or_path
304        self.model.eval()
305
306    def segment(self, image, **kwargs: Any) -> BinaryMask:
307        """Запускает TRT инференс.
308
309        Алгоритм:
310        1. Конвертация numpy → torch.Tensor (C, H, W), float32, [0, 1].
311        2. Добавление batch-измерения и перенос на устройство.
312        3. Инференс модели с torch.no_grad().
313        4. Пост-обработка: squeeze → numpy → uint8 [0, 255].
314
315        Args:
316            image: Входное изображение (H, W) или (H, W, 3), uint8.
317            **kwargs: Дополнительные параметры (игнорируются).
318
319        Returns:
320            BinaryMask: Бинарная маска формы (H, W), uint8, значения {0, 255}.
321                       При ошибке возвращает пустую маску того же размера.
322        """
323        try:
324            # Конвертация в 3 канала если нужно
325            if image.ndim == 2:
326                image = np.stack([image] * 3, axis=-1)
327
328            # Нормализация и конвертация в torch
329            tensor: torch.Tensor = (
330                torch.from_numpy(image)
331                .permute(2, 0, 1)
332                .float()
333                .div(255.0)
334                .unsqueeze(0)
335                .to(self.device)
336            )
337
338            with torch.no_grad():
339                out: torch.Tensor = self.model(tensor)
340
341            # Flatten до (H,W)
342            mask_tensor: torch.Tensor = out.squeeze()
343            if mask_tensor.dim() > 2:
344                mask_tensor = mask_tensor.squeeze(0)
345
346            # Конвертация в uint8 [0, 255]
347            mask: BinaryMask = (
348                (mask_tensor.cpu().numpy() * 255).clip(0, 255).astype(np.uint8)
349            )
350            return mask
351
352        except Exception as e:
353            logger.error(f"TRT '{self.method}' inference error: {e}")
354            h, w = image.shape[:2]
355            return np.zeros((h, w), dtype=np.uint8)
