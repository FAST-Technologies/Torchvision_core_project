utils.strategies

Универсальные стратегии инференса для нейросетевой сегментации.

Поддерживаемые задачи:

  1. Единый интерфейс: segment_image_unified() для 20+ архитектур
  2. Авто-препроцессинг: выбор нормализации через SMP/HF процессоры
  3. Постобработка: ресайз к оригиналу, паддинг под output_stride, instance→semantic
  4. Визуализация: создание overlay с настраиваемой прозрачностью и палитрой
  5. Метрики: автоматический расчёт IoU, Dice, Accuracy при наличии GT

Ключевые особенности:

  • ✅ Паттерн "Стратегия": реестр INFERENCE_STRATEGIES для авто-диспетчеризации
  • ✅ Универсальный ввод: str/Path/URL, PIL, np.ndarray, torch.Tensor
  • ✅ Авто-ресайз: все маски возвращаются в размере исходного изображения
  • ✅ Паддинг: поддержка output_stride для FPN/PSPNet/DeepLab
  • ✅ Instance→Semantic: конвертация масок SAM/YOLOv8 в семантическую карту
  • ✅ Логирование: детальный вывод классов, метрик, времени при verbose=True

Типичный workflow:

from utils.strategies import segment_image_unified
from segmenters.NeuralModelFactory import NeuralModelFactory, ModelType

# 1. Загрузка модели
model, processor, _ = NeuralModelFactory.create_model(
    ModelType.SEGFORMER,
    model_name="nvidia/segformer-b5-finetuned-ade-640-640",
    device="cuda"
)

# 2. Инференс с единым интерфейсом
overlay, info = segment_image_unified(
    model=model,
    processor=processor,
    image_input="test.jpg",
    model_type="segformer",
    device="cuda",
    alpha=0.7,
    verbose=True
)

# 3. Доступ к результатам
print(f"Time: {info['inference_time_ms']:.2f}ms, Classes: {info['unique_classes']}")
if info['metrics']:
    print(f"IoU: {info['metrics']['iou']:.3f}")
overlay.save("result.png")

Note:

  • Все стратегии выполняют инференс в контексте torch.no_grad().
  • Для SMP-моделей препроцессинг определяется через smp.encoders.get_preprocessing_fn().
  • Ресайз масок использует order=0 (nearest-neighbor) для сохранения целочисленных меток.
  • При verbose=True автоматически генерируется Markdown-отчёт в ADE20K_DIR.
  • Instance-сегментация (SAM/YOLOv8) назначает уникальный ID каждому объекту; для семантической сегментации используйте модели с class logits.

 151def infer_segformer(
 152    model: Any,
 153    processor: Any,
 154    image: Image.Image,
 155    device: str = "cuda",
 156) -> Tuple[MaskArray, Image.Image]:
 157    """Инференс для SegFormer (HuggingFace Transformers).
 158
 159    Возвращает семантическую маску в размере оригинального изображения.
 160    Поддерживает все варианты: B0, B1, B2, B3, B4, B5.
 161
 162    Args:
 163        model: Загруженная модель `SegformerForSemanticSegmentation`.
 164        processor: `SegformerImageProcessor` для препроцессинга и постпроцессинга.
 165        image: Входное изображение `PIL.Image` в RGB.
 166        device: Устройство для вычислений (`"cuda"` или `"cpu"`).
 167
 168    Returns:
 169        Tuple[np.ndarray, PIL.Image]:
 170        - `seg_map`: Семантическая маска `[H, W]`, dtype `uint8`, значения 0..149.
 171        - `image`: Оригинальное изображение (без изменений).
 172
 173    Note:
 174        - Использует `post_process_semantic_segmentation` с `target_sizes` для ресайза к оригиналу.
 175        - Все вычисления выполняются в контексте `torch.no_grad()`.
 176    """
 177    inputs = processor(images=image, return_tensors="pt").to(device)
 178    with torch.no_grad():
 179        outputs = model(**inputs)
 180        logits = outputs.logits
 181    logits_info: Dict[str, Any] = extract_logits_info(outputs, "segformer")
 182    print(f"📈 SegFormer logits: {logits_info}")
 183    print(f"📈 SegFormer custom logits: {logits}")
 184    seg_map: MaskArray = (
 185        processor.post_process_semantic_segmentation(
 186            outputs, target_sizes=[image.size[::-1]]  # [H, W] = [height, width]
 187        )[0]
 188        .cpu()
 189        .numpy()
 190    )
 191    return seg_map, image

 259# ──────────────────────────────────────────────────────────────────────
 260def infer_deeplab_torchvision(
 261    model: Any,
 262    processor: Any,
 263    image: Image.Image,
 264    device: str = "cuda",
 265    target_size: Tuple[int, int] = (512, 512),
 266) -> Tuple[MaskArray, Image.Image]:
 267    """Инференс для DeepLabV3+ из torchvision.
 268
 269    Args:
 270        model: Загруженная модель `DeepLabV3` из `torchvision.models.segmentation`.
 271        processor: Не используется (для совместимости интерфейса).
 272        image: Входное изображение `PIL.Image`.
 273        device: Устройство для вычислений.
 274        target_size: Размер, к которому ресайзится изображение перед инференсом
 275            (должен совпадать с размером при обучении модели).
 276
 277    Returns:
 278        Tuple[np.ndarray, PIL.Image]: Семантическая маска в размере оригинала и оригинальное изображение.
 279    """
 280    # Preprocessing
 281    preprocess = T.Compose(
 282        [
 283            T.ToTensor(),
 284            T.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
 285        ]
 286    )
 287
 288    # Ресайз к target_size
 289    image_resized: Image.Image = image.resize(target_size, Image.Resampling.BILINEAR)
 290    input_tensor: torch.Tensor = preprocess(image_resized).unsqueeze(0).to(device)
 291
 292    with torch.no_grad():
 293        raw_output = model(input_tensor)
 294
 295    logits_info: Dict[str, Any] = extract_logits_info(raw_output, "deeplab_tv")
 296    print(f"📈 DeepLabV3+ logits: {logits_info}")
 297
 298    # Извлечение логитов
 299    if isinstance(raw_output, dict):
 300        logits = raw_output["out"][0]
 301    else:
 302        logits = raw_output[0] if hasattr(raw_output, "__getitem__") else raw_output  # [C, H, W]
 303
 304    predicted_mask: MaskArray = logits.argmax(0).cpu().numpy().astype(np.uint8)  # [H, W]
 305
 306    # Ресайз к оригиналу
 307    if predicted_mask.shape != (image.size[1], image.size[0]):
 308        sh, sw = (
 309            image.size[1] / predicted_mask.shape[0],
 310            image.size[0] / predicted_mask.shape[1],
 311        )
 312        predicted_mask = zoom(predicted_mask, (sh, sw), order=0)
 313    return predicted_mask, image

 316# ──────────────────────────────────────────────────────────────────────
 317def infer_unet_smp(
 318    model: Any,
 319    processor: Any,
 320    image: Image.Image,
 321    encoder_name: str = "resnet34",
 322    device: str = "cuda",
 323    output_stride: int = 1,
 324) -> Tuple[MaskArray, Image.Image]:
 325    """Универсальный инференс для SMP-моделей (U-Net, SegNet) и кастомных архитектур.
 326
 327    Особенности:
 328    - Авто-определение препроцессинга через `smp.encoders.get_preprocessing_fn`.
 329    - Паддинг под `output_stride` для моделей с downsample (FPN, PSPNet).
 330    - Кроппинг паддинга и ресайз к оригинальному размеру.
 331
 332    Args:
 333        model: Загруженная модель из `segmentation_models_pytorch`.
 334        processor: Не используется (для совместимости интерфейса).
 335        image: Входное изображение `PIL.Image`.
 336        encoder_name: Название encoder'а для препроцессинга (по умолчанию `"resnet34"`).
 337        device: Устройство для вычислений.
 338        output_stride: Кратность размера (1 для U-Net/SegNet, 8/16/32 для других).
 339
 340    Returns:
 341        Tuple[np.ndarray, PIL.Image]: Семантическая маска в размере оригинала и оригинальное изображение.
 342    """
 343    # Preprocessing function
 344    try:
 345        # Для SMP-моделей с encoder
 346        if hasattr(model, "encoder") and hasattr(model.encoder, "name"):
 347            encoder_name = model.encoder.name
 348            preprocess_fn = smp.encoders.get_preprocessing_fn(encoder_name, "imagenet")
 349        else:
 350            # Fallback для SegNet без encoder атрибута
 351            raise AttributeError("No encoder attribute")
 352    except Exception:
 353        # Fallback: стандартный ImageNet preprocessing для SegNet
 354        mean: np.ndarray = np.array([0.485, 0.456, 0.406])
 355        std: np.ndarray = np.array([0.229, 0.224, 0.225])
 356
 357        def preprocess_fn(x: np.ndarray) -> np.ndarray:
 358            result: np.ndarray = (x.astype(np.float32) / 255.0 - mean) / std
 359            return result
 360
 361    image_np: np.ndarray = np.array(image)
 362
 363    # Preprocessing
 364    input_tensor = preprocess_fn(image_np)
 365    input_tensor = torch.from_numpy(input_tensor).permute(2, 0, 1).float().unsqueeze(0).to(device)
 366
 367    # Паддинг под output_stride
 368    pad_h, pad_w = 0, 0
 369    if output_stride > 1:
 370        h, w = input_tensor.shape[2], input_tensor.shape[3]
 371        pad_h = (output_stride - h % output_stride) % output_stride
 372        pad_w = (output_stride - w % output_stride) % output_stride
 373        if pad_h > 0 or pad_w > 0:
 374            input_tensor = torch.nn.functional.pad(input_tensor, (0, pad_w, 0, pad_h), mode="reflect")
 375
 376    with torch.no_grad():
 377        outputs = model(input_tensor)  # [B, C, H, W]
 378    is_segnet: bool = "SegNet" in str(type(model))
 379    model_type = "segnet" if is_segnet else "unet_smp"
 380    logits_info: Dict[str, Any] = extract_logits_info(outputs, model_type)
 381    print(f"📈 {'SegNet' if is_segnet else 'SMP'} logits: {logits_info}")
 382
 383    # Пост-процессинг: argmax + ресайз к оригиналу
 384    predicted_mask: MaskArray = outputs.argmax(1).squeeze(0).cpu().numpy()  # [H, W]
 385
 386    # Кроппинг после паддинга
 387    if output_stride > 1 and (pad_h > 0 or pad_w > 0):
 388        predicted_mask = predicted_mask[: image.size[1], : image.size[0]]
 389
 390    if predicted_mask.shape != image.size[::-1]:
 391        sh, sw = (
 392            image.size[1] / predicted_mask.shape[0],
 393            image.size[0] / predicted_mask.shape[1],
 394        )
 395        predicted_mask = zoom(predicted_mask, (sh, sw), order=0)
 396    return predicted_mask, image

 400def infer_sam(model: Any, processor: Any, image: Image.Image, device: str = "cuda") -> Tuple[np.ndarray, Image.Image]:
 401    """Инференс для модели SAM."""
 402    img_w, img_h = image.size
 403
 404    # Инференс (без prompts=None!)
 405    results = model(image)
 406
 407    logits_info: Dict[str, Any] = extract_logits_info(results, "sam")
 408    print(f"📈 SAM logits: {logits_info}")
 409
 410    print("📈 MobileSAM: instance segmentation (no class logits)")
 411    if results[0].masks is not None:
 412        print(
 413            f"   Masks: {results[0].masks.data.shape}, conf: {results[0].boxes.conf if hasattr(results[0], 'boxes') else 'N/A'}"
 414        )
 415    # Создаём семантическую карту из инстанс-масок
 416    seg_map: MaskArray = np.zeros((img_h, img_w), dtype=np.uint8)
 417
 418    if results[0].masks is not None:
 419        masks: np.ndarray = results[0].masks.data.cpu().numpy()

 448def infer_smp_model(
 449    model: Any,
 450    processor: Any,
 451    image: Image.Image,
 452    device: str = "cuda",
 453    output_stride: int = 32,
 454    log_logits: bool = True,
 455) -> Tuple[np.ndarray, Image.Image]:
 456    """Универсальный инференс для SMP-моделей (U-Net, FPN, PSPNet, DeepLabV3+) с авто-паддингом под output_stride.
 457
 458    Args:
 459        model: название модели.
 460        processor: текущззий процессор модели.
 461        image: исходное изображение для обработки.
 462        device: текущее устройство (CPU/CUDA).
 463        output_stride: кратность размера (32 для FPN/DeepLab, 8 для PSPNet, 1 для U-Net).
 464        log_logits: флаг для логирования логитов.
 465    """
 466    orig_w, orig_h = image.size
 467
 468    # Preprocessing
 469    try:
 470        encoder_name = model.encoder.name
 471    except Exception:
 472        encoder_name = "mit_b5"
 473
 474    preprocess_fn = smp.encoders.get_preprocessing_fn(encoder_name, "imagenet")
 475
 476    # Конвертация + препроцессинг
 477    image_np: np.ndarray = np.array(image)
 478    input_tensor = preprocess_fn(image_np)
 479    input_tensor = torch.from_numpy(input_tensor).permute(2, 0, 1).float()
 480
 481    # ПАДДИНГ под output_stride
 482    if output_stride > 1:
 483        h, w = input_tensor.shape[1], input_tensor.shape[2]
 484        pad_h = (output_stride - h % output_stride) % output_stride
 485        pad_w = (output_stride - w % output_stride) % output_stride
 486
 487        if pad_h > 0 or pad_w > 0:
 488            input_tensor = torch.nn.functional.pad(
 489                input_tensor,
 490                (0, pad_w, 0, pad_h),
 491                mode="reflect",
 492            )
 493    input_tensor = input_tensor.unsqueeze(0).to(device)
 494
 495    # Инференс
 496    with torch.no_grad():
 497        outputs = model(input_tensor)  # [B, C, H_pad, W_pad]
 498
 499    if log_logits:
 500        logits_info: Dict[str, Any] = extract_logits_info(outputs, "smp")
 501        print(f"📈 SMP logits: {logits_info}")
 502
 503    # Пост-процессинг: argmax + кроппинг к оригиналу
 504    pred_mask: np.ndarray = outputs.argmax(1).squeeze(0).cpu().numpy()  # [H_pad, W_pad]
 505
 506    # КРОППИНГ к оригинальному размеру
 507    if output_stride > 1 and (pad_h > 0 or pad_w > 0):
 508        pred_mask = pred_mask[:orig_h, :orig_w]
 509
 510    return pred_mask, image

 763class SegNet(torch.nn.Module):
 764    """Простая реализация SegNet для бенчмарка.
 765
 766    Encoder-Decoder с max pooling indices.
 767    """
 768
 769    def __init__(self, num_classes: int = NUM_CLASSES) -> None:
 770        """Инициализация модели SegNet."""
 771        super().__init__()
 772
 773        # Encoder (VGG16-like)
 774        self.enc1 = self._make_encoder(3, 64)
 775        self.enc2 = self._make_encoder(64, 128)
 776        self.enc3 = self._make_encoder(128, 256)
 777        self.enc4 = self._make_encoder(256, 512)
 778        self.enc5 = self._make_encoder(512, 512)
 779
 780        # Decoder
 781        self.dec5 = self._make_decoder(512, 512)
 782        self.dec4 = self._make_decoder(512, 256)
 783        self.dec3 = self._make_decoder(256, 128)
 784        self.dec2 = self._make_decoder(128, 64)
 785        self.dec1 = self._make_decoder(64, 64)
 786
 787        # Classifier
 788        self.classifier = torch.nn.Conv2d(64, num_classes, kernel_size=1)
 789
 790    # ──────────────────────────────────────────────────────────────────────
 791    def _make_encoder(self, in_ch: int, out_ch: int) -> torch.nn.Sequential:
 792        """Создание энкодера для модели SegNet."""
 793        return torch.nn.Sequential(
 794            torch.nn.Conv2d(in_ch, out_ch, 3, padding=1),
 795            torch.nn.BatchNorm2d(out_ch),
 796            torch.nn.ReLU(inplace=True),
 797            torch.nn.Conv2d(out_ch, out_ch, 3, padding=1),
 798            torch.nn.BatchNorm2d(out_ch),
 799            torch.nn.ReLU(inplace=True),
 800        )
 801
 802    # ──────────────────────────────────────────────────────────────────────
 803    def _make_decoder(self, in_ch: int, out_ch: int) -> torch.nn.Sequential:
 804        """Создание декодера для модели SegNet."""
 805        return torch.nn.Sequential(
 806            torch.nn.Conv2d(in_ch, out_ch, 3, padding=1),
 807            torch.nn.BatchNorm2d(out_ch),
 808            torch.nn.ReLU(inplace=True),
 809            torch.nn.Conv2d(out_ch, out_ch, 3, padding=1),
 810            torch.nn.BatchNorm2d(out_ch),
 811            torch.nn.ReLU(inplace=True),
 812            torch.nn.Conv2d(out_ch, out_ch, 3, padding=1),
 813            torch.nn.BatchNorm2d(out_ch),
 814            torch.nn.ReLU(inplace=True),
 815        )
 816
 817    # ──────────────────────────────────────────────────────────────────────
 818    def forward(self, x: torch.Tensor) -> torch.Tensor:
 819        """Прямой ход для модели SegNet."""
 820        # Encoder
 821        e1, p1 = self._encode(self.enc1, x)
 822        e2, p2 = self._encode(self.enc2, p1)
 823        e3, p3 = self._encode(self.enc3, p2)
 824        e4, p4 = self._encode(self.enc4, p3)
 825        e5, p5 = self._encode(self.enc5, p4)
 826
 827        # Decoder
 828        d5 = self._decode(self.dec5, p5, e5.size())
 829        d4 = self._decode(self.dec4, d5, e4.size())
 830        d3 = self._decode(self.dec3, d4, e3.size())
 831        d2 = self._decode(self.dec2, d3, e2.size())
 832        d1 = self._decode(self.dec1, d2, e1.size())
 833
 834        result: torch.Tensor = self.classifier(d1)
 835        return result
 836
 837    # ──────────────────────────────────────────────────────────────────────
 838    def _encode(self, encoder: torch.nn.Module, x: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
 839        """Encoder step: conv → batchnorm → relu → maxpool.
 840
 841        max_pool2d возвращает (output, indices), берём только output.
 842        """
 843        x = encoder(x)
 844        pooled, indices = torch.nn.functional.max_pool2d(x, 2, 2, return_indices=True)
 845        return x, pooled
 846
 847    # ──────────────────────────────────────────────────────────────────────
 848    def _decode(self, decoder: torch.nn.Module, x: torch.Tensor, output_size: torch.Size) -> torch.Tensor:
 849        """Decoder step: upsample → conv → batchnorm → relu."""
 850        # Upsampling к размеру encoder features
 851        x = torch.nn.functional.interpolate(x, size=output_size[2:], mode="bilinear", align_corners=False)
 852        result: torch.Tensor = decoder(x)
 853        return result

1176    1. `model.config.id2label` (HF transformers)

1178    3. Последний `torch.nn.Conv2d` в архитектуре (SMP/custom)

1190        if hasattr(model, "config") and hasattr(model.config, "id2label"):
1191            return len(model.config.id2label)
1192
1193        if model_type in ["deeplab_tv", "fcn_tv"]:
1194            if hasattr(model, "classifier"):
1195                return int(model.classifier[-1].out_channels)

1199        if model_type in ["unet_smp", "mit_smp", "fpn_mit", "psp_mit", "segnet_custom"]:
1200            for module in reversed(list(model.modules())):
1201                if isinstance(module, torch.nn.Conv2d):
1202                    return module.out_channels
1203            return fallback
1204
1205        if model_type in ["sam", "mobile_sam", "sam2"]:
1206            return None
1207        return fallback
1208    except Exception:
1209        return fallback

1264    image: Image.Image,
1265    mask: MaskArray,
1266    alpha: float = 0.5,
1267    palette: Optional[Union[List[List[int]], Callable[[], List[List[int]]]]] = None,
1268    model_type_for_palette: Optional[str] = None,
1269) -> Image.Image:
1270    """Создаёт визуализацию: оригинал + цветная маска.
1271
1272    🔧 ФИКС: Универсальная логика сдвига + защита от overflow.
1273    """
1274    # ──────────────────────────────────────────────────────────────
1275    # 1. Разрешение палитры
1276    # ──────────────────────────────────────────────────────────────
1277    palette_resolved: Optional[List[List[int]]] = None
1278    if palette is None:
1279        palette_resolved = ade_palette()
1280    elif callable(palette):
1281        palette_resolved = palette()
1282    else:
1283        palette_resolved = palette
1284
1285    palette_array: np.ndarray = np.array(palette_resolved, dtype=np.uint8)
1286
1287    h, w = mask.shape
1288    color_mask: np.ndarray = np.zeros((h, w, 3), dtype=np.uint8)
1289
1290    # ──────────────────────────────────────────────────────────────
1291    # 2. 🔧 ОПРЕДЕЛЕНИЕ СДВИГА ПО ТИПУ МОДЕЛИ
1292    # ──────────────────────────────────────────────────────────────
1293    palette_offset: int = 0  # По умолчанию: без сдвига (для HF-моделей)
1294
1295    # Наши обученные модели: предсказывают классы 1-150, палитра 0-149 → сдвиг -1

1297
1298    if model_type_for_palette in OUR_MODELS:
1299        palette_offset = -1
1300
1301    print(f"🎨 Palette offset for {model_type_for_palette}: {palette_offset}")
1302
1303    # ──────────────────────────────────────────────────────────────
1304    # 3. 🔧 БЕЗОПАСНОЕ ПРИМЕНЕНИЕ ПАЛИТРЫ
1305    # ──────────────────────────────────────────────────────────────
1306    unique_labels: np.ndarray = np.unique(mask)
1307
1308    for label in unique_labels:
1309        label_int: int = int(label)
1310        palette_idx: int = label_int + palette_offset
1311
1312        # 🔧 КЛЮЧЕВОЙ ФИКС: проверка границ ДО индексации

1314            # 🔧 Используем int-индексацию для избежания uint8 overflow
1315            color_mask[mask == label_int] = palette_array[palette_idx].tolist()
1316        elif palette_idx < 0:
1317            # Фон/неопределённый класс → чёрный [0,0,0]
1318            color_mask[mask == label_int] = [0, 0, 0]
1319        # else: palette_idx >= len(palette_array) → оставляем чёрный (по умолчанию)
1320

1322    # 4. 🔍 Отладочный вывод (опционально)

1324    if os.getenv("DEBUG", "0") == "1":
1325        print(f"🎨 Palette mapping (offset={palette_offset}, model={model_type_for_palette}):")
1326        for label in unique_labels[:10]:
1327            label_int = int(label)
1328            palette_idx = label_int + palette_offset
1329            if 0 <= palette_idx < len(palette_array):
1330                color = palette_array[palette_idx]
1331                print(f"   Label {label_int} → palette[{palette_idx}] = RGB{tuple(color)}")
1332            else:

1337    # ──────────────────────────────────────────────────────────────

1339    overlay: np.ndarray = (img_arr * (1 - alpha) + color_mask * alpha).astype(np.uint8)
1340
1341    return Image.fromarray(overlay)

Автоматически:

  1. Загружает/конвертирует изображение из разных форматов.
  2. Выбирает стратегию инференса по model_type.
  3. Выполняет предсказание и постпроцессинг.
  4. (Опционально) Логирует детали и считает метрики при наличии GT.
  5. Создаёт overlay-визуализацию.
