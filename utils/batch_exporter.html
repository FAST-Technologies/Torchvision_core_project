utils.batch_exporter

Модуль массового экспорта классических методов сегментации.

Предоставляет инструменты для пакетного экспорта методов сегментации из библиотеки PyTorch в оптимизированные форматы для продакшн-развёртывания: ONNX и TensorRT.

Основные возможности:

  • 🔄 Массовый экспорт пороговых и граничных методов сегментации
  • 🎯 Поддержка множественных точностей: fp32, fp16, bf16
  • 📦 Экспорт в ONNX (кроссплатформенный формат)
  • ⚡ Экспорт в TensorRT (оптимизация для NVIDIA GPU)
  • 📊 Автоматическая генерация отчётов о статусе экспорта
  • ♻️ Поддержка инкрементального экспорта (пропуск существующих файлов)

Поддерживаемые категории методов:

  1. Пороговые методы (THRESHOLD_METHODS):
    • global_thresholding, otsu_thresholding, adaptive_thresholding
    • threshold_niblack, threshold_sauvola, threshold_bernsen
    • threshold_phansalkar, threshold_percentile, threshold_kittler_illingworth
    • threshold_entropy_kapur, threshold_triangle, threshold_multi_otsu
    • threshold_local_contrast
  1. Граничные методы (EDGE_METHODS):
    • sobel_edge, canny_edge, prewitt_edge, scharr_edge, laplacian_edge
    • roberts_cross_edge, log_edge, dog_edge, marr_hildreth_edge
    • gradient_magnitude_direction, phase_congruency_edge

Архитектура экспорта:

┌─────────────────────────────────────┐
│  TorchSegmenter2 (исходный метод)   │
└─────────────┬───────────────────────┘
              │
    ┌─────────┴─────────┐
    ▼                   ▼
┌─────────┐      ┌─────────────┐
│  ONNX   │      │  TensorRT   │
│ (CPU/GPU)│      │ (GPU only) │
└─────────┘      └─────────────┘

Примеры использования:

  1. Базовый экспорт всех методов:
from utils.batch_exporter import export_all_classical_methods

results = export_all_classical_methods(
    output_base_dir="./exported_models",
    export_onnx=True,
    export_trt=torch.cuda.is_available()
)
  1. Экспорт с выбором точностей и методов:
results = export_all_classical_methods(
    precisions=["fp32", "bf16"],
    methods=["otsu_thresholding", "canny_edge", "sobel_edge"],
    input_shape=(1, 3, 1024, 1024),  # Full HD
    force_reexport=True
)
  1. Анализ результатов:
for method, backends in results.items():
    for backend, status in backends.items():
        if status == "✅ OK":
            print(f"{method} → {backend}: успешно")

Требования:

  • PyTorch >= 2.0 (для torch.export и Dynamo)
  • onnx >= 1.14 (для экспорта в ONNX)
  • tensorrt >= 8.6 (опционально, для экспорта в TensorRT)
  • CUDA >= 11.8 (для GPU-экспорта и TensorRT)

Примечания:

  • Для экспорта в TensorRT требуется установленный NVIDIA TensorRT и совместимая видеокарта.
  • Методы с torch.compile не поддерживаются для экспорта — используйте use_compile=False.
  • Входной shape должен соответствовать ожидаемому формату сегментера: (B, C, H, W).
  • Экспорт может занимать значительное время при большом количестве методов и точностей.

197def export_all_classical_methods(
198    output_base_dir: str = "./exported_models",
199    precisions: Optional[List[PrecisionType]] = None,
200    methods: Optional[List[str]] = None,
201    input_shape: Tuple[int, int, int, int] = (1, 3, 512, 512),
202    force_reexport: bool = False,
203    export_onnx: bool = True,
204    export_trt: bool = True,
205    trt_strategy: TRTStrategyType = "auto",
206    enable_trt_ep_fallback: bool = True,  # Гарантированный fallback через TRT EP
207    trt_ep_preset: str = "production",  # Пресет конфигурации: "production" | "debug" | "int8" | "dynamic"
208    trt_ep_custom_options: Optional[Dict[str, Any]] = None,  # Пользовательские опции (перезаписывают пресет)
209    trt_ep_cache_path: Optional[str] = None,  # Путь для кэша TRT EP
210) -> Dict[str, Dict[str, Any]]:
211    """Массовый экспорт классических методов сегментации.
212
213    Args:
214        output_base_dir: Базовая директория для экспорта
215        precisions: Список точностей ['fp32', 'fp16', 'bf16']
216        methods: Список методов (по умолчанию: все threshold + edge)
217        input_shape: Shape входного тензора (B, C, H, W)
218        force_reexport: Пересоздавать ли существующие файлы
219        export_onnx: Экспортировать ли в ONNX
220        export_trt: Экспортировать ли в TensorRT (требует CUDA)
221        trt_strategy: Стратегия экспорта в TRT:
222            - "auto": пробует все стратегии по порядку (рекомендуется)
223            - "api": tensorrt Python API (наиболее надёжный)
224            - "trtexec": subprocess вызов trtexec
225            - "onnx_tensorrt": через onnx-tensorrt parser
226            - "jit": legacy torch_tensorrt JIT
227        enable_trt_ep_fallback: Если True, создаёт ONNXSegmenter с TensorRT EP
228                               как гарантированный рабочий вариант, даже если
229                               нативный TRT экспорт не удался.
230        trt_ep_preset: Название пресета конфигурации для TensorRT EP:
231                      - "production": баланс скорость/точность (по умолчанию)
232                      - "debug": FP32 + детальное логирование
233                      - "int8": квантование (требует calibration.table)
234                      - "dynamic": для моделей с dynamic_axes
235        trt_ep_custom_options: Словарь опций, которые перезаписывают значения пресета.
236        trt_ep_cache_path: Путь для кэширования TRT engines (по умолчанию './trt_engines_onnxrt')
237
238    Returns:
239        Dict с результатами: {method_name: {backend: status}}
240        Добавляются ключи:
241        - `onnxrt_trt_{precision}`: статус создания fallback с TRT EP
242    """
243    if precisions is None:
244        precisions = ["fp32"]
245        if torch.cuda.is_available():
246            precisions.append("fp16")
247            if torch.cuda.get_device_capability(0)[0] >= 8:
248                precisions.append("bf16")
249
250    if methods is None:
251        methods = THRESHOLD_METHODS + EDGE_METHODS
252
253    os.makedirs(output_base_dir, exist_ok=True)
254    results: Dict[str, Dict[str, Any]] = {}
255
256    for method_name in methods:
257        print(f"\n🔄 Экспорт метода: {method_name}")
258        results[method_name] = {}
259
260        for precision in precisions:
261            print(f"  ├─ Точность: {precision}")
262
263            if precision == "bf16":
264                cap = torch.cuda.get_device_capability(0)
265                if cap[0] < 8:  # Ampere+
266                    print(f"    ⚠️  bf16 требует GPU Ampere+, пропускаем для {method_name}")
267                    results[method_name][f"trt_{precision}"] = "⚠️ BF16 unsupported"
268                    continue
269
270            # Инициализация сегментера с параметрами для экспорта
271            segmenter: TorchSegmenter2 = TorchSegmenter2(
272                method=method_name,
273                device="cuda" if torch.cuda.is_available() else "cpu",
274                precision=precision,
275                use_compile=False,  # Важно: отключаем torch.compile для экспорта
276                debug_mode=False,
277            )
278
279            # ───────── ONNX экспорт ─────────
280            if export_onnx:
281                onnx_dir: str = os.path.join(output_base_dir, "onnx", precision)
282                os.makedirs(onnx_dir, exist_ok=True)
283                onnx_path: str = os.path.join(onnx_dir, f"{method_name}.onnx")
284
285                if force_reexport and os.path.exists(onnx_path):
286                    os.remove(onnx_path)
287
288                if not os.path.exists(onnx_path):
289                    os.makedirs(os.path.dirname(onnx_path), exist_ok=True)
290                    try:
291                        result: bool = export_method_to_onnx_safe(
292                            segmenter=segmenter,
293                            method_name=method_name,
294                            output_path=onnx_path,
295                            opset_version=17,
296                            precision=precision,
297                            input_shape=input_shape,
298                        )
299                        if result is True and os.path.exists(onnx_path) and os.path.getsize(onnx_path) > 0:
300                            results[method_name][f"onnx_{precision}"] = "✅ OK"
301                            print(f"  │  └─ ONNX: {onnx_path}")
302                        else:
303                            msg = "❌ Export failed" if result is False else f"❌ File not created (result={result})"
304                            results[method_name][f"onnx_{precision}"] = msg
305                            print(f"  │  └─ ONNX: {msg}")
306                            print("\n⏳ Пауза 15 секунд перед запуском бенчмарка...")
307                            print("   (нажмите Ctrl+C для отмены, если нужно)")
308                            try:
309                                time.sleep(15)  # 🔥 Задержка 15 секунд
310                            except KeyboardInterrupt:
311                                print("\n⚠️  Бенчмарк пропущен по запросу пользователя")
312                    except Exception as e:

317                        print(f"  │  └─ Traceback:\n{traceback.format_exc()}")
318                        print("\n⏳ Пауза 15 секунд перед запуском бенчмарка...")
319                        print("   (нажмите Ctrl+C для отмены, если нужно)")
320                        try:
321                            time.sleep(15)  # 🔥 Задержка 15 секунд
322                        except KeyboardInterrupt:
323                            print("\n⚠️  Бенчмарк пропущен по запросу пользователя")
324                else:
325                    results[method_name][f"onnx_{precision}"] = "⏭️ Exists"
326
327            if not os.path.exists(onnx_path):
328                results[method_name][f"trt_{precision}"] = "⚠️ ONNX missing"
329                print(f"  │  └─ TRT skipped: ONNX not found")
330                print("\n⏳ Пауза 15 секунд перед запуском бенчмарка...")
331                print("   (нажмите Ctrl+C для отмены, если нужно)")
332                try:
333                    time.sleep(15)  # 🔥 Задержка 15 секунд
334                except KeyboardInterrupt:
335                    print("\n⚠️  Бенчмарк пропущен по запросу пользователя")
336                continue
337
338            # ───────── TensorRT экспорт ─────────
339            if export_trt and torch.cuda.is_available():
340                trt_dir: str = os.path.join(output_base_dir, "tensorrt", precision)
341                os.makedirs(trt_dir, exist_ok=True)
342                trt_path: str = os.path.join(trt_dir, f"{method_name}.trt")
343
344                if force_reexport and os.path.exists(trt_path):
345                    os.remove(trt_path)
346
347                if not os.path.exists(trt_path):
348                    try:
349                        success: bool = _export_trt_with_strategy(
350                            method_name=method_name,
351                            onnx_path=onnx_path,
352                            trt_path=trt_path,
353                            precision=precision,
354                            input_shape=input_shape,
355                            strategy=trt_strategy,
356                        )
357                        if success:
358                            results[method_name][f"trt_{precision}"] = "✅ OK"
359                            print(f"  │  └─ TRT: {trt_path}")
360                        else:
361                            results[method_name][f"trt_{precision}"] = "❌ Failed"
362                            print("\n⏳ Пауза 15 секунд перед запуском бенчмарка...")
363                            print("   (нажмите Ctrl+C для отмены, если нужно)")
364                            try:
365                                time.sleep(15)  # 🔥 Задержка 15 секунд
366                            except KeyboardInterrupt:
367                                print("\n⚠️  Бенчмарк пропущен по запросу пользователя")
368                    except Exception as e:
369                        results[method_name][f"trt_{precision}"] = f"❌ {e}"
370                        print(f"  │  └─ TRT error: {e}")
371                else:
372                    results[method_name][f"trt_{precision}"] = "⏭️ Exists"

378            except KeyboardInterrupt:
379                print("\n⚠️  Бенчмарк пропущен по запросу пользователя")

486                    trt_path=trt_path,
487                    precision=precision,
