AutoSegmenter API — улучшенная версия FastAPI бэкенда.

Модуль предоставляет REST API для интеллектуальной сегментации изображений с поддержкой:

  • Классических методов (пороговые, градиентные, кластеризация, активные контуры)
  • Нейросетевых моделей (SegFormer, Mask2Former, SAM, YOLOv8, SMP, TorchVision)
  • Автоматического выбора метода на основе характеристик изображения
  • Расчёта метрик качества при наличии Ground Truth
  • Генерации рекомендаций и визуализаций

Исправления и улучшения версии 2.0:

  1. Дублирующийся маршрут /api/methods убран.
  2. Поле best_for добавлено в рекомендации.
  3. Кеш нейронных моделей — модель грузится один раз (LRU, max 3).
  4. Bare except → except (json.JSONDecodeError, ValueError).
  5. Две функции b64-кодирования объединены в arr_to_b64.
  6. Добавлены /api/health и /api/cache_info.
  7. HTTP 422 вместо 500 при невалидных входных данных.
  8. elapsed_ms и library возвращаются клиенту.
  9. Пользовательские параметры корректно мёржатся с дефолтами.

Пример использования: ```bash # Запуск сервера python backend/main.py

# Сегментация классическим методом
curl -X POST http://localhost:8000/api/segment \
-F "file=@image.jpg" \
-F "mode=classical" \
-F "auto_select=true"

# Сегментация нейросетью
curl -X POST http://localhost:8000/api/segment \
-F "file=@image.jpg" \
-F "mode=neural" \
-F "task=semantic" \
-F "model=segformer_b2"

Attributes: _model_cache (Dict[str, Any]): LRU-кеш загруженных нейронных моделей. _CACHE_MAX (int): Максимальное количество моделей в кеше (по умолчанию 3). NEURAL_CONFIGS (NeuralConfigDict): Конфигурации предобученных нейросетей. auto_seg (AutoSegmenter): Глобальный экземпляр селектора методов.

 164def _get_or_load_neural(config: Dict[str, Any], task: str) -> Any:
 165    """Загружает нейронный сегментер с LRU-кешем (макс. 3 модели).
 166
 167    Алгоритм:
 168    1. Формирует уникальный ключ кеша из конфигурации и типа задачи.
 169    2. Проверяет наличие модели в _model_cache.
 170    3. При отсутствии:
 171    - Вытесняет старейшую запись если кеш полон.
 172    - Загружает NeuralSegmenter с указанной конфигурацией.
 173    - Сохраняет экземпляр в кеш.
 174    4. Возвращает закэшированный или вновь загруженный экземпляр.
 175
 176    Args:
 177        config (Dict[str, Any]): Конфигурация модели:
 178            - model_type: Тип архитектуры ("segformer", "mask2former", "sam", ...).
 179            - model_name: Имя модели в HuggingFace или путь к локальному чекпоинту.
 180            - Дополнительные параметры для инициализации NeuralSegmenter.
 181        task (str): Тип задачи сегментации:
 182            - "semantic": Семантическая сегментация (класс на пиксель).
 183            - "instance": Instance segmentation (отдельные объекты).
 184            - "panoptic": Паноптическая сегментация (вещи + вещи).
 185
 186    Returns:
 187        NeuralSegmenter: Готовый к использованию экземпляр сегментера.
 188
 189    Raises:
 190        RuntimeError: Если загрузка модели завершилась ошибкой.
 191        ValueError: Если конфигурация не содержит обязательных полей.
 192
 193    Example:
 194        ```python
 195        config = {"model_type": "segformer", "model_name": "nvidia/segformer-b2-..."}
 196        model = _get_or_load_neural(config, task="semantic")
 197        result = model.segment_image(pil_image)
 198        ```
 199
 200    Note:
 201        - Устройство (cuda/cpu) определяется автоматически при загрузке.
 202        - Повторные вызовы с идентичной конфигурацией возвращают тот же объект.
 203    """
 204    cache_key: str = json.dumps({**config, "_task": task}, sort_keys=True)
 205    if cache_key not in _model_cache:
 206        if len(_model_cache) >= _CACHE_MAX:
 207            oldest: str = next(iter(_model_cache))
 208            del _model_cache[oldest]
 209            logger.info("Model cache evicted oldest entry")
 210        device: str = "cuda" if torch.cuda.is_available() else "cpu"
 211        logger.info(f"Loading {config.get('model_type')} on {device}")
 212        _model_cache[cache_key] = NeuralSegmenter(**config, device=device)
 213    return _model_cache[cache_key]

 219def arr_to_b64(arr: np.ndarray) -> str:
 220    """Конвертирует numpy-массив в base64 PNG-строку для передачи по HTTP.
 221
 222    Алгоритм обработки:
 223    1. Приводит dtype к uint8 если необходимо (масштабирует [0,1] → [0,255]).
 224    2. Удаляет лишнее измерение для одноканальных изображений (H×W×1 → H×W).
 225    3. Конвертирует массив в PIL.Image и сохраняет в BytesIO в формате PNG.
 226    4. Кодирует бинарные данные в base64 и добавляет data: URI префикс.
 227
 228    Args:
 229        arr (np.ndarray): Входной массив:
 230            - Форма: (H, W) для grayscale или (H, W, C) для RGB.
 231            - dtype: любой числовой тип (автоматически приводится к uint8).
 232            - Диапазон значений: [0, 1] (float) или [0, 255] (uint8).
 233
 234    Returns:
 235        str: Строка формата `data:image/png;base64,...` готовая для вставки в <img src="">.
 236
 237    Example:
 238        ```python
 239        mask = np.zeros((512, 512), dtype=np.uint8)
 240        mask[100:200, 100:200] = 255
 241        b64_str = arr_to_b64(mask)
 242        # b64_str: "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."
 243        ```
 244
 245    Note:
 246        - Функция не изменяет входной массив (работает с копией при конвертации).
 247        - Для больших изображений (>4096×4096) рекомендуется предварительный ресайз.
 248        - PNG выбран как формат с потерями-без-потерь для бинарных масок.
 249    """
 250    if arr.dtype != np.uint8:
 251        arr = (arr * 255).astype(np.uint8) if arr.max() <= 1.0 else arr.astype(np.uint8)
 252    if arr.ndim == 3 and arr.shape[2] == 1:
 253        arr = arr.squeeze()
 254    buf = io.BytesIO()
 255    Image.fromarray(arr).save(buf, format="PNG")
 256    return "data:image/png;base64," + base64.b64encode(buf.getvalue()).decode()

 260def analyze_image_data(img_array: ImageArray) -> AnalysisDataDict:
 261    """Извлекает статистические данные изображения для визуализации и анализа.
 262
 263    Вычисляемые метрики:
 264    1. **Гистограмма интенсивностей**: 64 бина, диапазон [0, 256].
 265    2. **Плотность границ**: Доля пикселей с градиентом > 30% от максимума.
 266    3. **Края Собеля**: Визуализация градиентов в base64 для предпросмотра.
 267
 268    Алгоритм:
 269    1. Конвертация RGB → grayscale если необходимо (среднее по каналам).
 270    2. Вычисление гистограммы через np.histogram с 64 бинами.
 271    3. Применение оператора Собеля по осям X и Y через scipy.ndimage.
 272    4. Расчёт магнитуды градиента: |∇I| = √(Gx² + Gy²).
 273    5. Нормализация и конвертация краёв в base64 через arr_to_b64.
 274
 275    Args:
 276        img_array (ImageArray): Входное изображение:
 277            - Форма: (H, W, 3) для RGB или (H, W) для grayscale.
 278            - dtype: uint8, диапазон [0, 255].
 279
 280    Returns:
 281        AnalysisDataDict: Словарь с результатами анализа:
 282            - histogram (List[int]): Значения гистограммы (64 элемента).
 283            - hist_bins (List[float]): Границы бинов гистограммы (65 элементов).
 284            - edge_density (float): Доля пикселей-границ [0.0, 1.0].
 285            - edges_b64 (str): Base64-строка с визуализацией краёв Собеля.
 286
 287    Example:
 288        ```python
 289        img = np.random.randint(0, 256, (512, 512, 3), dtype=np.uint8)
 290        analysis = analyze_image_data(img)
 291        print(f"Edge density: {analysis['edge_density']:.2%}")
 292        ```
 293
 294    Note:
 295        - Гистограмма вычисляется по всем каналам для RGB (после усреднения).
 296        - Порог для edge_density (30% от максимума) выбран эмпирически.
 297        - Визуализация краёв нормализуется к [0, 255] перед кодированием.
 298    """
 299    from scipy import ndimage
 300
 301    # Гистограмма интенсивностей
 302    hist, bins = np.histogram(img_array.flatten(), bins=64, range=(0, 256))
 303    gray: np.ndarray = (
 304        np.mean(img_array, axis=2).astype(np.float32)
 305        if img_array.ndim == 3
 306        else img_array.astype(np.float32)
 307    )
 308    sobel_x: np.ndarray = ndimage.sobel(gray, axis=0)
 309    sobel_y: np.ndarray = ndimage.sobel(gray, axis=1)
 310    edges: np.ndarray = np.hypot(sobel_x, sobel_y)
 311    edges_norm: np.ndarray = (edges / (edges.max() + 1e-8) * 255).astype(np.uint8)
 312
 313    return {
 314        "histogram": hist.tolist(),
 315        "hist_bins": bins.tolist(),
 316        "edge_density": float(np.mean(edges > edges.max() * 0.3)),
 317        "edges_b64": arr_to_b64(edges_norm),
 318    }

 322def sanitize_metrics(m: MetricsDict) -> MetricsDict:
 323    """Заменяет `inf` и `NaN` на `None` для JSON-совместимости.
 324
 325    Проблема:
 326        Некоторые метрики (например, при делении на ноль) могут возвращать
 327        `float('inf')` или `float('nan')`, которые не сериализуются в JSON.
 328
 329    Решение:
 330        Рекурсивно обходит словарь и заменяет проблемные значения на None.
 331
 332    Args:
 333        m (MetricsDict): Словарь с метриками качества сегментации, например:
 334            {"iou": 0.85, "dice": 0.91, "precision": float('inf'), ...}
 335
 336    Returns:
 337        MetricsDict: Очищенный словарь, безопасный для json.dumps():
 338            {"iou": 0.85, "dice": 0.91, "precision": None, ...}
 339
 340    Example:
 341        ```python
 342        raw_metrics = {"iou": 0.8, "hausdorff": float('inf')}
 343        safe_metrics = sanitize_metrics(raw_metrics)
 344        # safe_metrics: {"iou": 0.8, "hausdorff": None}
 345        json.dumps(safe_metrics)  # ✅ Успешная сериализация
 346        ```
 347
 348    Note:
 349        - Функция не изменяет исходный словарь (возвращает новый).
 350        - Замена на None позволяет фронтенду корректно отображать "N/A".
 351        - Для продакшена рекомендуется логировать случаи замены для отладки.
 352    """
 353    return {
 354        k: (None if isinstance(v, float) and (math.isinf(v) or math.isnan(v)) else v)
 355        for k, v in m.items()
 356    }

 360def build_overlay(img: ImageArray, mask: MaskArray, alpha: float = 0.4) -> ImageArray:
 361    """Создаёт наложение маски на оригинальное изображение с прозрачностью.
 362
 363    Алгоритм смешивания (alpha blending):
 364        ```
 365        result = img * (1 - alpha) + overlay_color * alpha
 366        ```
 367        где overlay_color — красный канал (255, 0, 0) для пикселей маски.
 368
 369    Args:
 370        img (ImageArray): Оригинальное изображение:
 371            - Форма: (H, W) для grayscale или (H, W, 3) для RGB.
 372            - dtype: uint8, диапазон [0, 255].
 373        mask (MaskArray): Бинарная маска сегментации:
 374            - Форма: (H, W), dtype=uint8.
 375            - Значения: 0 (фон) или 255 (объект).
 376        alpha (float, optional): Прозрачность наложения [0.0, 1.0].
 377            - 0.0: только оригинальное изображение.
 378            - 1.0: только красная маска.
 379            - По умолчанию: 0.4 (баланс видимости).
 380
 381    Returns:
 382        np.ndarray: RGB-изображение формы (H, W, 3), dtype=uint8:
 383            - Пиксели фона: оригинальные цвета с прозрачностью.
 384            - Пиксели объекта: смесь оригинала и красного (255, 0, 0).
 385
 386    Example:
 387        ```python
 388        img = np.random.randint(0, 256, (512, 512, 3), dtype=np.uint8)
 389        mask = np.zeros((512, 512), dtype=np.uint8)
 390        mask[100:200, 100:200] = 255
 391        overlay = build_overlay(img, mask, alpha=0.5)
 392        # overlay: RGB изображение с полупрозрачной красной маской
 393        ```
 394
 395    Note:
 396        - Grayscale изображения автоматически дублируются в 3 канала.
 397        - Маска с значениями != 0 и != 255 интерпретируется как бинарная (>0 → объект).
 398        - Для производительности используется векторизованная индексация массивов.
 399    """
 400    rgb: np.ndarray = np.stack([img] * 3, axis=-1) if img.ndim == 2 else img.copy()
 401    col: np.ndarray = np.zeros_like(rgb)
 402    col[mask > 0] = [255, 0, 0]
 403    return (rgb * (1 - alpha) + col * alpha).astype(np.uint8)

 407def params_to_schema(params: Dict[str, Any]) -> Dict[str, Any]:
 408    """Генерирует JSON-схему UI-конфигуратора из параметров по умолчанию.
 409
 410    Алгоритм определения типа и диапазона:
 411    1. **boolean**: Если значение — bool, схема: {"type": "boolean", "default": v}.
 412    2. **int**:
 413    - "Большие" параметры (size/bin/iter/scale/radius): max=500.
 414    - Остальные: max=100.
 415    - min=1, step=1.
 416    3. **float**:
 417    - "Нормализованные" (|v|≤2.0 или threshold/k/ratio/factor): max=1.0.
 418    - Остальные: max=100.0.
 419    - min=0.0, step=0.01.
 420    4. **string**: Для остальных типов: {"type": "string", "default": str(v)}.
 421
 422    Args:
 423        params (Dict[str, Any]): Словарь параметров метода, например:
 424            {"threshold": 0.5, "window_size": 15, "k": -0.2, "enable": True}
 425
 426    Returns:
 427        Dict[str, Any]: JSON-схема для динамической генерации UI-формы:
 428            {
 429                "threshold": {"type": "float", "min": 0.0, "max": 1.0, "step": 0.01, "default": 0.5},
 430                "window_size": {"type": "int", "min": 1, "max": 500, "step": 1, "default": 15},
 431                "k": {"type": "float", "min": 0.0, "max": 100.0, "step": 0.01, "default": -0.2},
 432                "enable": {"type": "boolean", "default": True}
 433            }
 434
 435    Example:
 436        ```python
 437        params = {"threshold": 0.5, "iterations": 100}
 438        schema = params_to_schema(params)
 439        # schema: {
 440        #   "threshold": {"type": "float", "min": 0.0, "max": 1.0, ...},
 441        #   "iterations": {"type": "int", "min": 1, "max": 500, ...}
 442        # }
 443        ```
 444
 445    Note:
 446        - Эвристики для "больших" и "нормализованных" параметров можно расширять.
 447        - Схема совместима с библиотеками типа react-jsonschema-form.
 448        - Для сложных типов (списки, словари) требуется ручная доработка.
 449    """
 450    schema: Dict[str, Any] = {}
 451    for k, v in params.items():
 452        if isinstance(v, bool):
 453            schema[k] = {"type": "boolean", "default": v}
 454        elif isinstance(v, int):
 455            big: bool = any(x in k for x in ("size", "bin", "iter", "scale", "radius"))
 456            schema[k] = {
 457                "type": "int",
 458                "min": 1,
 459                "max": 500 if big else 100,
 460                "step": 1,
 461                "default": v,
 462            }
 463        elif isinstance(v, float):
 464            norm: bool = abs(v) <= 2.0 or any(
 465                x in k for x in ("threshold", "k", "ratio", "factor")
 466            )
 467            schema[k] = {
 468                "type": "float",
 469                "min": 0.0,
 470                "max": 1.0 if norm else 100.0,
 471                "step": 0.01,
 472                "default": v,
 473            }
 474        else:
 475            schema[k] = {"type": "string", "default": str(v)}
 476    return schema

  3. Возвращает список рекомендаций в формате JSON.
