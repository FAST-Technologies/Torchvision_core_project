segmenters.BackendSegmenters

Модуль высокопроизводительных сегментеров на базе ONNX Runtime и TensorRT.

Предназначен для ускоренного инференса предварительно экспортированных моделей сегментации с поддержкой аппаратного ускорения на GPU.

Классы:

  • 🟦 ONNXSegmenter: Инференс через ONNX Runtime с поддержкой CUDA/CPU провайдеров. • Автоматический выбор Execution Provider (CUDAExecutionProvider → CPUExecutionProvider) • Графические оптимизации: ORT_ENABLE_ALL для максимального ускорения • Гибкая конфигурация входной формы: input_shape=(B, C, H, W) • Устойчивость к ошибкам: возврат пустой маски при сбое инференса
  • 🟩 TRTSegmenter: Инференс через TensorRT (torch_tensorrt) для максимальной производительности. • Загрузка моделей из .trt файлов или готовых torch.nn.Module • Автоматическая конвертация: numpy → torch.Tensor → TRT inference → numpy • Только CUDA: TensorRT требует наличия GPU с поддержкой CUDA • Оптимизированный конвейер: нормализация [0,1], batch-обработка, пост-процессинг

Особенности реализации:

  • 🔄 Единый интерфейс: оба класса наследуют BaseSegmenter и реализуют segment() / segment_with_mask().
  • 🎚️ Автоматическая предобработка: конвертация в 3 канала, нормализация к [0, 1], добавление batch-измерения.
  • 🛡️ Устойчивость к ошибкам: при исключении в segment() возвращается пустая маска (H, W) вместо None.
  • 📦 Поддержка форматов: вход — np.ndarray, PIL.Image, str (путь), torch.Tensor; выход — np.ndarray uint8 {0, 255}.
  • ⚡ Оптимизации: torch.no_grad() для TRT, SessionOptions для ONNX, кэширование сессий/моделей.
  • 🔍 Логирование: информативные сообщения об инициализации, формах тензоров и ошибках инференса.

Ограничения:

  • Вероятностные маски не поддерживаются: segment_with_mask() возвращает (binary_mask, None).
  • TRTSegmenter требует наличия CUDA-совместимого GPU и установленных torch-tensorrt, tensorrt.
  • ONNX-модели должны быть экспортированы с фиксированной или динамической входной формой, совместимой с input_shape.

Workflow:

  1. Экспортировать обученную модель в ONNX (.onnx) или TensorRT (.trt) формат.
  2. Инициализировать сегментер: ONNXSegmenter("method", "model.onnx", device="cuda").
  3. Выполнить инференс: mask = segmenter.segment(image).
  4. (Опционально) Использовать в бенчмарках через CpuCudaBenchmark или SegmentationBenchmark.

Примечание:

  • Для классических методов (пороги, границы) используйте OpenCVSegmenter / SklearnSegmenter.
  • Для нейросетевых моделей в PyTorch — TorchSegmenter / TorchSegmenter2.
  • Данный модуль предназначен для деплоя и бенчмаркинга уже обученных моделей.
  • Функция load_trt_model() импортируется из utils.backend_exporter_new — убедитесь в её наличии.

 130class ONNXSegmenter(BaseSegmenter):
 131    """Сегментер нейронной модели через ONNX Runtime + CUDAExecutionProvider.
 132
 133    Работает для всех архитектур (U-Net, FPN, PSPNet, SegNet, DeepLab, FCN).
 134    Возвращает многоклассовую маску (H, W) с индексами классов 0..N-1,
 135    а не бинарную {0, 255} как ONNXSegmenter для классических методов.
 136
 137    Используется когда TRT engine не удалось собрать через torch_tensorrt.
 138    """
 139
 140    def __init__(
 141        self,
 142        model_key: str,
 143        onnx_path: str,
 144        num_classes: int = 150,
 145        device: DeviceType = "cuda",
 146        input_shape: InputShape = (1, 3, 512, 512),
 147        normalization: NormalizationType = "imagenet",
 148        mean: Optional[List[float]] = None,
 149        std: Optional[List[float]] = None,
 150        is_neural: Optional[bool] = None,
 151        use_tensorrt_ep: bool = False,
 152        trt_options: Optional[Dict[str, Any]] = None,
 153        trt_cache_path: Optional[str] = None,
 154        precision: PrecisionType = "fp32",
 155        **kwargs: Any,
 156    ) -> None:
 157        """Инициализация ONNX сегментера.
 158
 159        Args:
 160            model_key: Имя метода для логирования.
 161            onnx_path: Путь к .onnx файлу модели.
 162            num_classes: Число классов экспортируемой модели.
 163            device: Устройство выполнения: "cuda" или "cpu".
 164            input_shape: Ожидаемая форма входа: (B, C, H, W).
 165            normalization: Параметр нормализации (по уиолчанию "imagenet").
 166            mean: Среднее (может быть None).
 167            std: Среднеквадратичное отклонение (может быть None).
 168            is_neural: Флаг проверки на нейронную модель.
 169            use_tensorrt_ep: Использовать TensorRT Execution Provider.
 170            trt_options: Опции для TensorRT EP.
 171            trt_cache_path: Путь для кэша TRT engine.
 172            precision: Точность вычислений для TRT ("fp32", "fp16", "bf16").
 173            **kwargs: Дополнительные параметры.
 174        """
 175        super().__init__()
 176        self.method: str = model_key
 177        self.params: Dict[str, Any] = kwargs
 178        self.num_classes: int = num_classes
 179        self.device: torch.device = torch.device(device)
 180        self.input_shape: InputShape = input_shape
 181        self.is_neural: bool = is_neural if is_neural is not None else _is_neural_by_key(model_key)
 182
 183        self.use_tensorrt_ep: bool = use_tensorrt_ep
 184        self.trt_options: Optional[Dict[str, Any]] = trt_options
 185        self.trt_cache_path: Optional[str] = trt_cache_path
 186        self.precision: PrecisionType = precision
 187
 188        try:
 189            import onnxruntime as ort
 190        except ImportError:
 191            raise ImportError("onnxruntime-gpu не установлен: pip install onnxruntime-gpu")
 192
 193        # ──────────────────────────────────────────────────────────────
 194        # Формирование списка провайдеров с поддержкой TRT EP
 195        # ──────────────────────────────────────────────────────────────
 196        providers: List[OnnxProvider] = []
 197
 198        if self.device.type == "cuda" and self.use_tensorrt_ep:
 199            if "TensorrtExecutionProvider" in ort.get_available_providers():
 200                # Базовые опции для TRT EP
 201                trt_ep_opts: Dict[str, Any] = {
 202                    "device_id": 0,
 203                    "trt_fp16_enable": (precision in ["fp16", "bf16"]),
 204                    "trt_int8_enable": False,
 205                    # "trt_engine_cache_enable": True,
 206                    # "trt_engine_cache_path": trt_cache_path or f"./trt_cache/{precision}/{model_key}",
 207                    # "trt_timing_cache_enable": True,
 208                    # "trt_timing_cache_path": trt_cache_path or f"./trt_cache/{precision}/{model_key}/timing",
 209                    "trt_engine_cache_enable": False,  # ← Ключевое!
 210                    "trt_timing_cache_enable": False,  # ← И это!
 211                    "trt_builder_optimization_level": 5,
 212                    "trt_max_workspace_size": 1 << 30,  # 1GB
 213                }
 214                if precision == "bf16":
 215                    # Проверяем версию ONNX Runtime
 216                    import onnxruntime as ort
 217
 218                    ort_version = tuple(map(int, ort.__version__.split(".")[:2]))
 219                    if ort_version >= (1, 16):
 220                        trt_ep_opts["trt_bf16_enable"] = True
 221                        logger.info(
 222                            f"✅ {model_key}: активирован TRT EP с bf16 (ORT {'.'.join(map(str, ort_version))})"
 223                        )
 224                    else:
 225                        logger.warning(f"⚠️ {model_key}: bf16 требует ORT ≥1.16, используется fp16 fallback")
 226                        trt_ep_opts["trt_fp16_enable"] = True
 227                # Объединяем с пользовательскими опциями
 228                if trt_options:
 229                    trt_ep_opts.update({k: v for k, v in trt_options.items() if k not in trt_ep_opts})
 230
 231                providers.append(("TensorrtExecutionProvider", trt_ep_opts))
 232
 233                # CUDA EP как fallback
 234                providers.append(
 235                    (
 236                        "CUDAExecutionProvider",
 237                        {
 238                            "device_id": 0,
 239                            "arena_extend_strategy": "kNextPowerOfTwo",
 240                            "cudnn_conv_algo_search": "EXHAUSTIVE",
 241                            # "do_copy_in_default_stream": False,  # ← Разрешить non-default stream
 242                            # "enable_cuda_graph": True,  # ← Опционально: CUDA Graphs для ускорения
 243                            # "cudnn_conv_use_max_workspace": True,
 244                            "do_copy_in_default_stream": True,
 245                        },
 246                    )
 247                )
 248                logger.info(f"✅ {model_key}: активирован TensorrtExecutionProvider ({precision})")
 249            else:
 250                logger.warning(f"⚠️ {model_key}: TensorrtExecutionProvider не доступен, используем CUDA EP")
 251                providers.append(
 252                    (
 253                        "CUDAExecutionProvider",
 254                        {
 255                            "device_id": 0,
 256                            "arena_extend_strategy": "kNextPowerOfTwo",
 257                            "cudnn_conv_algo_search": "EXHAUSTIVE",
 258                            # "do_copy_in_default_stream": False,  # ← Разрешить non-default stream
 259                            # "enable_cuda_graph": True,  # ← Опционально: CUDA Graphs для ускорения
 260                            # "cudnn_conv_use_max_workspace": True,
 261                            "do_copy_in_default_stream": True,
 262                        },
 263                    )
 264                )
 265        elif self.device.type == "cuda":
 266            # Стандартный CUDA EP без TRT
 267            providers.append(
 268                (
 269                    "CUDAExecutionProvider",
 270                    {
 271                        "device_id": 0,
 272                        "arena_extend_strategy": "kNextPowerOfTwo",
 273                        "cudnn_conv_algo_search": "EXHAUSTIVE",
 274                        "do_copy_in_default_stream": True,
 275                    },
 276                )
 277            )
 278
 279        # CPU как последний fallback
 280        providers.append("CPUExecutionProvider")
 281
 282        # ──────────────────────────────────────────────────────────────
 283        # Создание сессии
 284        # ──────────────────────────────────────────────────────────────
 285        sess_options: ort.SessionOptions = ort.SessionOptions()
 286        sess_options.graph_optimization_level = ort.GraphOptimizationLevel.ORT_ENABLE_ALL
 287        sess_options.enable_mem_pattern = True
 288
 289        self.sess_options = sess_options
 290
 291        self.session: ONNXSession = ort.InferenceSession(onnx_path, sess_options=sess_options, providers=providers)
 292        self.input_name: str = self.session.get_inputs()[0].name
 293        self.output_name: str = self.session.get_outputs()[0].name
 294
 295        if precision != "fp32":
 296            logger.debug(
 297                f"🔧 [{self.method}] Запрошена точность: {precision}. "
 298                f"Модель: {onnx_path}, EP: {self.session.get_providers()}"
 299            )
 300
 301        print(f"🔍 Available outputs: {[o.name for o in self.session.get_outputs()]}")
 302        print(f"🔍 Expected output_name: {self.output_name}")
 303
 304        test_input = np.random.randn(*input_shape).astype(np.float32)
 305        test_output = self.session.run(None, {self.input_name: test_input})
 306        logger.info(
 307            f"Test run: output shape={test_output[0].shape if test_output else None}, "
 308            f"has_nan={np.isnan(test_output[0]).any() if test_output else 'N/A'}"
 309        )
 310
 311        if not self._validate_session():
 312            logger.warning(f"⚠️ {model_key}: сессия не прошла валидацию, возможны проблемы при инференсе")
 313
 314        # Проверяем реальный output shape из модели
 315        out_shape: Tuple[Union[str, int], ...] = self.session.get_outputs()[0].shape
 316        logger.info(
 317            f"ONNX '{model_key}': input={self.input_name}, " f"output={self.output_name}, output_shape={out_shape}"
 318        )
 319        active: Sequence[str] = self.session.get_providers()
 320        logger.info(
 321            f"NeuralONNXSegmenter '{model_key}': providers={active}, " f"output={self.session.get_outputs()[0].shape}"
 322        )
 323        if normalization == "imagenet":
 324            self.mean: Optional[np.ndarray] = np.array([0.485, 0.456, 0.406], dtype=np.float32)
 325            self.std: Optional[np.ndarray] = np.array([0.229, 0.224, 0.225], dtype=np.float32)
 326        elif normalization == "custom" and mean and std:
 327            self.mean = np.array(mean, dtype=np.float32)
 328            self.std = np.array(std, dtype=np.float32)
 329        else:
 330            self.mean = None
 331            self.std = None

 333    def _apply_precision(self, tensor: torch.Tensor, precision: PrecisionType) -> torch.Tensor:
 334        if precision == "fp16":
 335            return tensor.half()
 336        elif precision == "bf16" and hasattr(torch, "bfloat16"):
 337            return tensor.bfloat16()
 338        return tensor.float()

 340    def _validate_session(self) -> bool:
 341        """Проверка работоспособности сессии."""
 342        try:
 343            test_input = np.random.randn(*self.input_shape).astype(np.float32)
 344            outputs = self.session.run(None, {self.input_name: test_input})
 345            if outputs and outputs[0] is not None:
 346                logger.info(f"✅ Session validation OK: {outputs[0].shape}")
 347                return True
 348            else:
 349                logger.error(f"❌ Session validation failed: empty output")
 350                return False
 351        except Exception as e:
 352            logger.error(f"❌ Session validation error: {e}")
 353            return False

 355    def _preprocess_classic(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
 356        """Конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
 357
 358        Args:
 359            image: Входное изображение (H, W) или (H, W, 3), uint8.
 360
 361        Returns:
 362            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
 363        """
 364        if image.ndim == 2:
 365            image = np.stack([image] * 3, axis=-1)
 366        if image.ndim == 3 and image.shape[2] == 3:
 367            tensor: npt.NDArray[np.float32] = np.transpose(image, (2, 0, 1)).astype(np.float32) / 255.0
 368            return np.expand_dims(tensor, 0)  # (1,3,H,W)
 369        # Уже (B,C,H,W)
 370        return image.astype(np.float32)

 372    def _preprocess_neural(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
 373        """Imagenet нормализация: конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
 374
 375        Args:
 376            image: Входное изображение (H, W) или (H, W, 3), uint8.
 377
 378        Returns:
 379            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
 380        """
 381        if image.ndim == 3 and image.shape[2] != 3:
 382            image = image[:, :, :3]
 383        elif image.ndim == 2:
 384            image = np.stack([image] * 3, axis=-1)
 385
 386        # Resize к целевому размеру
 387        h_target, w_target = self.input_shape[2], self.input_shape[3]
 388        if image.shape[0] != h_target or image.shape[1] != w_target:
 389            pil: Image.Image = PILImage.fromarray(image.astype(np.uint8))
 390            pil = pil.resize((w_target, h_target), PILImage.Resampling.BILINEAR)
 391            image = np.array(pil)
 392
 393        # ImageNet нормализация
 394        if self.mean is not None and self.std is not None:
 395            tensor: npt.NDArray[np.float32] = (image.astype(np.float32) / 255.0 - self.mean) / self.std
 396        else:
 397            tensor = image.astype(np.float32) / 255.0
 398        tensor = np.transpose(tensor, (2, 0, 1))  # HWC → CHW
 399        return np.expand_dims(tensor, 0)  # (1, C, H, W)

 401    def segment(self, image: Union[str, np.ndarray, Image.Image, torch.Tensor], **kwargs: Any) -> BinaryMask:
 402        """Запускает ONNX инференс.
 403
 404        Алгоритм:
 405        1. Предобработка изображения → (1, 3, H, W), float32, [0, 1].
 406        2. Запуск сессии ONNX.
 407        3. Пост-обработка вывода: squeeze → бинаризация → uint8.
 408
 409        Args:
 410            image: Входное изображение (H, W) или (H, W, 3), uint8.
 411            **kwargs: Дополнительные параметры (игнорируются).
 412
 413        Returns:
 414            BinaryMask: Бинарная маска формы (H, W), uint8, значения {0, 255}.
 415                       При ошибке возвращает пустую маску того же размера.
 416        """
 417        # 1. Приведение входа к numpy
 418        if isinstance(image, str):
 419            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
 420        elif isinstance(image, Image.Image):
 421            image_np = np.array(image)
 422        elif isinstance(image, torch.Tensor):
 423            image_np = image.cpu().numpy()
 424            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
 425                image_np = np.transpose(image_np, (1, 2, 0))
 426        else:
 427            image_np = image
 428        orig_h, orig_w = image_np.shape[:2]
 429        try:
 430            if self.is_neural:
 431                tensor: PreprocessedTensor = self._preprocess_neural(image_np)
 432            else:
 433                tensor = self._preprocess_classic(image_np)
 434            outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor})
 435            if not outputs or outputs[0] is None:
 436                logger.error(f"ONNX '{self.method}' returned None/empty output")
 437                return np.zeros((orig_h, orig_w), dtype=np.uint8)
 438            logits: RawOutput = outputs[0]  # (1, C, H, W) или (1, H, W)
 439
 440            # 3. Интеллектуальная пост-обработка
 441            # Case A: Нейросеть (Batch, Channels, H, W)
 442            if logits.ndim == 4 and logits.shape[1] > 1:
 443                # Многоклассовая: argmax
 444                mask: np.ndarray = logits[0].argmax(axis=0).astype(np.uint8)
 445
 446            # Case B: Бинарная нейросеть или классика (Batch, 1, H, W) или (Batch, H, W)
 447            elif logits.ndim == 4 and logits.shape[1] == 1:
 448                mask = logits[0, 0]
 449                if mask.max() <= 1.0:
 450                    mask = (mask > 0.5).astype(np.uint8) * 255
 451                else:
 452                    mask = mask.astype(np.uint8)
 453
 454            elif logits.ndim == 3:
 455                # (1, H, W)
 456                mask = logits[0]
 457                if mask.max() <= 1.0:
 458                    mask = (mask > 0.5).astype(np.uint8) * 255
 459                else:
 460                    mask = mask.astype(np.uint8)
 461
 462            # Case C: Уже маска (H, W)
 463            elif logits.ndim == 2:
 464                mask = logits
 465                if mask.max() <= 1.0:
 466                    mask = (mask > 0.5).astype(np.uint8) * 255
 467                else:
 468                    mask = mask.astype(np.uint8)
 469
 470            else:
 471                # Fallback
 472                mask = logits.flatten().reshape((orig_h, orig_w)).astype(np.uint8)
 473
 474            # Resize к оригинальному размеру
 475            if mask.shape != (orig_h, orig_w):
 476                from scipy.ndimage import zoom
 477
 478                sh, sw = orig_h / mask.shape[0], orig_w / mask.shape[1]
 479                mask = zoom(mask, (sh, sw), order=0).astype(np.uint8)
 480
 481            return cast(BinaryMask, mask)
 482
 483        except Exception as e:
 484            logger.error(f"ONNX '{self.method}' inference error: {e}")
 485            return np.zeros((orig_h, orig_w), dtype=np.uint8)

 487    def segment_with_mask(
 488        self, image: ImageInput, alpha: float = 0.9, **kwargs: Any
 489    ) -> Tuple[BinaryMask, Optional[ProbabilityMask]]:
 490        """Сегментация с возвратом визуализации и бинарной маски.
 491
 492        Создаёт наложение маски на оригинальное изображение с прозрачностью `alpha`.
 493        Стиль визуализации соответствует другим сегментерам (OpenCV/Sklearn/Torch).
 494
 495        Args:
 496            image: Входное изображение.
 497            alpha: Коэффициент наложения маски [0, 1]:
 498                - 0.0 = только оригинальное изображение
 499                - 1.0 = только маска (красным цветом)
 500                - 0.9 = по умолчанию (сильный акцент на маске)
 501            **kwargs: Дополнительные параметры:
 502                - return_probs (bool): Если True, возвращать вероятностную маску.
 503                - prob_class (int): Для multi-class: индекс класса для вероятностной маски.
 504                - prob_threshold (float): Порог для бинаризации вероятностей (по умолчанию 0.5).
 505
 506        Returns:
 507            Tuple[np.ndarray, np.ndarray]:
 508                - `overlay`: Визуализация формы `(H, W, 3)`, dtype=uint8, RGB.
 509                - `mask`: Бинарная маска формы `(H, W)`, dtype=uint8, {0, 255}.
 510
 511        Note:
 512            - Маска накладывается красным цветом `[255, 0, 0]` для пикселей > 127.
 513            - Grayscale изображения автоматически конвертируются в 3-канальные для наложения.
 514            - Формула смешивания: `result = overlay * alpha + original * (1 - alpha)`.
 515        """
 516        # ──────────────────────────────────────────────────────────────
 517        # 1. Конвертация входного изображения в numpy
 518        # ──────────────────────────────────────────────────────────────
 519        if isinstance(image, str):
 520            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
 521        elif isinstance(image, Image.Image):
 522            image_np = np.array(image.convert("RGB"))
 523        elif isinstance(image, torch.Tensor):
 524            image_np = image.cpu().numpy()
 525            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
 526                image_np = np.transpose(image_np, (1, 2, 0))
 527            if image_np.ndim == 2:
 528                image_np = np.stack([image_np] * 3, axis=-1)
 529        elif isinstance(image, np.ndarray):
 530            image_np = image
 531            if image_np.ndim == 2:
 532                image_np = np.stack([image_np] * 3, axis=-1)
 533            elif image_np.shape[2] != 3:
 534                image_np = image_np[:, :, :3]
 535        else:
 536            raise TypeError(f"Unsupported image type: {type(image)}")
 537
 538        orig_h, orig_w = image_np.shape[:2]
 539
 540        try:
 541            # ──────────────────────────────────────────────────────────────
 542            # 2. Предобработка (аналогично методу segment)
 543            # ──────────────────────────────────────────────────────────────
 544            if self.is_neural:
 545                tensor_np: PreprocessedTensor = self._preprocess_neural(image_np)
 546            else:
 547                tensor_np = self._preprocess_classic(image_np)
 548
 549            # ──────────────────────────────────────────────────────────────
 550            # 3. Инференс модели
 551            # ──────────────────────────────────────────────────────────────
 552            # outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor_np})
 553
 554            # if not outputs or outputs[0] is None:
 555            #     logger.error(f"ONNX '{self.method}' returned None output")
 556            #     return image_np.copy(), np.zeros((orig_h, orig_w), dtype=np.uint8)
 557
 558            # logits: RawOutput = outputs[0]
 559
 560            logger.debug(f"=== ONNX Inference Debug ===")
 561            logger.debug(
 562                f"Input: name={self.input_name}, shape={tensor_np.shape}, dtype={tensor_np.dtype}, range=[{tensor_np.min():.3f}, {tensor_np.max():.3f}]"
 563            )
 564            logger.debug(f"Output expected: name={self.output_name}, shape={self.session.get_outputs()[0].shape}")
 565            logger.debug(f"Active providers: {self.session.get_providers()}")
 566            logger.debug(f"Session options: graph_opt={self.sess_options.graph_optimization_level}")
 567
 568            if not tensor_np.flags["C_CONTIGUOUS"]:
 569                logger.warning("⚠️ Input tensor not C-contiguous, making copy")
 570                tensor_np = np.ascontiguousarray(tensor_np)
 571
 572            outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor_np})
 573            if not outputs or outputs[0] is None:
 574                logger.error(f"❌ session.run returned empty/None!")
 575                logger.error(f"Available outputs: {[o.name for o in self.session.get_outputs()]}")
 576                all_outputs = self.session.run(None, {self.input_name: tensor_np})
 577                logger.error(f"All outputs count: {len(all_outputs) if all_outputs else 0}")
 578
 579                logger.info(
 580                    f"  Input: shape={tensor_np.shape}, dtype={tensor_np.dtype}, range=[{tensor_np.min():.3f}, {tensor_np.max():.3f}]"
 581                )
 582                logger.info(f"  Providers: {self.session.get_providers()}")
 583
 584                # 🔧 Fallback: попробовать с явным именем выхода
 585                try:
 586                    outputs = self.session.run([self.output_name], {self.input_name: tensor_np})
 587                    logger.info(f"  Retry with explicit output name: {len(outputs) if outputs else 'None'} outputs")
 588                    if outputs and outputs[0] is not None:
 589                        logger.info(f"✅ Fallback succeeded for {self.method}")
 590                    else:
 591                        logger.warning(f"⚠️ Fallback also failed for {self.method}")
 592                except Exception as e:
 593                    logger.error(f"  Fallback error: {e}")
 594                return image_np.copy(), np.zeros((orig_h, orig_w), dtype=np.uint8)
 595            logits: RawOutput = outputs[0]  # (1, C, H, W) или (1, H, W)
 596            if np.isnan(logits).any() or np.isinf(logits).any():
 597                logger.warning(f"⚠️ Logits contain NaN/Inf: nan={np.isnan(logits).sum()}, inf={np.isinf(logits).sum()}")
 598                logits = np.nan_to_num(logits, nan=0.0, posinf=1.0, neginf=0.0)
 599
 600            logger.info(
 601                f"Output: shape={logits.shape}, dtype={logits.dtype}, "
 602                f"range=[{logits.min():.3f}, {logits.max():.3f}], has_nan={np.isnan(logits).any()}"
 603            )
 604
 605            # ──────────────────────────────────────────────────────────────
 606            # 4. Интеллектуальная пост-обработка (аналогично segment)
 607            # ──────────────────────────────────────────────────────────────
 608            return_probs: bool = kwargs.get("return_probs", False)
 609            prob_class: int = kwargs.get("prob_class", -1)
 610            prob_threshold: float = kwargs.get("prob_threshold", 0.5)
 611            prob_mask: Optional[ProbabilityMask] = None
 612
 613            if logits.ndim == 4 and logits.shape[1] > 1:
 614                # Multi-class: argmax
 615                mask: np.ndarray = logits[0].argmax(axis=0).astype(np.uint8)
 616                if return_probs:
 617                    if 0 <= prob_class < logits.shape[1]:
 618                        probs = logits[0, prob_class]
 619                    else:
 620                        probs = np.max(logits[0], axis=0)
 621                    if probs.max() > 1.0 or probs.min() < 0:
 622                        exp_vals = np.exp(logits[0] - np.max(logits[0], axis=0, keepdims=True))
 623                        softmax = exp_vals / (np.sum(exp_vals, axis=0, keepdims=True) + 1e-8)
 624                        prob_mask = (
 625                            softmax[prob_class].astype(np.float32)
 626                            if 0 <= prob_class < logits.shape[1]
 627                            else np.max(softmax, axis=0).astype(np.float32)
 628                        )
 629                    else:
 630                        prob_mask = probs.astype(np.float32)
 631            else:
 632                # Binary
 633                raw_mask = logits[0, 0] if logits.ndim == 4 else (logits[0] if logits.ndim == 3 else logits)
 634                if raw_mask.max() <= 1.0:
 635                    mask = (raw_mask > prob_threshold).astype(np.uint8) * 255
 636                else:
 637                    mask = raw_mask.astype(np.uint8)
 638                if return_probs:
 639                    if raw_mask.max() <= 1.0 and raw_mask.min() >= 0:
 640                        prob_mask = raw_mask.astype(np.float32)
 641                    else:
 642                        prob_mask = 1.0 / (1.0 + np.exp(-np.clip(raw_mask.astype(np.float32), -50, 50)))
 643
 644            # ──────────────────────────────────────────────────────────────
 645            # 5. Ресайз масок к оригинальному размеру изображения
 646            # ──────────────────────────────────────────────────────────────
 647            if mask.shape != (orig_h, orig_w):
 648                sh, sw = orig_h / mask.shape[0], orig_w / mask.shape[1]
 649                mask = zoom(mask, (sh, sw), order=0).astype(np.uint8)  # nearest для маски
 650
 651            if prob_mask is not None and prob_mask.shape != (orig_h, orig_w):
 652                sh, sw = orig_h / prob_mask.shape[0], orig_w / prob_mask.shape[1]
 653                prob_mask = zoom(prob_mask, (sh, sw), order=1).astype(np.float32)  # linear для вероятностей
 654
 655            # ──────────────────────────────────────────────────────────────
 656            # 5. 🔧 СОЗДАНИЕ ОВЕРЛЕЯ (как в OpenCV/Sklearn/Torch сегментерах)
 657            # ──────────────────────────────────────────────────────────────
 658            # Конвертируем исходное изображение в RGB если нужно
 659            if image_np.ndim == 2:
 660                base_img = np.stack([image_np] * 3, axis=-1)
 661            else:
 662                base_img = image_np.copy()
 663
 664            # Создаём оверлей: копию изображения для наложения маски
 665            overlay = base_img.copy()
 666
 667            # 🔧 FIX: Красный цвет для маски [255, 0, 0] — только там, где mask > 127
 668            mask_bool = mask > 127
 669            overlay[mask_bool] = [255, 0, 0]  # RGB: красный
 670
 671            # 🔧 FIX: Правильная формула alpha blending (как в OpenCVSegmenter):
 672            # result = overlay * alpha + base_img * (1 - alpha)
 673            # Это даёт: красная маска с прозрачностью, оригинал виден под ней
 674            result = cv2.addWeighted(
 675                overlay.astype(np.float32), alpha, base_img.astype(np.float32), 1.0 - alpha, 0
 676            ).astype(np.uint8)
 677
 678            return result, mask.astype(np.uint8)
 679
 680        except Exception as e:
 681            logger.error(f"TRT '{self.method}' segment_with_mask error: {e}", exc_info=True)
 682            # Возвращаем пустые маски при ошибке
 683            return np.zeros((orig_h, orig_w), dtype=np.uint8), None

 770        if image.ndim == 2:
 771            image = np.stack([image] * 3, axis=-1)

 790    def _preprocess_classic(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
 791        """Конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
 792
 793        Args:
 794            image: Входное изображение (H, W) или (H, W, 3), uint8.
 795
 796        Returns:
 797            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
 798        """
 799        if image.ndim == 2:
 800            image = np.stack([image] * 3, axis=-1)
 801        if image.ndim == 3 and image.shape[2] == 3:

 807    def _preprocess_neural(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
 808        """Imagenet нормализация: конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
 809
 810        Args:
 811            image: Входное изображение (H, W) или (H, W, 3), uint8.
 812
 813        Returns:
 814            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
 815        """
 816        if image.ndim == 3 and image.shape[2] != 3:
 817            image = image[:, :, :3]
 818        elif image.ndim == 2:
 819            image = np.stack([image] * 3, axis=-1)
 820
 821        # Resize к целевому размеру
 822        h_target, w_target = self.input_shape[2], self.input_shape[3]
 823        if image.shape[0] != h_target or image.shape[1] != w_target:
 824            pil: Image.Image = PILImage.fromarray(image.astype(np.uint8))
 825            pil = pil.resize((w_target, h_target), PILImage.Resampling.BILINEAR)
 826            image = np.array(pil)
 827
 828        # ImageNet нормализация
 829        if self.mean is not None and self.std is not None:
 830            tensor: npt.NDArray[np.float32] = (image.astype(np.float32) / 255.0 - self.mean) / self.std
 831        else:
 832            tensor = image.astype(np.float32) / 255.0
 833        tensor = np.transpose(tensor, (2, 0, 1))  # HWC → CHW
 834        return np.expand_dims(tensor, 0)  # (1, C, H, W)

 836    def segment(self, image: ImageInput, **kwargs: Any) -> BinaryMask:
 837        """Запускает TRT инференс.
 838
 839        Алгоритм:
 840        1. Конвертация numpy → torch.Tensor (C, H, W), float32, [0, 1].
 841        2. Добавление batch-измерения и перенос на устройство.
 842        3. Инференс модели с torch.no_grad().
 843        4. Пост-обработка: squeeze → numpy → uint8 [0, 255].
 844
 845        Args:
 846            image: Входное изображение (H, W) или (H, W, 3), uint8.
 847            **kwargs: Дополнительные параметры (игнорируются).
 848
 849        Returns:
 850            BinaryMask: Бинарная маска формы (H, W), uint8, значения {0, 255}.
 851                       При ошибке возвращает пустую маску того же размера.
 852        """
 853        # 1. Приведение входа
 854        if isinstance(image, str):
 855            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
 856        elif isinstance(image, Image.Image):
 857            image_np = np.array(image)
 858        elif isinstance(image, torch.Tensor):
 859            image_np = image.cpu().numpy()
 860            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
 861                image_np = np.transpose(image_np, (1, 2, 0))
 862        else:
 863            image_np = image
 864        orig_h, orig_w = image_np.shape[:2]
 865        try:
 866            if self.is_neural:
 867                tensor_np = self._preprocess_neural(image_np)
 868            else:
 869                tensor_np = self._preprocess_classic(image_np)
 870
 871            tensor = torch.from_numpy(tensor_np).to(self.device) if isinstance(tensor_np, np.ndarray) else tensor_np
 872            tensor = self._apply_precision(tensor, self.precision)
 873
 874            # 3. Инференс
 875            use_stream: bool = kwargs.get("use_cuda_stream", True)
 876
 877            if use_stream and self.device.type == "cuda":
 878                # Создаём или используем кэшированный stream
 879                if not hasattr(self, "_inference_stream"):
 880                    self._inference_stream: torch.cuda.Stream = torch.cuda.Stream(device=self.device)
 881
 882                with torch.cuda.stream(self._inference_stream):
 883                    with torch.no_grad():
 884                        out = self.model(tensor)
 885                    # Синхронизация только этого stream перед копированием на CPU
 886                    self._inference_stream.synchronize()
 887            else:
 888                # Fallback: выполнение в дефолтном stream
 889                with torch.no_grad():
 890                    out = self.model(tensor)
 891
 892            if isinstance(out, torch.Tensor):
 893                out_np: np.ndarray = out.cpu().float().numpy()
 894            elif isinstance(out, np.ndarray):
 895                out_np = out.astype(np.float32)
 896            elif isinstance(out, (list, tuple)):
 897                # Если модель возвращает несколько выходов, берём первый
 898                first = out[0]
 899                if isinstance(first, torch.Tensor):
 900                    out_np = first.cpu().float().numpy()
 901                else:
 902                    out_np = np.asarray(first, dtype=np.float32)
 903            else:
 904                # Fallback: пытаемся конвертировать в массив
 905                out_np = np.asarray(out, dtype=np.float32)
 906
 907            # 🔧 FIX: Явное приведение типов для linter
 908            out_np = cast(np.ndarray, out_np)
 909
 910            # 4. Интеллектуальная пост-обработка (аналогично ONNX)
 911            if out_np.ndim == 4 and out_np.shape[1] > 1:
 912                # Multi-class
 913                # Case A: Нейросеть (Batch, Channels, H, W)
 914                mask: np.ndarray = out_np[0].argmax(axis=0).astype(np.uint8)
 915            # Case B: Бинарная нейросеть или классика (Batch, 1, H, W) или (Batch, H, W)
 916            elif out_np.ndim == 4 and out_np.shape[1] == 1:
 917                mask = out_np[0, 0]
 918                if mask.max() <= 1.0:
 919                    mask = (mask > 0.5).astype(np.uint8) * 255
 920                else:
 921                    mask = mask.astype(np.uint8)
 922            elif out_np.ndim == 3:
 923                # (1, H, W)
 924                mask = out_np[0]
 925                if mask.max() <= 1.0:
 926                    mask = (mask > 0.5).astype(np.uint8) * 255
 927                else:
 928                    mask = mask.astype(np.uint8)
 929
 930            # Case C: Уже маска (H, W)
 931            elif out_np.ndim == 2:
 932                mask = out_np
 933                if mask.max() <= 1.0:
 934                    mask = (mask > 0.5).astype(np.uint8) * 255
 935                else:
 936                    mask = mask.astype(np.uint8)
 937
 938            else:
 939                # Fallback
 940                mask = out_np.flatten().reshape((orig_h, orig_w)).astype(np.uint8)
 941
 942            # 5. Ресайз
 943            if mask.shape != (orig_h, orig_w):
 944                sh, sw = orig_h / mask.shape[0], orig_w / mask.shape[1]
 945                mask = zoom(mask, (sh, sw), order=0).astype(np.uint8)
 946            return cast(BinaryMask, mask)
 947
 948        except Exception as e:
 949            logger.error(f"TRT '{self.method}' inference error: {e}")
 950            return np.zeros((orig_h, orig_w), dtype=np.uint8)

 952    def segment_with_mask(
 953        self, image: ImageInput, alpha: float = 0.9, **kwargs: Any
 954    ) -> Tuple[BinaryMask, Optional[ProbabilityMask]]:
 955        """Сегментация с возвратом визуализации и бинарной маски.
 956
 957        Для TRT-модели:
 958        - Бинарная маска: результат пост-обработки (argmax для multi-class, порог для binary)
 959        - Вероятностная маска: нормализованные вероятности/логиты модели (опционально)
 960
 961        Создаёт наложение маски на оригинальное изображение с прозрачностью `alpha`.
 962        Стиль визуализации соответствует другим сегментерам (OpenCV/Sklearn/Torch).
 963
 964        Алгоритм пост-обработки:
 965        1. Multi-class output (C>1): argmax → binary mask, softmax → prob mask
 966        2. Binary output (C=1): sigmoid/threshold → binary mask, raw logits → prob mask
 967        3. Ресайз масок к оригинальному размеру изображения
 968
 969        Args:
 970            image: Входное изображение (путь, PIL, numpy или torch).
 971            alpha: Коэффициент наложения маски [0, 1]:
 972              - 0.0 = только оригинальное изображение
 973              - 1.0 = только маска (красным цветом)
 974              - 0.9 = по умолчанию (сильный акцент на маске)
 975            **kwargs: Дополнительные параметры:
 976                - return_probs (bool): Если True, возвращать вероятностную маску.
 977                - prob_class (int): Для multi-class: индекс класса для вероятностной маски.
 978                - prob_threshold (float): Порог для бинаризации вероятностей (по умолчанию 0.5).
 979
 980        Returns:
 981            Tuple[BinaryMask, Optional[ProbabilityMask]]:
 982            - `overlay`: Визуализация формы `(H, W, 3)`, dtype=uint8, RGB.
 983            - `mask`: Бинарная маска формы `(H, W)`, dtype=uint8, {0, 255}.
 984
 985        Note:
 986            - Маска накладывается красным цветом `[255, 0, 0]` для пикселей > 127.
 987            - Grayscale изображения автоматически конвертируются в 3-канальные для наложения.
 988            - Формула смешивания: `result = overlay * alpha + original * (1 - alpha)`.
 989        """
 990        # ──────────────────────────────────────────────────────────────
 991        # 1. Конвертация входного изображения в numpy
 992        # ──────────────────────────────────────────────────────────────
 993        if isinstance(image, str):
 994            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
 995        elif isinstance(image, Image.Image):
 996            image_np = np.array(image.convert("RGB"))
 997        elif isinstance(image, torch.Tensor):
 998            image_np = image.cpu().numpy()
 999            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
1000                image_np = np.transpose(image_np, (1, 2, 0))
1001            if image_np.ndim == 2:
1002                image_np = np.stack([image_np] * 3, axis=-1)
1003        elif isinstance(image, np.ndarray):
1004            image_np = image
1005            if image_np.ndim == 2:
1006                image_np = np.stack([image_np] * 3, axis=-1)
1007            elif image_np.shape[2] != 3:
1008                image_np = image_np[:, :, :3]
1009        else:
1010            raise TypeError(f"Unsupported image type: {type(image)}")
1011
1012        orig_h, orig_w = image_np.shape[:2]
1013
1014        try:
1015            # ──────────────────────────────────────────────────────────────
1016            # 2. Предобработка (аналогично методу segment)
1017            # ──────────────────────────────────────────────────────────────
1018            if self.is_neural:
1019                tensor_np = self._preprocess_neural(image_np)
1020            else:
1021                tensor_np = self._preprocess_classic(image_np)
1022
1023            # ──────────────────────────────────────────────────────────────
1024            # 3. Инференс модели
1025            # ──────────────────────────────────────────────────────────────
1026            tensor = torch.from_numpy(tensor_np).to(self.device) if isinstance(tensor_np, np.ndarray) else tensor_np
1027            tensor = self._apply_precision(tensor, self.precision)
1028            use_stream = kwargs.get("use_cuda_stream", True)
1029
1030            if use_stream and self.device.type == "cuda":
1031                if not hasattr(self, "_inference_stream"):
1032                    self._inference_stream = torch.cuda.Stream(device=self.device)
1033                with torch.cuda.stream(self._inference_stream):
1034                    with torch.no_grad():
1035                        out = self.model(tensor)
1036                    self._inference_stream.synchronize()
1037            else:
1038                with torch.no_grad():
1039                    out = self.model(tensor)
1040
1041            if isinstance(out, torch.Tensor):
1042                logits: np.ndarray = out.cpu().float().numpy()
1043            elif isinstance(out, np.ndarray):
1044                logits = out.astype(np.float32)
1045            elif isinstance(out, (list, tuple)):
1046                # Если модель возвращает несколько выходов, берём первый
1047                first = out[0]
1048                if isinstance(first, torch.Tensor):
1049                    logits = first.cpu().float().numpy()
1050                else:
1051                    logits = np.asarray(first, dtype=np.float32)
1052            else:
1053                # Fallback: пытаемся конвертировать в массив
1054                logits = np.asarray(out, dtype=np.float32)
1055
1056            # 🔧 FIX: Явное приведение типов для linter
1057            logits = cast(np.ndarray, logits)
1058
1059            # ──────────────────────────────────────────────────────────────
1060            # 4. Интеллектуальная пост-обработка (аналогично segment)
1061            # ──────────────────────────────────────────────────────────────
1062            return_probs: bool = kwargs.get("return_probs", False)
1063            prob_class: int = kwargs.get("prob_class", -1)
1064            prob_threshold: float = kwargs.get("prob_threshold", 0.5)
1065
1066            prob_mask: Optional[ProbabilityMask] = None
1067
1068            if logits.ndim == 4 and logits.shape[1] > 1:
1069                # Multi-class: argmax
1070                mask: np.ndarray = logits[0].argmax(axis=0).astype(np.uint8)
1071                if return_probs:
1072                    if 0 <= prob_class < logits.shape[1]:
1073                        probs = logits[0, prob_class]
1074                    else:
1075                        probs = np.max(logits[0], axis=0)
1076                    if probs.max() > 1.0 or probs.min() < 0:
1077                        exp_vals = np.exp(logits[0] - np.max(logits[0], axis=0, keepdims=True))
1078                        softmax = exp_vals / (np.sum(exp_vals, axis=0, keepdims=True) + 1e-8)
1079                        prob_mask = (
1080                            softmax[prob_class].astype(np.float32)
1081                            if 0 <= prob_class < logits.shape[1]
1082                            else np.max(softmax, axis=0).astype(np.float32)
1083                        )
1084                    else:
1085                        prob_mask = probs.astype(np.float32)
1086            else:
1087                # Binary
1088                raw_mask = logits[0, 0] if logits.ndim == 4 else (logits[0] if logits.ndim == 3 else logits)
1089                if raw_mask.max() <= 1.0:
1090                    mask = (raw_mask > prob_threshold).astype(np.uint8) * 255
1091                else:
1092                    mask = raw_mask.astype(np.uint8)
1093                if return_probs:
1094                    if raw_mask.max() <= 1.0 and raw_mask.min() >= 0:
1095                        prob_mask = raw_mask.astype(np.float32)
1096                    else:
1097                        prob_mask = 1.0 / (1.0 + np.exp(-np.clip(raw_mask.astype(np.float32), -50, 50)))
1098
1099            # ──────────────────────────────────────────────────────────────
1100            # 5. Ресайз масок к оригинальному размеру изображения
1101            # ──────────────────────────────────────────────────────────────
1102            if mask.shape != (orig_h, orig_w):
1103                sh, sw = orig_h / mask.shape[0], orig_w / mask.shape[1]
1104                mask = zoom(mask, (sh, sw), order=0).astype(np.uint8)  # nearest для маски
1105
1106            if prob_mask is not None and prob_mask.shape != (orig_h, orig_w):
1107                sh, sw = orig_h / prob_mask.shape[0], orig_w / prob_mask.shape[1]
1108                prob_mask = zoom(prob_mask, (sh, sw), order=1).astype(np.float32)  # linear для вероятностей
1109
1110            # ──────────────────────────────────────────────────────────────
1111            # 5. 🔧 СОЗДАНИЕ ОВЕРЛЕЯ (как в OpenCV/Sklearn/Torch сегментерах)
1112            # ──────────────────────────────────────────────────────────────
1113            # Конвертируем исходное изображение в RGB если нужно
1114            if image_np.ndim == 2:
1115                base_img = np.stack([image_np] * 3, axis=-1)
1116            else:
1117                base_img = image_np.copy()
1118
1119            # Создаём оверлей: копию изображения для наложения маски
1120            overlay = base_img.copy()
1121
1122            # 🔧 FIX: Красный цвет для маски [255, 0, 0] — только там, где mask > 127
1123            mask_bool = mask > 127
1124            overlay[mask_bool] = [255, 0, 0]  # RGB: красный
1125
1126            # 🔧 FIX: Правильная формула alpha blending (как в OpenCVSegmenter):
1127            # result = overlay * alpha + base_img * (1 - alpha)
1128            # Это даёт: красная маска с прозрачностью, оригинал виден под ней
1129            result = cv2.addWeighted(
1130                overlay.astype(np.float32), alpha, base_img.astype(np.float32), 1.0 - alpha, 0
1131            ).astype(np.uint8)
1132
1133            return result, mask.astype(np.uint8)
1134
1135        except Exception as e:
1136            logger.error(f"TRT '{self.method}' segment_with_mask error: {e}", exc_info=True)
1137            # Возвращаем пустые маски при ошибке
1138            return np.zeros((orig_h, orig_w), dtype=np.uint8), None

356    def _preprocess_classic(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:

367        if image.ndim == 3 and image.shape[2] == 3:
368            tensor: npt.NDArray[np.float32] = np.transpose(image, (2, 0, 1)).astype(np.float32) / 255.0

373    def _preprocess_neural(self, image: npt.NDArray[np.uint8]) -> PreprocessedTensor:
374        """Imagenet нормализация: конвертирует изображение в формат (1, 3, H, W), float32, [0, 1].
375
376        Args:
377            image: Входное изображение (H, W) или (H, W, 3), uint8.
378
379        Returns:
380            PreprocessedTensor: Тензор формы (1, 3, H, W), float32, нормализованный к [0, 1].
381        """
382        if image.ndim == 3 and image.shape[2] != 3:
383            image = image[:, :, :3]
384        elif image.ndim == 2:
385            image = np.stack([image] * 3, axis=-1)
386
387        # Resize к целевому размеру
388        h_target, w_target = self.input_shape[2], self.input_shape[3]
389        if image.shape[0] != h_target or image.shape[1] != w_target:
390            pil: Image.Image = PILImage.fromarray(image.astype(np.uint8))
391            pil = pil.resize((w_target, h_target), PILImage.Resampling.BILINEAR)
392            image = np.array(pil)

394        # ImageNet нормализация
395        if self.mean is not None and self.std is not None:
396            tensor: npt.NDArray[np.float32] = (image.astype(np.float32) / 255.0 - self.mean) / self.std
397        else:
398            tensor = image.astype(np.float32) / 255.0
399        tensor = np.transpose(tensor, (2, 0, 1))  # HWC → CHW

402    def segment(self, image: Union[str, np.ndarray, Image.Image, torch.Tensor], **kwargs: Any) -> BinaryMask:
403        """Запускает ONNX инференс.
404
405        Алгоритм:
406        1. Предобработка изображения → (1, 3, H, W), float32, [0, 1].
407        2. Запуск сессии ONNX.
408        3. Пост-обработка вывода: squeeze → бинаризация → uint8.
409
410        Args:
411            image: Входное изображение (H, W) или (H, W, 3), uint8.
412            **kwargs: Дополнительные параметры (игнорируются).
413
414        Returns:
415            BinaryMask: Бинарная маска формы (H, W), uint8, значения {0, 255}.
416                       При ошибке возвращает пустую маску того же размера.
417        """
418        # 1. Приведение входа к numpy
419        if isinstance(image, str):
420            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
421        elif isinstance(image, Image.Image):
422            image_np = np.array(image)
423        elif isinstance(image, torch.Tensor):
424            image_np = image.cpu().numpy()
425            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
426                image_np = np.transpose(image_np, (1, 2, 0))
427        else:
428            image_np = image
429        orig_h, orig_w = image_np.shape[:2]
430        try:
431            if self.is_neural:
432                tensor: PreprocessedTensor = self._preprocess_neural(image_np)
433            else:
434                tensor = self._preprocess_classic(image_np)
435            outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor})
436            if not outputs or outputs[0] is None:
437                logger.error(f"ONNX '{self.method}' returned None/empty output")
438                return np.zeros((orig_h, orig_w), dtype=np.uint8)
439            logits: RawOutput = outputs[0]  # (1, C, H, W) или (1, H, W)
440
441            # 3. Интеллектуальная пост-обработка
442            # Case A: Нейросеть (Batch, Channels, H, W)
443            if logits.ndim == 4 and logits.shape[1] > 1:
444                # Многоклассовая: argmax
445                mask: np.ndarray = logits[0].argmax(axis=0).astype(np.uint8)
446
447            # Case B: Бинарная нейросеть или классика (Batch, 1, H, W) или (Batch, H, W)
448            elif logits.ndim == 4 and logits.shape[1] == 1:
449                mask = logits[0, 0]
450                if mask.max() <= 1.0:
451                    mask = (mask > 0.5).astype(np.uint8) * 255
452                else:
453                    mask = mask.astype(np.uint8)
454
455            elif logits.ndim == 3:
456                # (1, H, W)
457                mask = logits[0]
458                if mask.max() <= 1.0:
459                    mask = (mask > 0.5).astype(np.uint8) * 255
460                else:
461                    mask = mask.astype(np.uint8)
462
463            # Case C: Уже маска (H, W)
464            elif logits.ndim == 2:
465                mask = logits
466                if mask.max() <= 1.0:
467                    mask = (mask > 0.5).astype(np.uint8) * 255
468                else:
469                    mask = mask.astype(np.uint8)
470
471            else:
472                # Fallback
473                mask = logits.flatten().reshape((orig_h, orig_w)).astype(np.uint8)
474
475            # Resize к оригинальному размеру
476            if mask.shape != (orig_h, orig_w):
477                from scipy.ndimage import zoom
478
479                sh, sw = orig_h / mask.shape[0], orig_w / mask.shape[1]
480                mask = zoom(mask, (sh, sw), order=0).astype(np.uint8)
481
482            return cast(BinaryMask, mask)
483
484        except Exception as e:
485            logger.error(f"ONNX '{self.method}' inference error: {e}")
486            return np.zeros((orig_h, orig_w), dtype=np.uint8)

488    def segment_with_mask(
489        self, image: ImageInput, alpha: float = 0.9, **kwargs: Any
490    ) -> Tuple[BinaryMask, Optional[ProbabilityMask]]:
491        """Сегментация с возвратом визуализации и бинарной маски.
492
493        Создаёт наложение маски на оригинальное изображение с прозрачностью `alpha`.
494        Стиль визуализации соответствует другим сегментерам (OpenCV/Sklearn/Torch).
495
496        Args:
497            image: Входное изображение.
498            alpha: Коэффициент наложения маски [0, 1]:
499                - 0.0 = только оригинальное изображение
500                - 1.0 = только маска (красным цветом)
501                - 0.9 = по умолчанию (сильный акцент на маске)
502            **kwargs: Дополнительные параметры:
503                - return_probs (bool): Если True, возвращать вероятностную маску.
504                - prob_class (int): Для multi-class: индекс класса для вероятностной маски.
505                - prob_threshold (float): Порог для бинаризации вероятностей (по умолчанию 0.5).
506
507        Returns:
508            Tuple[np.ndarray, np.ndarray]:
509                - `overlay`: Визуализация формы `(H, W, 3)`, dtype=uint8, RGB.
510                - `mask`: Бинарная маска формы `(H, W)`, dtype=uint8, {0, 255}.
511
512        Note:
513            - Маска накладывается красным цветом `[255, 0, 0]` для пикселей > 127.
514            - Grayscale изображения автоматически конвертируются в 3-канальные для наложения.
515            - Формула смешивания: `result = overlay * alpha + original * (1 - alpha)`.
516        """
517        # ──────────────────────────────────────────────────────────────
518        # 1. Конвертация входного изображения в numpy
519        # ──────────────────────────────────────────────────────────────
520        if isinstance(image, str):
521            image_np: np.ndarray = np.array(Image.open(image).convert("RGB"))
522        elif isinstance(image, Image.Image):
523            image_np = np.array(image.convert("RGB"))
524        elif isinstance(image, torch.Tensor):
525            image_np = image.cpu().numpy()
526            if image_np.ndim == 3 and image_np.shape[0] in (1, 3):
527                image_np = np.transpose(image_np, (1, 2, 0))
528            if image_np.ndim == 2:
529                image_np = np.stack([image_np] * 3, axis=-1)
530        elif isinstance(image, np.ndarray):
531            image_np = image
532            if image_np.ndim == 2:
533                image_np = np.stack([image_np] * 3, axis=-1)
534            elif image_np.shape[2] != 3:
535                image_np = image_np[:, :, :3]
536        else:
537            raise TypeError(f"Unsupported image type: {type(image)}")
538
539        orig_h, orig_w = image_np.shape[:2]
540
541        try:
542            # ──────────────────────────────────────────────────────────────
543            # 2. Предобработка (аналогично методу segment)
544            # ──────────────────────────────────────────────────────────────
545            if self.is_neural:
546                tensor_np: PreprocessedTensor = self._preprocess_neural(image_np)
547            else:
548                tensor_np = self._preprocess_classic(image_np)
549
550            # ──────────────────────────────────────────────────────────────
551            # 3. Инференс модели
552            # ──────────────────────────────────────────────────────────────
553            # outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor_np})
554
555            # if not outputs or outputs[0] is None:
556            #     logger.error(f"ONNX '{self.method}' returned None output")
557            #     return image_np.copy(), np.zeros((orig_h, orig_w), dtype=np.uint8)
558
559            # logits: RawOutput = outputs[0]

561            logger.debug(f"=== ONNX Inference Debug ===")

563                f"Input: name={self.input_name}, shape={tensor_np.shape}, dtype={tensor_np.dtype}, range=[{tensor_np.min():.3f}, {tensor_np.max():.3f}]"
564            )
565            logger.debug(f"Output expected: name={self.output_name}, shape={self.session.get_outputs()[0].shape}")
566            logger.debug(f"Active providers: {self.session.get_providers()}")
567            logger.debug(f"Session options: graph_opt={self.sess_options.graph_optimization_level}")
568
569            if not tensor_np.flags["C_CONTIGUOUS"]:
570                logger.warning("⚠️ Input tensor not C-contiguous, making copy")
571                tensor_np = np.ascontiguousarray(tensor_np)
572
573            outputs: List[RawOutput] = self.session.run([self.output_name], {self.input_name: tensor_np})
574            if not outputs or outputs[0] is None:
575                logger.error(f"❌ session.run returned empty/None!")
576                logger.error(f"Available outputs: {[o.name for o in self.session.get_outputs()]}")
577                all_outputs = self.session.run(None, {self.input_name: tensor_np})
578                logger.error(f"All outputs count: {len(all_outputs) if all_outputs else 0}")
579
580                logger.info(
581                    f"  Input: shape={tensor_np.shape}, dtype={tensor_np.dtype}, range=[{tensor_np.min():.3f}, {tensor_np.max():.3f}]"
582                )
583                logger.info(f"  Providers: {self.session.get_providers()}")
584
585                # 🔧 Fallback: попробовать с явным именем выхода
586                try:
587                    outputs = self.session.run([self.output_name], {self.input_name: tensor_np})
588                    logger.info(f"  Retry with explicit output name: {len(outputs) if outputs else 'None'} outputs")
589                    if outputs and outputs[0] is not None:
590                        logger.info(f"✅ Fallback succeeded for {self.method}")
591                    else:
592                        logger.warning(f"⚠️ Fallback also failed for {self.method}")
593                except Exception as e:
594                    logger.error(f"  Fallback error: {e}")
595                return image_np.copy(), np.zeros((orig_h, orig_w), dtype=np.uint8)
596            logits: RawOutput = outputs[0]  # (1, C, H, W) или (1, H, W)
597            if np.isnan(logits).any() or np.isinf(logits).any():
598                logger.warning(f"⚠️ Logits contain NaN/Inf: nan={np.isnan(logits).sum()}, inf={np.isinf(logits).sum()}")
599                logits = np.nan_to_num(logits, nan=0.0, posinf=1.0, neginf=0.0)

602                f"Output: shape={logits.shape}, dtype={logits.dtype}, "
603                f"range=[{logits.min():.3f}, {logits.max():.3f}], has_nan={np.isnan(logits).any()}"

606            # ──────────────────────────────────────────────────────────────
607            # 4. Интеллектуальная пост-обработка (аналогично segment)

609            return_probs: bool = kwargs.get("return_probs", False)
610            prob_class: int = kwargs.get("prob_class", -1)
611            prob_threshold: float = kwargs.get("prob_threshold", 0.5)
612            prob_mask: Optional[ProbabilityMask] = None

614            if logits.ndim == 4 and logits.shape[1] > 1:
615                # Multi-class: argmax

619                        probs = logits[0, prob_class]
620                    else:
621                        probs = np.max(logits[0], axis=0)

624                        softmax = exp_vals / (np.sum(exp_vals, axis=0, keepdims=True) + 1e-8)
625                        prob_mask = (
626                            softmax[prob_class].astype(np.float32)
627                            if 0 <= prob_class < logits.shape[1]

630                    else:
631                        prob_mask = probs.astype(np.float32)
632            else:
633                # Binary
634                raw_mask = logits[0, 0] if logits.ndim == 4 else (logits[0] if logits.ndim == 3 else logits)

637                else:
638                    mask = raw_mask.astype(np.uint8)

640                    if raw_mask.max() <= 1.0 and raw_mask.min() >= 0:
641                        prob_mask = raw_mask.astype(np.float32)
642                    else:
643                        prob_mask = 1.0 / (1.0 + np.exp(-np.clip(raw_mask.astype(np.float32), -50, 50)))

645            # ──────────────────────────────────────────────────────────────
646            # 5. Ресайз масок к оригинальному размеру изображения

Сегментация с возвратом визуализации и бинарной маски.

Для TRT-модели:

  • Бинарная маска: результат пост-обработки (argmax для multi-class, порог для binary)
  • Вероятностная маска: нормализованные вероятности/логиты модели (опционально)

Создаёт наложение маски на оригинальное изображение с прозрачностью alpha. Стиль визуализации соответствует другим сегментерам (OpenCV/Sklearn/Torch).

Алгоритм пост-обработки:

  1. Multi-class output (C>1): argmax → binary mask, softmax → prob mask
  2. Binary output (C=1): sigmoid/threshold → binary mask, raw logits → prob mask
  3. Ресайз масок к оригинальному размеру изображения

Args: image: Входное изображение (путь, PIL, numpy или torch). alpha: Коэффициент наложения маски [0, 1]: - 0.0 = только оригинальное изображение - 1.0 = только маска (красным цветом) - 0.9 = по умолчанию (сильный акцент на маске) **kwargs: Дополнительные параметры: - return_probs (bool): Если True, возвращать вероятностную маску. - prob_class (int): Для multi-class: индекс класса для вероятностной маски. - prob_threshold (float): Порог для бинаризации вероятностей (по умолчанию 0.5).

Returns: Tuple[BinaryMask, Optional[ProbabilityMask]]: - overlay: Визуализация формы (H, W, 3), dtype=uint8, RGB. - mask: Бинарная маска формы (H, W), dtype=uint8, {0, 255}.

Note: - Маска накладывается красным цветом [255, 0, 0] для пикселей > 127. - Grayscale изображения автоматически конвертируются в 3-канальные для наложения. - Формула смешивания: result = overlay * alpha + original * (1 - alpha).
