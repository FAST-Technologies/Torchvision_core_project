segmenters.BaseSegmenter

Абстрактный базовый класс для всех методов сегментации изображений.

Модуль определяет унифицированный интерфейс (BaseSegmenter) для реализации алгоритмов сегментации, обеспечивая совместимость между классическими методами (пороговые, граничные, кластеризация) и нейросетевыми архитектурами.

Ключевые компоненты:

  • 🎨 Типизация: Протоколы и TypeAlias для изображений, масок, метрик. • ImageInput: Union[str, np.ndarray, PIL.Image, torch.Tensor] • BinaryMask: np.ndarray формы (H, W), dtype uint8, значения {0, 255} • ProbabilityMask: np.ndarray формы (H, W), dtype float32, значения [0, 1] • MetricsDict: Dict[str, float] для результатов оценки качества

  • 🔧 Абстрактные методы (требуют реализации в наследниках): • segment(image, **kwargs) → BinaryMask: Основная сегментация • segment_with_mask(image, **kwargs) → (BinaryMask, Optional[ProbabilityMask]): Сегментация с возвратом вероятностной маски

  • 🛠️ Готовые утилиты (доступны всем наследникам): • preprocess_image(): Конвертация входов → np.ndarray с опциями grayscale/resize/normalize • visualize(): Наложение маски на изображение с альфа-блендингом • evaluate_metrics(): Расчёт метрик через SegmentationMetrics • segment_and_evaluate(): Комбинированный вызов "сегментация + оценка" • _ensure_binary_mask(): Приведение масок к формату {0, 255} • get_info(): Мета-информация о сегментере

  • 🔄 Гибкий вызов: Перегрузка __call__ позволяет использовать экземпляр как функцию: • seg(image) → BinaryMask • seg(image, return_mask=True) → (BinaryMask, ProbabilityMask | None)

Особенности реализации:

  • 📦 Поддержка 4 форматов входа: путь к файлу, PIL.Image, np.ndarray, torch.Tensor
  • 🎨 Конвертация цветовых пространств: RGB ↔ BGR ↔ GRAY через OpenCV/PIL
  • 📐 Ресайз с адаптивной интерполяцией: INTER_AREA для уменьшения, INTER_LINEAR для увеличения
  • 🎚️ Нормализация: опциональное приведение [0,255] → [0,1] для нейросетей
  • 🛡️ Валидация: проверка размеров изображения и маски перед визуализацией/оценкой
  • 🔍 Логирование: информативные сообщения об ошибках загрузки и обработки

Workflow для создания нового сегментера:

  1. Наследовать класс: class MySegmenter(BaseSegmenter):
  2. Реализовать абстрактные методы: segment() и segment_with_mask()
  3. (Опционально) Переопределить preprocess_image() для специфичной предобработки
  4. Использовать готовые утилиты: visualize(), evaluate_metrics(), _ensure_binary_mask()

Примечание:

  • Все методы сегментации должны возвращать маску в формате BinaryMask: форма (H, W), dtype uint8, значения {0, 255} (0=фон, 255=объект).
  • Для вероятностных выходов используйте тип ProbabilityMask и возвращайте None, если метод не поддерживает вывод уверенности.
  • Метрики рассчитываются через делегирование SegmentationMetrics.calculate_all_metrics() — убедитесь в наличии этого модуля в проекте.
  • Для массового тестирования используйте обёртки: BatchClassicTester, SegmentationTester, TorchImplementationValidator.

316    def preprocess_image(
317        self,
318        image: ImageInput,
319        as_gray: bool = False,
320        target_size: Optional[Tuple[int, int]] = None,
321        normalize: bool = False,
322    ) -> NumpyImage:
323        """Предобработка изображения к единому формату `np.ndarray`.
324
325        Поддерживает:
326        - Загрузку из файла/URL.
327        - Конвертацию форматов (PIL → numpy, torch → numpy).
328        - Конвертацию цветовых пространств (RGB/GRAY).
329        - Ресайз к `target_size`.
330        - Нормализацию значений в [0, 1].
331
332        Args:
333            image: Входное изображение.
334            as_gray: Если `True`, конвертирует в оттенки серого.
335            target_size: Целевой размер `(ширина, высота)`. Если `None`, размер не меняется.
336            normalize: Если `True`, нормализует значения в [0, 1] (dtype float32).
337
338        Returns:
339            NumpyImage: Предобработанное изображение.
340            - Если `normalize=False`: dtype `uint8`, диапазон [0, 255].
341            - Если `normalize=True`: dtype `float32`, диапазон [0, 1].
342
343        Raises:
344            ValueError: Если не удалось загрузить изображение по пути/URL.
345            TypeError: Если тип входных данных не поддерживается.
346        """
347        result: NumpyImage
348        if isinstance(image, str):
349            # Загрузка из файла
350            if as_gray:
351                img = cv2.imread(image, cv2.IMREAD_GRAYSCALE)
352                if img is None:
353                    raise ValueError(f"Не удалось загрузить изображение: {image}")
354                result = img  # Уже в GRAY
355            else:
356                img = cv2.imread(image)
357                if img is None:
358                    raise ValueError(f"Не удалось загрузить изображение: {image}")
359                result = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  # BGR→RGB
360        elif isinstance(image, Image.Image):
361            # PIL Image
362            if as_gray:
363                result = np.array(image.convert("L"), dtype=np.uint8)  # 'L' = grayscale
364            else:
365                result = np.array(image.convert("RGB"), dtype=np.uint8)
366        elif isinstance(image, np.ndarray):
367            # NumPy array
368            result = image.copy()
369            if as_gray and len(image.shape) == 3:
370                # Конвертируем RGB/BGR в GRAY
371                if image.shape[2] == 3:
372                    result = cv2.cvtColor(image, cv2.COLOR_RGB2GRAY)
373        elif isinstance(image, torch.Tensor):
374            # PyTorch tensor
375            if image.dim() == 3:
376                # Изменение порядка каналов из (C, H, W) в (H, W, C)
377                if image.shape[0] in (1, 3):
378                    img_np = image.permute(1, 2, 0).cpu().numpy()
379                else:
380                    img_np = image.cpu().numpy()
381            else:
382                img_np = image.cpu().numpy()
383
384            # Приведение к uint8
385            if img_np.dtype in (np.float32, np.float64):
386                if img_np.max() <= 1.0:
387                    img_np = (img_np * 255).astype(np.uint8)
388                else:
389                    img_np = img_np.astype(np.uint8)
390
391            result = img_np
392            if as_gray and len(result.shape) == 3 and result.shape[2] == 3:
393                result = cv2.cvtColor(result, cv2.COLOR_RGB2GRAY)
394        else:
395            raise TypeError(
396                f"Неподдерживаемый тип изображения: {type(image)}. " f"Ожидается один из: {ImageInput.__args__}"
397            )
398        if target_size is not None:
399            interpolation: int = (
400                cv2.INTER_AREA
401                if result.shape[0] * result.shape[1] > target_size[0] * target_size[1]
402                else cv2.INTER_LINEAR
403            )
404            result = cv2.resize(result, target_size, interpolation=interpolation)
405
406        if normalize:
407            if result.dtype != np.float32:

531    # ──────────────────────────────────────────────────────────────────────
532    def _ensure_binary_mask(self, mask: Union[BinaryMask, ProbabilityMask], threshold: float = 0.5) -> BinaryMask:
533        """Приведение маски к бинарному формату {0, 255}.
534
535        Обрабатывает:
536        - `uint8` с диапазоном [0, 1] → умножение на 255.
537        - `uint8` с диапазоном [0, 255] → пороговая бинаризация.
538        - `float32/64` с диапазоном [0, 1] → пороговая бинаризация.
539        - `float32/64` с произвольным диапазоном → нормализация + бинаризация.
540
541        Args:
542            mask: Входная маска.
543            threshold: Порог бинаризации (для вероятностных масок).
544
545        Returns:
546            BinaryMask: Бинарная маска формы `(H, W)`, dtype `uint8`, значения {0, 255}.
547        """
548        if mask.dtype == np.uint8:
549            if mask.max() == 1:
550                return (mask * 255).astype(np.uint8)
551            elif mask.max() <= 255:
552                return np.where(mask > threshold * 255, 255, 0).astype(np.uint8)
553        elif mask.dtype in (np.float32, np.float64):
554            if mask.max() <= 1.0:
555                return np.where(mask > threshold, 255, 0).astype(np.uint8)
556            else:
557                normalized = mask / mask.max()
558                return np.where(normalized > threshold, 255, 0).astype(np.uint8)
559        return mask.astype(np.uint8)

317    def preprocess_image(
318        self,
319        image: ImageInput,
320        as_gray: bool = False,
321        target_size: Optional[Tuple[int, int]] = None,
322        normalize: bool = False,
323    ) -> NumpyImage:
324        """Предобработка изображения к единому формату `np.ndarray`.
325
326        Поддерживает:
327        - Загрузку из файла/URL.
328        - Конвертацию форматов (PIL → numpy, torch → numpy).
329        - Конвертацию цветовых пространств (RGB/GRAY).
330        - Ресайз к `target_size`.
331        - Нормализацию значений в [0, 1].
332
333        Args:
334            image: Входное изображение.
335            as_gray: Если `True`, конвертирует в оттенки серого.
336            target_size: Целевой размер `(ширина, высота)`. Если `None`, размер не меняется.
337            normalize: Если `True`, нормализует значения в [0, 1] (dtype float32).
338
339        Returns:
340            NumpyImage: Предобработанное изображение.
341            - Если `normalize=False`: dtype `uint8`, диапазон [0, 255].
342            - Если `normalize=True`: dtype `float32`, диапазон [0, 1].
343
344        Raises:
345            ValueError: Если не удалось загрузить изображение по пути/URL.
346            TypeError: Если тип входных данных не поддерживается.
347        """
348        result: NumpyImage
349        if isinstance(image, str):
350            # Загрузка из файла
351            if as_gray:
352                img = cv2.imread(image, cv2.IMREAD_GRAYSCALE)
353                if img is None:
354                    raise ValueError(f"Не удалось загрузить изображение: {image}")
355                result = img  # Уже в GRAY
356            else:
357                img = cv2.imread(image)
358                if img is None:
359                    raise ValueError(f"Не удалось загрузить изображение: {image}")
360                result = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  # BGR→RGB
361        elif isinstance(image, Image.Image):
362            # PIL Image
363            if as_gray:
364                result = np.array(image.convert("L"), dtype=np.uint8)  # 'L' = grayscale
365            else:
366                result = np.array(image.convert("RGB"), dtype=np.uint8)
367        elif isinstance(image, np.ndarray):
368            # NumPy array
369            result = image.copy()
370            if as_gray and len(image.shape) == 3:
371                # Конвертируем RGB/BGR в GRAY
372                if image.shape[2] == 3:
373                    result = cv2.cvtColor(image, cv2.COLOR_RGB2GRAY)
374        elif isinstance(image, torch.Tensor):
375            # PyTorch tensor
376            if image.dim() == 3:
377                # Изменение порядка каналов из (C, H, W) в (H, W, C)
378                if image.shape[0] in (1, 3):
379                    img_np = image.permute(1, 2, 0).cpu().numpy()
380                else:
381                    img_np = image.cpu().numpy()
382            else:
383                img_np = image.cpu().numpy()
384
385            # Приведение к uint8
386            if img_np.dtype in (np.float32, np.float64):
387                if img_np.max() <= 1.0:
388                    img_np = (img_np * 255).astype(np.uint8)
389                else:
390                    img_np = img_np.astype(np.uint8)
391
392            result = img_np
393            if as_gray and len(result.shape) == 3 and result.shape[2] == 3:
394                result = cv2.cvtColor(result, cv2.COLOR_RGB2GRAY)
395        else:
396            raise TypeError(
397                f"Неподдерживаемый тип изображения: {type(image)}. " f"Ожидается один из: {ImageInput.__args__}"
398            )
399        if target_size is not None:
400            interpolation: int = (
401                cv2.INTER_AREA
402                if result.shape[0] * result.shape[1] > target_size[0] * target_size[1]
403                else cv2.INTER_LINEAR
404            )
405            result = cv2.resize(result, target_size, interpolation=interpolation)
406
407        if normalize:
408            if result.dtype != np.float32:
409                result = result.astype(np.float32) / 255.0
410
411        return result
